## 一、先讲透：这个滤波器的公式和 α 的含义

一阶低通滤波的离散形式（指数移动平均）：

```
y[k] = α·x[k] + (1-α)·y[k-1]
```

- `x[k]`：这一拍的新采样（含噪声）
- `y[k-1]`：上一拍的滤波输出
- `α`：平滑系数，取值 (0, 1]

**α 的直觉**：α 是「新样本的话语权」。

- α 大（→1）：`y[k] ≈ x[k]`，几乎全信新样本 → 滤波弱、紧跟输入、噪声残留多。
- α 小（→0）：`y[k] ≈ y[k-1]`，几乎只信历史 → 滤波强、输出平滑、但反应慢有延迟。

所以 α 是一个「**滤波强度 vs 响应速度**」的旋钮。这就是 (b) 图要展示的 trade-off。

## 二、为什么这么写（逐段）

### 1. 为什么用 `filter()` 而不自己写 for 循环

```matlab
y = filter(0.2, [1 -0.8], x_noisy);
```

Python 版里是自己写循环 `for k: y[k] = lp.update(x[k])`。MATLAB 有个内置函数 `filter(b, a, x)`，专门干「线性差分方程」这件事：

```
a(1)*y[k] = b(1)*x[k] + b(2)*x[k-1] + ... - a(2)*y[k-1] - ...
```

把低通公式 `y[k] = α·x[k] + (1-α)·y[k-1]` 整理成这个标准形：

```
y[k] - (1-α)·y[k-1] = α·x[k]
   ↑ a(2)             ↑ b(1)
```

所以 `b = [α]`，`a = [1, -(1-α)]`。`filter(0.2, [1 -0.8], x_noisy)` 就是 α=0.2 的一阶低通。

> **为什么这么写**：`filter` 是向量化操作，一行代替整个 for 循环，而且它内部用的是滤波器的标准表达，以后你看到任何差分方程都能直接套 `filter(b,a,x)`。这是 MATLAB 处理滤波器最常用的函数。

### 2. 为什么噪声用 `randn` 而不用 `rand`

```matlab
rng(0);
noise = 0.4*randn(1, n);
```

- `randn`：标准**正态分布**（高斯）随机数，均值 0、方差 1。真实传感器的噪声大多近似高斯，所以用 `randn`。
- `rand`：**均匀分布**（0~1），不适合模拟传感器噪声。
- `0.4*`：把标准差放大到 0.4，让噪声明显一点。
- `rng(0)`：固定随机种子。这样每次运行 `randn` 生成的是**同一串**随机数，结果可复现——和 Python 版 `np.random.default_rng(0)` 的作用完全一样。去掉它，每次跑出来的噪声都不同，图就不一样了。

### 3. 为什么幅频响应用 `freqz` 而不是手写公式

```matlab
[H, f] = freqz(a, [1 -(1-a)], 1024, Fs);
semilogx(f, 20*log10(abs(H)));
```

Python 版里写了一大段 `magnitude_response()` 函数，手动算 `|H(e^{jω})|`。MATLAB 的 `freqz(b, a, N, Fs)` 直接做这件事：

- 输入滤波器的 `b`、`a` 系数
- 输出 N 个频率点的频率响应 `H`，以及对应的实际频率 `f`（因为传了采样率 `Fs`，频率轴就是 Hz）
- `20*log10(abs(H))` 把幅度换算成**分贝 (dB)**，这是幅频响应的标准画法
- `semilogx` 是「x 轴对数刻度」的 plot，因为频率跨度从 0.1Hz 到几百 Hz，用对数轴才看得清低频段

> **为什么这么写**：`freqz` 省掉了手推 `|H(e^{jω})|` 公式的工作，而且不会算错。你只要给对 `b`、`a` 系数，频率响应自动出来。

### 4. 为什么画 -3dB 线用 `yline(-3)`，为什么「-3dB」这么重要

```matlab
yline(-3, '--', 'DisplayName', '-3 dB');
```

-3dB 是滤波器的**截止频率**定义：幅度下降到最大值的 `1/√2 ≈ 0.707`（即 -3dB）处的频率。这条线往下投影到 x 轴，就是该滤波器的截止频率 `fc`。

**为什么盯 -3dB**：它是「通带」和「阻带」的分界。频率低于 `fc` 的信号基本通过，高于 `fc` 的被明显抑制。看 (c) 图，三条曲线分别在哪掉到 -3dB，就对应三个不同的截止频率——α 越小，曲线越早下坠，`fc` 越低，滤掉的频率越多。

### 5. 为什么 (d) 图里 α 只画到 0.8，不画到 1

```matlab
a_axis = linspace(0.001, 0.8, 1000);
fc = acos((2 - 2*a_axis - a_axis.^2) ./ (2*(1 - a_axis))) / (2*pi*dt);
```

截止频率与 α 的精确关系（离散域）：

```
cos(2π·fc·dt) = (2 - 2α - α²) / (2(1-α))
```

`acos` 要求括号里的值在 [-1, 1] 之间。当 α > 2(√2-1) ≈ 0.828 时，右边会超出这个范围，方程**无解**——意思是此时整个通带几乎不衰减，根本不存在 -3dB 点。所以 (d) 图只画到 0.8。

> 这是「离散域精确解」和「连续近似 fc ≈ α/(2π·dt)」的区别：后者在 α 大、频率接近奈奎斯特频率时会明显离谱。代码里用的是精确式，和 Python 版 `cutoff_freq()` 完全一致。

### 6. 为什么用 `./` 和 `.^`（点运算）

```matlab
fc = acos((2 - 2*a_axis - a_axis.^2) ./ (2*(1 - a_axis))) / (2*pi*dt);
```

`a_axis` 是一个有 1000 个元素的**向量**。`a_axis.^2` 的「点」表示「逐元素」平方，`./` 表示「逐元素」相除——没有点的话 MATLAB 会把它们当**矩阵**运算，直接报错或算错。

> 这是 MATLAB 向量化的基本规矩：**对向量/数组做加减乘除幂，全部加一个点**（`.*` `./` `.^`）。它等价于 Python numpy 里 `a_axis**2`、`.../...`（numpy 默认就是逐元素）。

## 三、看懂图：四个面板各看什么

- **(a)**：灰线是含噪信号（毛刺多），红线是滤波后（平滑），黑虚线是干净正弦（真值）。红线贴着黑虚线走，说明滤波成功「还原」了被噪声埋住的信号。
- **(b)**：三条滤波结果对比。α=0.05 的线最平滑但**滞后**（波形整体往右偏），α=0.6 的线紧跟噪声但毛刺残留多。**越平滑 → 越滞后**，这就是 trade-off。
- **(c)**：三条幅频曲线，α 越小曲线越早下坠（截止频率越低），滤掉的频率范围越宽。
- **(d)**：截止频率 `fc` 随 α 单调上升的曲线，红点标出 (b)(c) 用的三个 α 对应的 `fc`。

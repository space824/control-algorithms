## 一、先讲透：二阶低通的公式和它多出来的那个参数

二阶低通（连续域）：

```
H(s) = ωn² / (s² + (ωn/Q)·s + ωn²)
```

离散成 biquad 差分方程（双线性变换 + 预畸变之后）：

```
y[k] = b0·x[k] + b1·x[k-1] + b2·x[k-2] − a1·y[k-1] − a2·y[k-2]
```

比一阶多了三样东西：

| | 一阶 | 二阶 |
|---|---|---|
| 参数 | α（或 fc） | fc + **Q** |
| 系数 | 1 个 b、1 个 a | 3 个 b、2 个 a（a0 归一化掉） |
| 状态 | y[k-1] | x[k-1]、x[k-2]、y[k-1]、y[k-2] |
| 斜率 | −20 dB/十倍频 | **−40 dB/十倍频** |

**Q = 1/√2 ≈ 0.7071 就是巴特沃斯**：通带最平坦、−3dB 点正好落在 ωn、阶跃超调正好 4.32%。

## 二、为什么这么写（逐段）

### 1. 为什么二阶还是能用 `filter()` 一行搞定

```matlab
y2 = filter(b, a, x_noisy);
```

Day 3 里一阶写的是 `filter(alpha, [1 -(1-alpha)], x)`，今天换成 `filter(b, a, x)`——**函数没变，只是 b、a 变长了**。

`filter(b, a, x)` 解的就是这个通用差分方程：

```
a(1)·y[k] = b(1)·x[k] + b(2)·x[k-1] + b(3)·x[k-2]
                          − a(2)·y[k-1] − a(3)·y[k-2]
```

因为 `a(1) = 1`（我们已经归一化过），两边除以 a(1) 就是前面那条递推式。所以 `a = [1, a1, a2]` 里，**`a1`、`a2` 的正负号和差分方程里完全一致**（本例 `a1 = −1.6849`）。

> 注意那个负号：`a1` 是负数，`filter` 里又是 `− a(2)·y[k-1]`，两个负号抵消成 `+1.6849·y[k-1]`。少写一个负号，滤波器就变成正反馈、直接发散。这是 biquad 最常见的抄错点。

### 2. 为什么手算系数、不用 `butter()`

MATLAB 有现成的：

```matlab
[b, a] = butter(2, fc/(Fs/2));   % 也能给出二阶巴特沃斯
```

但脚本里没这么写，而是手推了一遍：

```matlab
w0    = 2*pi*fc*dt;
alpha = sin(w0)/(2*Q);
b = [(1-cos(w0))/2/a0, (1-cos(w0))/a0, (1-cos(w0))/2/a0];
a = [1, -2*cos(w0)/a0, (1-alpha)/a0];
```

**为什么这么写**：

1. **和 Python 版一一对应**——`SecondOrderLowPass.from_cutoff()` 用的是同一组闭式，两边结果能逐位对上，方便互相验证；
2. `butter()` 的 `Wn` 是**归一化频率** `fc/(Fs/2)`，用错很容易把 fc 填成 Hz 导致设计出来的滤波器完全不对；
3. 手算一遍，你才知道「Q 在哪一步进公式」——就是 `alpha = sin(w0)/(2Q)` 这一行。想改成临界阻尼，把这个 `Q` 换成 0.5 就行。

> 等第 3 条理由变成"我已经熟了"，再回去用 `butter()` 提速，那时它才是工具而不是黑箱。

### 3. 为什么 (d) 图要算「相位延迟」

```matlab
z_sig = exp(-1j*2*pi*f_sig*dt);
H     = (b(1) + b(2)*z_sig + b(3)*z_sig^2) / ...
        (a(1) + a(2)*z_sig + a(3)*z_sig^2);
d1    = -angle(H)/(2*pi*f_sig)*1000;      % 毫秒
```

频率响应就是让 `z = e^{jω}` 代进传递函数。这里 `z_sig = e^{-jω_sig}`（z⁻¹ 的形式），代进去得到一个复数：

- `abs(H)` = 该频率的**幅度增益**（衰减多少）；
- `angle(H)` = 该频率的**相位**（滞后多少）。

相位是负的（滞后），取负号再除以角频率 `ω = 2π·f`，就得到**等效时间延迟**。本课数字：一阶 3.98 ms、二阶 6.29 ms。

> **为什么用相位延迟而不是"看波形错开多少"**：波形错开只能定性；`−φ/ω` 是一个能进表格的数，还能直接喂给 (d) 图当横轴。

### 4. 为什么 `noisegain` 要写成 `sqrt(mean(abs(H).^2))`

```matlab
w   = linspace(0, pi, 4096);
ejw = exp(-1j*w);
num = b(1) + b(2)*ejw + b(3)*ejw.^2;
den = a(1) + a(2)*ejw + a(3)*ejw.^2;
ng  = sqrt(mean(abs(num./den).^2));
```

白噪声的功率在 `[0, π]`（即 0 ~ 奈奎斯特）上均匀分布。通过滤波器后，输出功率等于**滤波器在这段频率上的平均功率增益**：

```
输出方差 = 输入方差 × mean(|H|²)
```

所以 `sqrt(mean(|H|²))` 就是**噪声标准差的放大倍数**。本课：一阶 0.3336、二阶 0.2808。

> 这个数为什么关键：它把"二阶是不是更干净"从"看图感觉"变成"两个可以比大小的数"。而且它揭示了一个反直觉结论——**白噪声下两者的差只有 1.5 dB**，远小于"斜率翻倍"给人的印象。

### 5. 为什么 (d) 图里白噪声和干扰各画两条线

因为"谁的噪声抑制更好"这个问题，**答案取决于噪声长什么样**：

- **白噪声**：两条虚线几乎重合 → 阶数换不来好处（等效噪声带宽只与延迟成反比，与阶数无关）；
- **120 Hz 窄带干扰**：两条实线拉得很开 → 二阶明显更优（斜率翻倍，离 fc 越远处差距越大）。

如果把两种噪声混在一张图里只画两条线，结论就会被稀释成"差不多"。**分开画，才看得见真正的适用边界。**

### 6. 为什么把 `design2`、`design1`、`noisegain` 放在文件末尾做局部函数

```matlab
function [b, a] = design2(fc, dt, Q)
    ...
end
```

R2016b 之后，**脚本文件末尾可以定义局部函数**。好处：

- 同一段系数计算要复用多次（阶跃那一段用 `dt_s`、扫描 fc 那段用 80 次），写成函数避免复制粘贴；
- 函数名带语义（`design2` = 设计二阶），比一堆内联代码好读；
- 与 Python 版的"类方法 + 辅助函数"结构对应，两边对照着看很顺。

## 三、看懂图：四个面板各看什么

- **(a)**：橙（一阶）和蓝（二阶）几乎重合——RMSE 0.1448 vs 0.1449。**这张图最大的信息量就是"看不出区别"**：同 fc、白噪声下，二阶并不更干净。
- **(b)**：橙色单调爬到 1（无超调），蓝色冲到 1.0432 再回落（4.32% 超调），且前 10 ms 明显更低（延迟更大）。
- **(c)**：两条曲线在 fc=35.7 Hz 处同时穿过 −3 dB，之后一个 −20 dB/dec、一个 −40 dB/dec。红色竖线标出 120 Hz 干扰位置，正好落在两条线差距最大的地方。
- **(d)**：横轴延迟、纵轴残余噪声。**虚线重合**（白噪声打平）、**实线分开**（窄带干扰二阶赢）——一张图回答"到底该用几阶"。

## 四、Python 与 MATLAB 的对应关系

| Python | MATLAB |
|---|---|
| `SecondOrderLowPass.from_cutoff(fc, dt)` | `design2(fc, dt, Q)` |
| `FirstOrderLowPass.from_cutoff(fc, dt)` | `design1(fc, dt)` |
| `lp.update(x)` 逐拍循环 | `filter(b, a, x)` 一次性算完 |
| `response(coeffs, dt, f)` | `freqz(b, a, N, Fs)` |
| `noise_gain(coeffs, dt)` | `noisegain(b, a)` |
| `phase_delay_ms(coeffs, dt, f_sig)` | `-angle(H)/(2*pi*f_sig)*1000` |

**唯一的实质差别**：Python 版手写 `update()` 循环是为了看清"一拍一拍怎么递推"；MATLAB 版用 `filter()` 一行算完是因为**算法已经懂了，接下来要提效率**。这两种写法没有高下，是学习的不同阶段。

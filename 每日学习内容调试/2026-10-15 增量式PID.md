## 0. 今天要解决的新问题

Day 1 的位置式 PID 有两个**天生缺陷**：

1. **积分饱和**：积分累加器会无限累积，输出被限幅后仍然在涨，松开后造成超调。
2. **微分冲击**：设定值阶跃的瞬间，微分项 `de/dt` 会产生一个巨大的瞬时尖峰。

**增量式 PID 就是为了根治这两个问题而生的。** 今天就是用代码和图像，把这「根治」的过程看清楚。

## 1. 增量式 PID 是什么（核心公式推导）

### 1.1 思想：只输出「变化量」

回顾位置式，它直接输出**绝对控制量** u[k]。增量式换了个思路：

```
只算出"这一步控制量要变多少" Δu[k]，再叠加到上一次输出上：
    u[k] = u[k-1] + Δu[k]
```

这就是名字「增量式」的由来——输出的是**增量（increment）**，不是绝对量。它也叫「**速度形式**」，因为 Δu 本质上就是 u 的变化速度。

### 1.2 递推公式是怎么推出来的（对位置式做一阶差分）

先写出位置式的离散公式（Day 1 已讲）：

```
u[k] = Kp·e[k] + Ki·I[k] + Kd·(e[k] − e[k-1]) / dt
其中 I[k] = I[k-1] + e[k]·dt   （积分累加器）
```

现在做「**一阶差分**」：用 u[k] 减去 u[k-1]，让积分累加器 I 被消掉：

```
u[k-1] = Kp·e[k-1] + Ki·I[k-1] + Kd·(e[k-1] − e[k-2]) / dt

Δu[k] = u[k] − u[k-1]
      = Kp·(e[k] − e[k-1])
      + Ki·(I[k] − I[k-1])
      + Kd·[(e[k] − e[k-1]) − (e[k-1] − e[k-2])] / dt
```

关键一步：因为 `I[k] − I[k-1] = e[k]·dt`，代入并整理：

```
Δu[k] = Kp·(e[k] − e[k-1])  +  Ki·dt·e[k]  +  Kd·(e[k] − 2e[k-1] + e[k-2]) / dt
```

把采样周期 dt 吸收进增益里（记 `Ki' = Ki·dt`，`Kd' = Kd/dt`），就得到代码里的最终形式：

```
Δu[k] = Kp·(e[k] − e[k-1])  +  Ki'·e[k]  +  Kd'·(e[k] − 2e[k-1] + e[k-2])
```

### 1.3 这个公式最深刻的结论

**积分累加器 I 消失了！** 整条公式里只剩 `e[k]`、`e[k-1]`、`e[k-2]` 三个当前/最近的误差，**没有任何「把所有历史误差加起来」的项**。

- 位置式要记住「过去所有误差之和」（一个不断增长的 I）。
- 增量式只需要记住「最近两个误差」。

这就是后面「天然抗积分饱和」的根源——没有会无限累积的东西了。

### 1.4 两个新术语

- **一阶差分**：`e[k] − e[k-1]`（误差这一步变了多少）。
- **二阶差分**：`(e[k] − e[k-1]) − (e[k-1] − e[k-2]) = e[k] − 2e[k-1] + e[k-2]`，即「变化量的变化量」。增量式里的微分项作用在误差的**二阶差分**上，量级天然比位置式的一阶差分（除以 dt）小得多。

## 2. 区别一：积分饱和 —— 增量式天然免疫

### 2.1 位置式为什么会饱和（复习+加深）

位置式有个独立积分累加器 `I[k]`。当输出 u 被限幅夹住（比如阀门最多开 100%）时，
误差还一直是正的，I 就一直在涨。等设定值降下来、需要收油门了，I 已经涨到天上，
要花很久才能「吐」回来——表现为严重的超调和长时间振荡。

Day 1 的位置式靠「条件积分」手动打补丁才压住它。

### 2.2 增量式为什么天然免疫

增量式**唯一的记忆是上一次输出 `u[k-1]`**：

```
u[k] = u[k-1] + Δu[k]
```

而 `u[k-1]` 是被输出限幅夹住的（不会超过上限）。所以增量式即便饱和，也只是 u 停在
上限值，**内部没有任何东西在偷偷继续累积**。一旦误差反号，Δu 马上变负，u 立即往下走，
干净利落，不留「历史欠账」。

> 一句话：位置式饱和的是「积分」，增量式饱和的只是「输出」；输出被夹住就夹住了，
> 没有第二个会偷偷涨的量。

## 3. 常见的误读：突变响应 —— 增量式**并不能**消除「微分冲击」

### 3.1 什么是微分冲击（derivative kick）

位置式的微分项是：

```
D = Kd · (e[k] − e[k-1]) / dt
```

当设定值在某一刻**阶跃**（从 0 突然跳到 1），误差 e 也瞬间从 0 跳到 1，于是
`e[k] − e[k-1]` 在这一步是个巨大的值，再除以很小的 dt，微分项就变成了一个**瞬时尖峰**。
这个尖峰作用在控制量上，会把执行器猛地顶一下——这就是「微分冲击」。

### 3.2 增量式并没有躲开，因为两者本来就是同一个式子

增量式是位置式做一阶差分得来的。差分之后，`Kd·Δe/dt` 这一项并不会凭空变小，
它只是变成了误差的**二阶差分**：

```
Kd · (e[k] − 2e[k-1] + e[k-2]) / dt
```

注意分母上的 dt **还在**。很多教材省掉它，是因为把 Kd 定义成了已经吸收周期的系数
（Kd = Kp·Td/T）。可一旦你把位置式那组 kp/ki/kd 直接搬过来又省掉 dt，
微分增益就等于放大了 1/dt = 100 倍——那不是「更平滑」，那是发散。

配平之后，两种实现在代数上**完全等价**：Day 2 的例子实测，两者 t=0 第一拍的控制量
都是 **33.02**，全程 max abs(u) 也都是 33.02，曲线逐点重合（误差 7e-15）。
所以「位置式有尖峰、增量式平滑」这个说法不成立。

**微分冲击的真正解法是「微分先行」**：把 D 项从误差 e 换到测量值 y 上——

```
D[k] = −Kd · (y[k] − y[k-1]) / dt
```

设定值阶跃时 y 是连续的，D 项不跳变，尖峰就没了。P1 直流电机项目里的 STM32 代码
用的正是这个办法。

## 4. 新知识点：二阶系统（今天的新被控对象）

Day 1 的是一阶系统 `dx/dt = −a·x + b·u`，只会「慢慢逼近」，**不会振荡**。今天引入二阶系统：

```
x'' + 2·ζ·ωn·x' + ωn²·x = b·u
```

### 4.1 三个参数的含义

| 参数 | 符号 | 含义 |
|------|------|------|
| 阻尼比 | ζ (zeta) | 决定「会不会振荡」。ζ<1 欠阻尼→振荡；ζ=1 临界；ζ>1 过阻尼→不振荡 |
| 自然频率 | ωn (wn) | 决定振荡快慢、响应节奏 |
| 输入增益 | b | 同 Day 1，输入放大倍数 |

本例取 `ζ=0.3`（欠阻尼），所以系统会**来回振荡**。

### 4.2 为什么 Day 2 要用二阶系统

- Day 1 说过「微分项 D 对一阶系统收益很小」。**D 的价值恰恰体现在能振荡的系统上**——它提供的「刹车力」正好用来压制振荡。
- 「微分冲击」的尖峰本身是「对误差求导」造成的，和对象阶次关系不大；但二阶系统能让
  「D 的刹车作用」和这份尖峰同时显形——一阶系统单调爬升，看不出 D 有什么用。

所以今天换对象，是为了让「D 的作用」**看得见**；至于「微分冲击」，它不是增量式能消除
的东西，而是需要靠「微分先行」去消除。

### 4.3 代码里怎么离散（把二阶方程拆成两个一阶）

二阶方程含 `x''`，不方便直接递推。代码引入速度 `v = x'`，把二阶拆成两个一阶：

```python
self.v += self.dt * (-2 * self.zeta * self.wn * self.v
                     - self.wn ** 2 * self.x
                     + self.b * u)     # 先更新速度 v（加速度 = 上式的括号）
self.x += self.dt * self.v             # 再更新位置 x（速度 = v）
```

即：先算加速度 → 更新速度 v → 再更新位置 x，和物理里「位置-速度-加速度」一致。

## 5. 新知识点：NaivePositionPID（故意不抗饱和的对照版）

代码里多了一个类 `NaivePositionPID`，注意它和 Day 1 的 `PositionPID` **不一样**：

| | Day 1 `PositionPID` | Day 2 `NaivePositionPID` |
|---|---|---|
| 抗积分饱和 | ✅ 条件积分（未饱和才累积） | ❌ 无任何处理 |
| 积分项 | 输出未限幅时才累积 | `self._integral += e*dt` 无条件累积 |
| 用途 | 生产用 | **故意留个 bug，专门用来演示积分饱和怎么产生** |

```python
def update(self, setpoint, measurement):
    e = setpoint - measurement
    self._integral += e * self.dt   # 无条件累积，即使饱和了也照样涨
    ...
```

它存在的意义：作为「坏的对照组」，和增量式放在同一张图里，让「积分饱和的坏处」肉眼可见。

## 6. 代码实现（逐段）

### 6.1 增量式控制器：`src/pid/incremental_pid.py`

状态只存三个东西（没有积分累加器）：

```python
def reset(self):
    self._e_prev = 0.0    # e[k-1]
    self._e_prev2 = 0.0   # e[k-2]
    self._last_output = 0.0   # u[k-1]，唯一的"记忆"
```

核心 update：

```python
def update(self, setpoint, measurement):
    e = setpoint - measurement

    # 增量式核心递推式（对应 1.2 节的最终公式）
    du = (self.kp * (e - self._e_prev)
          + self.ki * e
          + self.kd * (e - 2.0 * self._e_prev + self._e_prev2))

    u = self._last_output + du          # u[k] = u[k-1] + Δu[k]

    # 输出限幅：夹住 u 就等于夹住了"记忆"，所以天然抗积分饱和
    if self.hi is not None and u > self.hi:
        u = self.hi
    elif self.lo is not None and u < self.lo:
        u = self.lo

        这是一个输出限幅逻辑：

如果输出 u 超过上限 self.hi，就把 u 钳位到 self.hi
如果输出 u 低于下限 self.lo，就把 u 钳位到 self.lo

看起来很简单，就是防止输出超出执行机构的物理范围（比如阀门不能开超过100%，电机不能给超过额定电压）。

    # 移位更新：把历史误差往后挪一格
    self._e_prev2 = self._e_prev
    self._e_prev = e
    self._last_output = u
    return u
```

注意最后三行「移位」：`e_prev2` 接替 `e_prev`，`e_prev` 接替 `e`。这正是「只保留最近两个误差」的机制。

### 6.2 变设定值的仿真：`examples/day2_incremental_pid.py`

Day 1 的设定值全程恒定，今天需要「先 3、5 秒后再降 0.5」，所以多了一个按时间取设定值的函数：

```python
def current_setpoint(t, setpoint_seq):
    sp = setpoint_seq[0][1]
    for t_start, sp_val in setpoint_seq:
        if t >= t_start:
            sp = sp_val
    return sp

# 用法：[(0.0, 3.0), (5.0, 0.5)] 表示 0~5s 设定值=3，5s 之后=0.5
```

主循环里每一步都用 `current_setpoint(t[k], setpoint_seq)` 拿到「当前时刻的设定值」，其余和 Day 1 一样。

### 6.3 两组对比共用同一组增益

```python
gains = dict(kp=3.0, ki=2.0, kd=0.3)   # 位置式、增量式用完全相同的 Kp/Ki/Kd
```

**这样对比才公平**——同样的参数，只换 PID 结构，才能把「结构的差异」孤立出来。

## 7. 图的对应与解释（四张子图）

运行 `python examples/day2_incremental_pid.py` 生成 `docs/images/day2_incremental_pid.png`，
是 2×2 的四张图，分两组对比。

### 第一组：(a) 和 (b) —— 二阶系统，看清「微分冲击」和「两者等价」

设定值在 t=0 从 0 阶跃到 1，被控对象是二阶欠阻尼系统。

**图 (a)：输出 y 的阶跃响应**

- 黑色虚线 = 设定值 r=1。
- 两条实线 = 位置式（positional）和增量式（incremental）的输出 y。
- 现象：**两条线完全重合**。增益配平之后，增量式就是位置式的差分形式，结果必然一样。

**图 (b)：控制量 u 的曲线（关键！）**

- 现象：**t=0 处有一根竖直尖峰，纵轴冲到 33**——设定值一阶跃，`Δe/dt` 瞬间爆炸。
- 这根尖峰就是第 3 节的「derivative kick」。**两条曲线在尖峰上也重合**，看不出谁「更刺」
  ——这不是画图错了，而是两者真的等价。
- 结论：**微分冲击两种形式都躲不掉**；要消除它，得改用「微分先行」。

### 第二组：(c) 和 (d) —— 一阶系统 + 输出限幅，演示「积分饱和」

限幅 `(0, 1)`，设定值先要 3（远超系统能力，逼控制量饱和），5 秒后又降到 0.5。

**图 (c)：输出 y 的响应**

- 现象：5 秒松开限幅后，**位置式（无抗饱和）先冲过头再振荡半天才回到 0.5**；增量式几乎无超调，直接稳稳落回 0.5。
- 原因：位置式的积分在饱和期间一直在偷偷涨，松开后「历史欠账」要慢慢还；增量式没这个欠账。

**图 (d)：控制量 u 的曲线**

- 现象：两条在饱和期间都停在 u=1（上限），但**位置式在内部积累了巨大积分**（表面看 u 没动，内里已经满负荷）；增量式 u 被夹住就是夹住，一松开立即响应。
- 结论：**增量式没有隐藏的「积分欠账」，抗饱和是结构上天然保证的**，不需要额外写抗饱和代码。

### 小结：四张图对应两句话

| 图 | 现象 | 说明 |
|---|---|---|
| (a)(b) | 两条曲线完全重合 | **增量式不平滑掉微分冲击，二者等价** |
| (c)(d) | 位置式松开限幅后超调 | **增量式天然抗积分饱和** |

## 8. 今日要点

1. **增量式输出 Δu，叠加到 u[k-1]**：`u[k] = u[k-1] + Δu[k]`。
2. **递推公式由位置式做一阶差分得到**，积分累加器被消掉，只剩 `e[k-1]`、`e[k-2]` 两个历史误差。
3. **天然抗积分饱和**：唯一记忆 `u[k-1]` 被限幅夹住，没有会无限累积的量。
4. **「无微分冲击」是误读**：配平后增量式与位置式等价，尖峰一样大；要消除得用微分先行（对测量值求导）。
5. **二阶系统 `x'' + 2ζωn x' + ωn² x = b·u`**：ζ<1 欠阻尼会振荡，D 的价值在这种系统上才明显。
6. **位置式的代价**：需要绝对量时得额外累加；增量式的代价：要保留两个历史误差，且输出是相对的。

## 9. 位置式 vs 增量式 一句话对比（速查）

| 维度 | 位置式 | 增量式 |
|------|--------|--------|
| 输出 | 绝对量 u[k] | 增量 Δu，需叠加 |
| 积分 | 独立累加器，会饱和（要抗饱和代码） | 无累加器，天然抗饱和 |
| 设定值突变 | 有微分冲击 | 同样有（两者等价） |
| 需要存储 | 积分和 + 上次误差 | 最近两个误差 |
| 适用 | 需绝对量（阀门开度、占空比） | 步进电机、需无扰动切换的场合 |

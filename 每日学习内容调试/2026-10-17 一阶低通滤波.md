## 0. 今天要解决的新问题：怎么把噪声从信号里抠出来

Day 1、Day 2 一直在和「控制误差」打交道。今天换一个几乎每个工程都会遇到的问题：**测量信号里混着噪声**。

比如陀螺仪、加速度计、编码器、温度探头……读回来的原始数据往往是「真实信号 + 一堆高频毛刺」：

```
raw[k] = 真实值[k] + noise[k]
```

噪声频率通常远高于真实信号，所以只要用一个**只放行低频、拦住高频**的东西过一遍，就能把毛刺滤掉。这个东西就叫**低通滤波器**。今天从最简单、最经典的一阶 RC 低通入手。

---

## 1. 一阶低通滤波是什么（从 RC 电路到递推公式）

### 1.1 先看连续时间：一阶 RC 电路

一个电阻 R 和一个电容 C 串联，输入电压 x(t)、电容两端输出电压 y(t)，就是最经典的低通电路。它的传递函数是：

```
H(s) = Y(s) / X(s) = 1 / (1 + s·τ)   ，时间常数 τ = R·C
```

它的频率特性（把 s 换成 j·ω）：

```
|H(jω)| = 1 / sqrt(1 + (ω·τ)²)
```

- 低频（ω 很小）：|H| ≈ 1，信号几乎无损通过。
- 高频（ω 很大）：|H| ≈ 1/(ω·τ)，衰减得越来越厉害。
- **-3dB 截止角频率 ωc = 1/τ**，对应截止频率 `fc = 1 / (2π·R·C)`：这个频率以上的分量被「拦腰砍」。

一句话：**RC 电路天然就是个低通滤波器**，转折点由时间常数 τ 决定。

### 1.2 离散化：把连续方程变成一行递推

连续方程（时域）是：

```
τ · dy/dt + y = x
```

把微分 `dy/dt` 用「后向差分」近似：`dy/dt ≈ (y[k] − y[k-1]) / dt`，代入：

```
τ · (y[k] − y[k-1]) / dt + y[k] = x[k]
```

整理成 y[k] 的表达式：

```
(τ + dt) · y[k] = τ · y[k-1] + dt · x[k]

y[k] = dt/(dt+τ) · x[k] + τ/(dt+τ) · y[k-1]
```

令

```
α = dt / (dt + τ) = dt / (dt + RC)
```

那么 `τ/(dt+τ) = 1 − α`，于是得到那条著名的递推式：

```
y[k] = α·x[k] + (1-α)·y[k-1]
```

这就是**一阶低通滤波的离散形式**，也叫**指数移动平均（EMA / Exponential Moving Average）**。它只需要记住「上一拍的输出 y[k-1]」一个数，就能一拍拍递推下去，硬件上实现成本极低。

### 1.3 α 到底在说什么

拆开读这行公式：

```
y[k] = α · x[k]   +   (1-α) · y[k-1]
        ↑新样本贡献        ↑历史输出保留
```

- **α 是新样本 x[k] 的话语权**，`1-α` 是历史输出 y[k-1] 的话语权，两者加起来永远是 1。
- α → 1：几乎完全相信新样本，`y[k] ≈ x[k]`，等于**没滤波**。
- α → 0：几乎完全相信历史，输出几乎不变，等于**滤过头**（信号都跟着被抹平）。

所以 α 是「**信新还是信旧**」的权衡旋钮，范围 (0, 1]。

---

## 2. 调 α 就是在调截止频率（本课第二重点）

### 2.1 时间常数 τ 与 α 的换算

从 1.2 节的推导反解：

```
α = dt / (dt + τ)   ⟺   τ = dt · (1-α) / α
```

- α 越大 → τ 越小 → 滤波器「惯性」越小、响应越快。
- α 越小 → τ 越大 → 惯性越大、越「迟钝」。

### 2.2 截止频率公式

连续域的截止频率是 `fc = 1/(2π·τ)`，把 τ 代进去：

```
fc ≈ α / (2π·dt)          （小 α 时的近似式，α<<1）
```

更精确的**离散域**公式（考虑离散化的影响，代码里用的就是这个）：

```
cos(2π·fc·dt) = (2 − 2α − α²) / (2(1−α))
```

反解出 fc 就是图 (d) 画的那条曲线。两个式子在小 α 时几乎重合。

### 2.3 结论（务必记住这条主线）

| α 变化 | 截止频率 fc | 对信号的作用 |
|--------|-------------|--------------|
| **α ↑ 增大** | fc ↑ 升高 | 放行更多高频 → 噪但**响应快、延迟小声滤得少，** |
| **α ↓ 减小** | fc ↓ 降低 | 压住更多高频 → 噪声滤得干净，但**延迟大** |

用本课参数（dt = 1ms）算出来的三档：

| α | fc（离散精确值） |
|---|------------------|
| 0.05 | ≈ 8.2 Hz |
| 0.2  | ≈ 35.7 Hz |
| 0.6  | ≈ 157.3 Hz |

> 这就是「**调 α 看截止频率变化**」的完整含义：α 不是一个可有可无的常数，它直接决定滤波器把「分界线」划在多少 Hz。

## 3. 核心权衡：滤波强度 vs 延迟（今天最重要的一句话）

低通滤波从来不是免费的。信号和噪声都在「频谱」上，滤波器只能按频率一刀切：

- 想多滤噪声 → 把 fc 压低 → 但真实信号的高频成分（比如正弦的边沿、快变的细节）也会被一起削掉，而且输出会**滞后**。
- 想少滞后 → 把 fc 抬高 → 但噪声也跟着漏进来。

**α 就是在这两者之间找平衡的那个旋钮。** 工程上先看「噪声频率在哪、信号频率在哪」，把 fc 夹在两者之间，再微调。

一个重要的数量关系：相位延迟（滞后）在频率 f 处约为

```
φ(f) = −arctan(f / fc)
```

f 越接近 fc，滞后越大；信号频率远低于 fc 时，滞后可以忽略。这解释了图 (a)(b) 里 α 越小、波形越往右「错开」的现象。

## 4. 代码实现（逐段）

### 4.1 滤波器核心类：`src/filter/lowpass.py`

类里只有一个状态——上一拍输出 `self._y`，这就是「滤波器唯一的记忆」：

```python
class FirstOrderLowPass:
    def __init__(self, alpha=0.2, y0=0.0):
        self.alpha = float(alpha)
        self.reset(y0)

    def reset(self, y0=0.0):
        self._y = float(y0)   # y[k-1]，唯一的记忆

    def update(self, x):
        # y[k] = α·x[k] + (1-α)·y[k-1]
        self._y = self.alpha * x + (1.0 - self.alpha) * self._y
        return self._y
```

整个滤波器就一行核心代码 `self.alpha * x + (1 - alpha) * self._y`，和 Day 1/2 的 PID 相比轻量得多——因为滤波器不做「控制」，只做「加权平均」。

### 4.2 由截止频率反推 α：`from_cutoff`

实际工程里，我们通常先知道「想把 fc 设成多少 Hz」，再反推 α，而不是拍脑袋填 α。类里提供了这个反向构造方法：

```python
@classmethod
def from_cutoff(cls, cutoff_hz, dt):
    c = math.cos(2.0 * math.pi * cutoff_hz * dt)
    k = 1.0 - c
    alpha = -k + math.sqrt(k * (k + 2.0))   # 离散精确解，而非近似
    return cls(alpha=alpha)
```

用法：

```python
lp = FirstOrderLowPass.from_cutoff(cutoff_hz=10.0, dt=0.001)  # 想要 10Hz 截止
```

（配套的近似式是 `alpha ≈ 2π·fc·dt`，fc 远低于采样率时两者几乎一样，代码用精确式保证 fc 靠近奈奎斯特频率时也不离谱。）

### 4.3 示例脚本里的两个数学函数：`examples/day3_lowpass_filter.py`

```python
def magnitude_response(alpha, dt, f):
    """|H(e^{jω})|，ω = 2π·f·dt，用于画幅频响应。"""
    w = 2.0 * np.pi * np.asarray(f) * dt
    denom = np.sqrt(1.0 - 2.0 * (1.0 - alpha) * np.cos(w) + (1.0 - alpha) ** 2)
    return alpha / denom

def cutoff_freq(alpha, dt):
    """由 α、dt 计算离散域精确的 -3dB 截止频率。"""
    c = (2.0 - 2.0 * alpha - alpha ** 2) / (2.0 * (1.0 - alpha))
    wc = np.arccos(c)
    return wc / (2.0 * np.pi * dt)
```

这两个函数不是滤波器本身，而是「**给滤波器做体检**」用的：把 α 翻译成频域里的曲线，好让我们看见截止频率在哪。

### 4.4 逐点滤波的辅助函数

滤波器是「一拍拍更新」的，所以要跑完整段信号，写个循环把它喂进去：

```python
def filter_signal(x, alpha, y0=0.0):
    lp = FirstOrderLowPass(alpha=alpha, y0=y0)
    y = np.empty_like(x, dtype=float)
    for k in range(len(x)):
        y[k] = lp.update(x[k])
    return y
```

### 4.5 信号生成（含噪正弦）

```python
dt = 0.001                     # 1kHz 采样
f_sig = 3.0                    # 3Hz 正弦
rng = np.random.default_rng(0) # 固定种子，图可复现
x_clean = np.sin(2*np.pi*f_sig*t)
noise = rng.normal(0.0, 0.4, size=n)   # 高斯白噪声，标准差 0.4
x_noisy = x_clean + noise
```

噪声标准差取 0.4（信号幅值才 1），噪声相当「浓」，这样滤波前后的反差才肉眼可见。

**图 (c)：幅频响应 |H(f)|**

- 三条曲线对应三个 α，横轴对数频率、纵轴 dB。
- 每条曲线在低频是 0dB（不衰减），高频往下掉。**掉到 −3dB（黑虚线）时的频率就是截止频率**，竖虚线标注了三档 fc：8.2 / 35.7 / 157.3 Hz。

**图 (d)：截止频率 fc 与 α 的关系曲线**

- 横轴 α、纵轴 fc，蓝线是 `fc(α)` 的理论曲线，红点是三个 α 的落点。
- 现象：**fc 随 α 单调上升**，且在小 α 区近似线性（对应 `fc≈α/(2π·dt)`），越大爬得越陡。这张图把「调 α = 调截止频率」画成了一目了然的函数关系。

## 6. 今日要点

1. **离散递推式**：`y[k] = α·x[k] + (1-α)·y[k-1]`，是 RC 低通用后向差分离散化而来，也叫指数移动平均。
2. **α 的含义**：新样本的话语权；`1-α` 是历史输出的话语权。α∈(0,1]。
3. **α 与时间常数**：`τ = dt·(1-α)/α`；α 越大惯性越小、响应越快。
4. **α 与截止频率**：近似 `fc ≈ α/(2π·dt)`，精确式 `cos(2π·fc·dt) = (2−2α−α²)/(2(1−α))`。**α 越大，fc 越高。**
5. **核心权衡**：α 小 → 滤得干净但延迟大；α 大 → 跟手但噪声残留。工程上把 fc 夹在信号频率和噪声频率之间。
6. **滞后规律**：相位延迟 `φ(f) ≈ −arctan(f/fc)`，信号频率越接近 fc，滞后越明显。
7. **代码极简**：滤波器只有一个状态 `y[k-1]`，核心只有一行加权平均；另配 `from_cutoff` 由目标截止频率反推 α。

## 7. 速查表：α 该怎么选

| 场景 | 建议 α / fc | 理由 |
|------|-------------|------|
| 信号很慢、噪声很强（如温度） | α 取小（fc 略高于信号频率） | 狠狠压噪声，延迟无所谓 |
| 需要实时跟手（如电机转速反馈） | α 取大（fc 远高于信号频率） | 减少滞后，容忍一点噪声 |
| 信号频率已知为 f0 | 先设 fc ≈ 3~10 × f0 | 信号无损通过，又留出压噪声的余地 |
| 不知道 α 该填多少 | 用 `from_cutoff(fc, dt)` 反推 | 直接按 Hz 思维设计，不拍脑袋 |

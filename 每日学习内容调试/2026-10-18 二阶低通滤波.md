## 0. 今天的新问题：一阶为什么不够用

Day 3 的一阶低通只有**一条 20 dB/十倍频**的衰减坡。这带来一个绕不过去的矛盾：

- 想把 3 Hz 正弦旁边的 120 Hz 干扰压下去 → 得把截止频率往低压；
- 一旦把截止频率往低压，3 Hz 信号本身也跟着滞后、衰减。

**一阶只有一个旋钮（α 或 fc），却要同时满足「别衰减信号」和「压住高频干扰」两件事**，坡太缓，两头顾不全。

二阶的思路：**不换截止频率，换坡的陡度**。把 20 dB/十倍频变成 40 dB/十倍频，让「fc 以上」掉得更狠，fc 以下的信号仍原样通过。

> 但今天最后会发现一个反直觉的结论：**在白噪声上，二阶几乎不赚**。真正的收益要看噪声是什么样的。这是本文档 §3 的核心。

## 1. 二阶低通是什么：从 H(s) 到两个关键参数

### 1.1 标准二阶形式

二阶低通（连续域）的标准写法：

```
H(s) = ωn² / (s² + (ωn/Q)·s + ωn²)
```

两个参数：

- **ωn**：自然角频率（rad/s），对应频率 `fn = ωn/2π`；
- **Q**：品质因数，控制"坡拐弯处的形状"。

分母是个二次式，所以极点有两个，这正是"二阶"的含义。

### 1.2 Q 到底在控制什么

Q 和教科书里常见的阻尼比 ζ 是同一件事，只是写法不同：

```
ζ = 1 / (2Q)        ⟺        Q = 1 / (2ζ)
```

三个取值区间：

| Q | ζ | 幅频曲线在 fc 附近 | 阶跃响应 |
|---|---|---|---|
| **> 0.7071** | < 0.707 | **鼓出一个峰**（谐振），峰值可能 > 0 dB | 超调明显、来回振 |
| **= 0.7071** | = 0.707 | 最平坦，无峰 | 超调 **4.32%**（实测一致） |
| **< 0.7071** | > 0.707 | 拐角变圆、过渡更缓 | 无超调，但更"肉" |

### 1.3 为什么偏偏是 0.7071（巴特沃斯）

巴特沃斯（Butterworth）的定义是：**通带内最大平坦**——幅频曲线在低频段尽可能贴住 0 dB，不鼓包、不塌陷。

数学上，这要求 `Q = 1/√2 ≈ 0.7071`。它还有两个好性质：

1. **−3 dB 点正好落在 ωn**：所以"截止频率 fc"和"自然频率 fn"在巴特沃斯里是同一个数，不用换算；
2. 高阶巴特沃斯可以级联得到，是工程上最常用的"标准型"。

> 记住这条：**巴特沃斯 = Q=0.7071 = 最平坦 = 截止点就是 wn = 阶跃超调 4.32%**。这四个说法是一件事。

## 2. 从 H(s) 到差分方程：双线性变换 + 预畸变

### 2.1 为什么一阶能用欧拉，二阶最好别用

Day 3 里一阶低通用后向欧拉离散（`dy/dt ≈ (y[k]−y[k-1])/dt`），效果不错。但同样的做法套到二阶上会出问题：

- 欧拉离散把 `s²` 展开成 `(1−z⁻¹)²/dt²`，**频率轴会被严重扭曲**，fc 越接近采样率越离谱；
- 甚至可能把离散后的极点推出单位圆（本该稳定的滤波器变得不稳定）。

所以在二阶上，标准做法换成**双线性变换（Tustin）**：它能保证「连续域稳定的，离散后一定稳定」，而且阶数不变。

### 2.2 双线性变换

```
s = (2/dt) · (z − 1)/(z + 1)
```

代进 H(s)，整理成 z⁻¹ 的多项式，就得到 biquad 系数。代价是**频率轴被"挤弯"**（warping）：越靠近奈奎斯特频率，映射越非线性。

### 2.3 预畸变（pre-warping）修正这个弯曲

我们希望数字滤波器的 −3 dB 点**精确**落在想要的 fc 上。做法是先把 fc 预畸变一次：

```
ωa = (2/dt) · tan(π·fc·dt)        ← 用这个 ωa 去设计连续域滤波器
```

这样经过双线性变换的"挤弯"之后，−3 dB 点正好回到 fc。

### 2.4 工程上直接用闭式（RBJ Cookbook）

上面的「双线性 + 预畸变」推完，可以整理成一组很短的闭式（本课代码用的就是它）：

```
w0    = 2π·fc·dt
alpha = sin(w0) / (2Q)

b0 = (1 − cos w0) / 2 / (1 + alpha)
b1 = (1 − cos w0)     / (1 + alpha)
b2 = b0
a1 = −2·cos(w0)       / (1 + alpha)
a2 = (1 − alpha)      / (1 + alpha)      ← 已归一化，a0 = 1
```

验算：`b0+b1+b2 = 2(1−cos w0)/(1+alpha)`，`1+a1+a2 = 2(1−cos w0)/(1+alpha)`，两者相等 →

```
直流增益 = (b0+b1+b2)/(1+a1+a2) = 1       ✓ 低频不衰减
```

代码里 `dc_gain` 属性就是查这个的，实测 `1.000000`。

**本课参数下的实际系数**（fc = 35.7 Hz，dt = 1 ms）：

```
b0 =  0.010824
b1 =  0.021647
b2 =  0.010824
a1 = −1.684889
a2 =  0.728184
```

看 `a1`、`a2`：两者都接近 ±1 但没越过，极点稳稳在单位圆内——这就是"离散化的稳定性"落到纸面上的样子。

### 2.5 差分方程与四个状态

```
y[k] = b0·x[k] + b1·x[k−1] + b2·x[k−2] − a1·y[k−1] − a2·y[k−2]
```

对比 Day 3 的一阶：

| | 一阶 | 二阶 |
|---|---|---|
| 递推式 | `y[k] = α·x[k] + (1−α)·y[k−1]` | 上面这一行 |
| 需要记住的状态 | **1 个**（y[k−1]） | **4 个**（x[k−1]、x[k−2]、y[k−1]、y[k−2]） |
| 内存（float） | 4 字节 | 16 字节 |

「更陡的坡」不是免费的，代价就是**记忆翻四倍**。

## 3. 与一阶正面比较（本课核心，全部用实测数据）

统一条件：fc = 35.7 Hz（就是 Day 3 里 α = 0.2 对应的截止频率）、采样 1 kHz、信号 3 Hz 正弦、白噪声 σ = 0.4、干扰 120 Hz。

### 3.1 总表

| 指标 | 含噪输入 | 一阶 | 二阶 | 谁赢 |
|---|---|---|---|---|
| RMSE（对真值） | 0.3912 | **0.1448** | 0.1449 | **平** |
| 白噪声放大倍数 | 1.0000 | 0.3336（−9.5 dB） | **0.2808（−11.0 dB）** | 二阶，但只赢 1.5 dB |
| 延迟 @3 Hz | 0 | **3.98 ms** | 6.29 ms | **一阶** |
| 120 Hz 干扰衰减 | 0 dB | −10.7 dB | **−21.9 dB** | **二阶赢 11.2 dB** |
| 阶跃超调 | — | **0.00%** | 4.32% | **一阶** |
| 阶跃上升（10→90%） | — | 9.80 ms | **9.60 ms** | 基本平 |
| 阶跃调节（±2%） | — | **17.40 ms** | 26.60 ms | **一阶** |

**怎么读这张表**：二阶在「120 Hz 干扰」上赢得非常漂亮（11.2 dB ≈ 幅度压到 1/3.6），但在「白噪声」和「延迟」上几乎没赚甚至亏。

### 3.2 反直觉结论一：白噪声下，二阶几乎不赚

这是今天最值得记住的一条。**滤波器的等效噪声带宽**（白噪声通过后还剩下多少功率）与**低频群延迟**之间的关系是：

```
白噪声输出方差 ∝ 1 / (4τ)          τ = 低频群延迟
而 τ 为：一阶 τ = 1/(2πfc)，二阶巴特沃斯 τ = ζ/(πfc)
```

把 τ 代回去：

- 一阶：`∫|H|²df = (π/2)fc`，代入 `fc = 1/(2πτ)` → `1/(4τ)`
- 二阶：`∫|H|²df = (π/4)·fc/ζ`，代入 `fc = ζ/(πτ)` → 也是 `1/(4τ)`

**两者完全一样。** 也就是说：**同样的延迟，换来同样的白噪声抑制，跟阶数无关。**

本课数字验证：一阶延迟 3.98 ms、噪声放大 0.3336；二阶延迟 6.29 ms、噪声放大 0.2808。按 1/(4τ) 换算，二阶在 3.98 ms 处的等效噪声应当与一阶相同——图 (d) 里那两条**几乎重合的虚线**就是这件事。

> 这就是所谓"没有免费的午餐"：**白噪声只认延迟，不认阶数**。想靠"升级到二阶"来压白噪声，方向就是错的。

### 3.3 反直觉结论二：二阶的主场在窄带干扰

如果噪声不是铺满整个频谱的白噪声，而是**集中在某个频率**（PWM 纹波、电机换向、结构谐振、50/100 Hz 工频，全都是这种），结论立刻反过来：

120 Hz 处，两个滤波器的衰减差：

```
一阶：−10.7 dB      （幅度 0.291）
二阶：−21.9 dB      （幅度 0.080）      → 差 11.2 dB，幅度压到 1/3.6
```

原因就是斜率：从 35.7 Hz 到 120 Hz 是 1.75 个十倍频多一点，`20 dB/dec × 1.75 ≈ 35 dB` 的斜率差在这一点上结算成 11 dB。

**离 fc 越远，差距越大**：fc 的 2 / 4 / 8 倍处，一阶与二阶的衰减差大约是 5 / 12 / 18 dB。

### 3.4 代价：4.32% 超调和更长的调节时间

巴特沃斯的 Q = 0.7071 略欠阻尼，所以阶跃响应一定超调。理论值：

```
超调 = exp(−πζ/√(1−ζ²)) = exp(−π) = 4.32%          ← 与实测 4.32% 完全吻合
```

如果超调不可接受，就把 Q 调到 0.5 附近（临界阻尼），代价是过渡带变缓——again，没有免费午餐。

### 3.5 所以到底回答那两个问题

- **谁的噪声抑制更好？** 看噪声类型。白噪声：**打平**；窄带/高频集中干扰：**二阶明显更好**（本课 11.2 dB）。
- **谁的延迟更大？** **二阶**。同样 fc 下多约 1.6 倍（6.29 ms vs 3.98 ms），而且这个多出来的延迟正是它"更陡"的代价。

## 4. 代码实现（逐段）

### 4.1 二阶滤波器核心类：`src/filter/second_order.py`

类里存四个状态，`update()` 就是照着差分方程写一遍：

```python
def update(self, x):
    x = float(x)
    y = (self.b0 * x
         + self.b1 * self._x1
         + self.b2 * self._x2
         - self.a1 * self._y1
         - self.a2 * self._y2)

    # 移位：为下一拍准备历史
    self._x2 = self._x1
    self._x1 = x
    self._y2 = self._y1
    self._y1 = y
    return y
```

注意 `- self.a1 * self._y1`：系数表里的 `a1` 是**负数**（本课 −1.6849），前面这个减号不能丢，否则变成正反馈、直接发散。这是 biquad 最常见的抄错点。

### 4.2 由截止频率生成系数：`from_cutoff`

```python
@classmethod
def from_cutoff(cls, cutoff_hz, dt, q=SQRT1_2):
    ...校验 fc 落在 (0, fs/2)...
    w0 = 2.0 * math.pi * cutoff_hz * dt
    c = math.cos(w0)
    s = math.sin(w0)

    alpha = s / (2.0 * q)
    a0 = 1.0 + alpha

    b0 = (1.0 - c) / 2.0 / a0
    b1 = (1.0 - c) / a0
    b2 = b0
    a1 = -2.0 * c / a0
    a2 = (1.0 - alpha) / a0
    return cls(b0, b1, b2, a1, a2)
```

**为什么这里也要校验 fc < fs/2**：Day 3 的额外补丁 E 已经踩过这个坑——`from_cutoff` 在 fc 超过奈奎斯特时会静默给出无意义的 α。二阶这边同样会把极点推出单位圆，所以直接抛 `ValueError`，不给"看起来能跑"的机会。

### 4.3 把一阶也写成 biquad 形式

为了用同一套函数分析两个滤波器，示例脚本里做了个转换：

```python
def first_order_coeffs(lp):
    """y[k] = α·x[k] + (1-α)·y[k-1]  ⟺  b0 = α, a1 = -(1-α)，其余为 0。"""
    return (lp.alpha, 0.0, 0.0, -(1.0 - lp.alpha), 0.0)
```

一阶其实就是「b1 = b2 = a2 = 0 的 biquad」。这一步让后面的频率响应、噪声放大、延迟三个函数**两个滤波器共用一份代码**，也顺手说明：一阶是二阶的特例。

### 4.4 三个"体检"函数

```python
def response(coeffs, dt, f):
    """H(e^{jω}) = (b0 + b1·e^{-jω} + b2·e^{-2jω}) / (1 + a1·e^{-jω} + a2·e^{-2jω})"""

def noise_gain(coeffs, dt, n=8192):
    """白噪声放大倍数 = sqrt(mean(|H|²))，ω 在 [0, π] 上均匀取样"""

def phase_delay_ms(coeffs, dt, f_sig):
    """相位延迟 = −φ(ω)/ω，换算成毫秒"""
```

这三个函数不参与滤波，只负责"给滤波器做体检"：把时域看不懂的行为翻译成频域的数字。

> `noise_gain` 是今天新加的，也是最有用的一天：它把"白噪声下二阶打平"这件事变成**一个可以算出来的数**（0.3336 vs 0.2808），而不是靠眼睛看波形。

### 4.5 阶跃指标

```python
def step_metrics(t, y, amp=1.0):
    overshoot = (y.max()/amp - 1.0) * 100.0
    # 上升时间 10%→90%，调节时间进 ±2% 带
```

超调的关键是 `y.max()` 而不是终值——二阶巴特沃斯稳态恰好为 1，超调全部体现在峰值上（1.0432）。

横轴 = 3 Hz 处的相位延迟（ms），纵轴 = 残余噪声相对输入的电平（dB）。沿每条曲线移动相当于拧截止频率。

> 一句话读法：**虚线重合 → 阶数在白噪声上无用；实线分开 → 阶数在窄带干扰上值钱。**

## 6. 今日要点

1. **二阶低通的连续形式**：`H(s) = ωn²/(s² + (ωn/Q)s + ωn²)`，两个参数决定一切。
2. **Q 与 ζ**：`ζ = 1/(2Q)`。**Q = 0.7071（ζ = 0.7071）= 巴特沃斯**：最平坦、−3 dB 落在 ωn、阶跃超调正好 4.32%。
3. **离散化用双线性变换**，而不是欧拉：保证稳定性、保阶数，代价是频率轴弯曲，用预畸变 `tan(π·fc·dt)` 修正回来。
4. **biquad 差分方程**：`y[k] = b0x[k] + b1x[k−1] + b2x[k−2] − a1y[k−1] − a2y[k−2]`，四个状态。
5. **直流增益必须为 1**：`(b0+b1+b2)/(1+a1+a2) = 1`，代码里用 `dc_gain` 自检。
6. **白噪声下阶数不赚**：等效噪声带宽 ∝ 1/延迟，与阶数无关。同延迟 → 同噪声。
7. **二阶的主场是窄带干扰**：本课 120 Hz 处一阶 −10.7 dB、二阶 −21.9 dB，差 11.2 dB；离 fc 越远差距越大。
8. **延迟与超调是二阶的代价**：同 fc 下延迟约 1.6 倍，阶跃有 4.32% 超调、调节时间更长。

## 7. 速查表：什么时候该上一阶、什么时候上二阶

| 场景 | 选谁 | 理由 |
|---|---|---|
| 传感器白噪声（陀螺、ADC、编码器抖动） | **一阶** | 白噪声下二阶不赚，还多 4 个状态和超调 |
| 有明显的固定频率干扰（PWM 纹波、50/100 Hz 工频、结构谐振） | **二阶** | 斜率翻倍，离 fc 越远越占便宜 |
| 需要零超调（比如进执行器的指令不能振） | 一阶，或二阶取 Q = 0.5 | 巴特沃斯有 4.32% 超调 |
| 算力/内存极紧（比如 1 kHz 控制环里的 MCU） | 一阶 | 二阶要 4 个状态 + 5 次乘加，一阶只要 1 个状态 |
| 要和 Day 3 的结果对照 | 同 fc 下比 | 先固定 fc 再比，否则比的是截止频率不是阶数 |

## 8. 和 Day 3 的接口

- Day 3 的 `FirstOrderLowPass.from_cutoff(fc, dt)` 与今天的 `SecondOrderLowPass.from_cutoff(fc, dt)` **签名一致**，所以可以一行切换：
  ```python
  filt = SecondOrderLowPass.from_cutoff(cutoff_hz=35.7, dt=0.001)   # 换掉这一行就行
  ```
- 两者都是"一拍一输入"的 `update(x)` 接口，能直接丢进同一个 `filter_signal()` 里对比。
- 这套接口后面会原样带进硬件项目（P1 电机测速、P2 姿态解算都要滤波），所以**接口统一比算法花哨更重要**。

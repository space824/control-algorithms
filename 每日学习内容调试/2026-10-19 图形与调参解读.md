## 2. α 变化对图的影响（本课唯一的核心旋钮）

| α 变化 | (a) 时域 | (b) 误差 | (c) 位置 | (d) 交叉点 |
|---|---|---|---|---|
| **↑ 增大**（信陀螺更多） | 更平滑，但开始跟着漂移往上走 | 蓝线从"贴 0"慢慢抬起 | 红点往右移，越过最优后**陡升** | 交叉点**左移**（fc 降低） |
| **↓ 减小**（信加速度计更多） | 毛刺变多，但压得住漂移 | 蓝线抖动变大 | 红点往左移，RMSE 缓慢上升 | 交叉点**右移**（fc 升高） |

**记法**（和 Day 3 正好反过来）：

- α 大 = 「更信陀螺」= 更平滑、更会漂；
- α 小 = 「更信加速度计」= 更不漂、更毛糙。

**工程直觉**：图 (c) 的曲线**左边缓、右边陡**。意思是 α 取小一点只是稍微变差，取大一点会突然崩掉。所以**宁可偏小**。

## 3. 其他参数变化对图的影响（这一步才真正理解"什么决定最优 α"）

### 3.1 陀螺零偏 `gyro_bias`

| 零偏变化 | 图上的表现 |
|---|---|
| **↑ 变大**（如 0.5 → 2.0 °/s） | (a) 红线爬得更陡、(b) 红线斜率更陡；(c) 最优 α **往左移**（要多信加速度计才压得住） |
| **↓ 变小** | (c) 最优 α 往右移（可以放心多信陀螺） |

**关键**：**零偏越大，越要信加速度计**。这也是为什么廉价 MEMS 模块（零偏不稳）通常把 α 取小、甚至要定期重标定。

### 3.2 加速度计噪声 `accel_noise`

| 噪声变化 | 图上的表现 |
|---|---|
| **↑ 变大**（如 1.5 → 5.0 °） | (a) 灰线更"毛"；(c) 最优 α **往右移**（陀螺相对更可信） |
| **↓ 变小** | 最优 α 往左移（可以多信加速度计） |

**关键**：**最优 α 本质上由「两路噪声的比值」决定**。这正好是 Kalman 里 `Q/R` 的比值——Day 10 会看到同一件事用协方差自动算出来。

### 3.3 陀螺噪声 `gyro_noise`

| 噪声变化 | 影响 |
|---|---|
| **↑ 变大** | 陀螺短期也没那么准了；最优 α 略往左移（多信加速度计） |
| 相对加速度计噪声可忽略 | 现实中通常成立（陀螺噪声比加速度计小一个量级以上） |

### 3.4 真实运动频率 `f_tilt`（这条最容易被忽略）

| 运动变化 | 图上的表现 |
|---|---|
| **↑ 变快**（0.05 → 0.5 Hz） | (c) 最优点**明显左移**：运动越快，越不能"黏"（α 大 → 滞后 → 跟丢） |
| **↓ 变慢**（趋近静止） | 最优 α 可以很大（0.99+），因为不怕滞后，只怕漂移 |

**关键**：**α 的下限由"噪声"决定，上限由"运动带宽"决定**。`fc` 必须夹在两者之间：

```
运动频率  ≪  fc  ≪  噪声主要集中的频率
```

图 (d) 的交叉点 `fc = 0.32 Hz` 就是这么来的：运动 0.05 Hz 在左边（信加速度计），噪声在右边（信陀螺）。

### 3.5 采样周期 `dt`

| dt 变化 | 影响 |
|---|---|
| **dt ↑（采样慢）** | 同样 α，τ 变大、fc 变低（τ = dt·α/(1-α) 与 dt 成正比） |
| **dt ↓（采样快）** | 同样 α，τ 变小、fc 升高 → **滤波变弱** |

**关键**：α 是相对的，**必须和 dt 一起看**。换采样率要重算 α：

```
α = τ / (τ + dt)        ← 想保持同一个 τ，就这么反推
```

例：原来 100 Hz、α=0.98（τ=0.49 s）。改到 200 Hz 想维持 τ=0.49 s：

```
α = 0.49 / (0.49 + 0.005) = 0.9899      ← 不是 0.98
```

## 4. 四张图的核心读法（一句话版）

- **(a) 蓝色同时干掉了灰色和红色的病**：不抖（不像灰）、不漂（不像红）。
- **(b) 红线是斜直线**：陀螺误差线性增长，斜率就是零偏——**时间一长必废**。
- **(c) 左边缓、右边崩**：α 宁小勿大；课本 0.98 接近最优但不是最优。
- **(d) 蓝橙两条加起来恒为 1**：低频信加速度计、高频信陀螺，这就是"互补"的严格含义。

## 5. 调参 → 看图 速查表

| 图上的症状 | 原因 | 怎么办 |
|---|---|---|
| (a) 蓝线跟着红线一起漂 | α 太大，太信陀螺 | **调小 α**（多信加速度计） |
| (a) 蓝线毛刺太多、跟灰线差不多 | α 太小，加速度计噪声全进来了 | **调大 α** |
| (a) 蓝线明显滞后于黑虚线（形似但错开） | α 太大、fc 低于运动频率 | **调小 α**（提高 fc） |
| (c) 红点落在最优左侧很远 | α 偏小 | 增大 α 直到接近最优 |
| (c) RMSE 突然飙到 1 附近 | α 接近 1，τ 太长跟丢 | **立刻调小 α** |
| (d) 交叉点落到了运动频率左边 | fc 太低，信号本身被当噪声滤了 | 提高 fc（调小 α） |
| 换了采样率后效果全变 | α 没跟着 dt 重算 | 用 `α = τ/(τ+dt)` 反推 |
| 换了陀螺模块后开始漂 | 零偏变了 | 重标零偏，或调小 α |

## 6. 动手试玩：改哪个数、看什么变化

### 6.1 该调的旋钮在哪

打开 `examples/day5_complementary_filter.py`，`main()` 顶部：

```python
dt = 0.01          # 采样周期（100 Hz）
duration = 30.0    # 时长
alpha = 0.98       # 核心旋钮
```

传感器的"脏"程度在 `simulate()` 的默认参数里：

```python
f_tilt=0.05, amp=20.0          # 真实运动：0.05 Hz、20°
gyro_bias=0.5, gyro_noise=0.1  # 陀螺：零偏 0.5°/s、噪声 0.1°/s
accel_noise=1.5                # 加速度计噪声 1.5°
```

改任意一个 → 保存 → 重跑 `python examples/day5_complementary_filter.py` → 看新图。**一次只改一个数。**

### 6.2 各参数作用（一句话版）

- **α**：信陀螺还是信加速度计。大 → 平滑但漂；小 → 不漂但毛糙。
- **gyro_bias**：陀螺"谎报"的常数。越大，红线爬得越陡，α 该越小。
- **accel_noise**：加速度计有多脏。越大，α 该越大（陀螺相对更可信）。
- **gyro_noise**：陀螺的短期抖动。通常远小于加速度计噪声。
- **f_tilt**：真实运动快慢。越快，越不能取大 α（会滞后）。
- **dt**：采样周期。改了必须重算 α。

### 6.3 试玩清单（改 → 跑 → 看）

| 编号 | 改哪个数 | 图上会看到什么 |
|---|---|---|
| 1 | `alpha` 0.98 → 0.95 | (a) 蓝线毛刺变多、漂移被压住；(c) 红点左移；(d) 交叉点右移 |
| 2 | `alpha` 0.98 → 0.995 | (a) 蓝线极平滑但开始跟不上、明显滞后；(c) RMSE 飙到 1 附近 |
| 3 | `gyro_bias` 0.5 → 2.0 | (b) 红线斜率变陡 4 倍；(c) 最优点明显左移 |
| 4 | `accel_noise` 1.5 → 5.0 | (a) 灰线更毛；(c) 最优点右移（更信陀螺） |
| 5 | `f_tilt` 0.05 → 0.5 | (a) 蓝线开始跟不上（滞后）；(c) 最优点大幅左移 |
| 6 | `dt` 0.01 → 0.005 | τ 减半、fc 翻倍，同样 α 下滤波变弱（蓝线更毛） |
| 7 | 把 `alpha` 改回 0.98 但 `dt` 换成 0.005 | 验证「α 必须配 dt」：τ 从 0.49 s 掉到 0.245 s |
| 8 | `gyro_bias` 改成 0（理想陀螺） | 红线不再漂，(c) 最优点右移到接近 0.99——**没有漂移时当然该多信陀螺** |

> 第 8 条最值得做：它让你一次看清「最优 α 不是常数，而是由两个传感器的相对质量决定的」。这也是为什么 Day 9 的卡尔曼要"自动算增益"——**它就是在做第 8 条这件事，只不过自动的**。

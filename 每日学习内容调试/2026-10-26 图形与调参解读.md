## 1. 这四张图在回答同一个问题

前六天调一个参数，看一张图就够了（比如 Day 3 只看图 (a) 就知道 α 调得对不对）。**状态空间是二维（甚至更高维）的，一张图画不下。**

于是这四张图分工：

| 面板 | 画的是 | 回答的问题 |
|---|---|---|
| **(a)** | `x1`、`x2` 两条曲线 | **状态和输出差在哪**——没有传感器的量长什么样 |
| **(b)** | 同 ωn、不同 ζ 的四条阶跃 | **ζ 这个旋钮管什么** |
| **(c)** | `c` 扫过去时极点走过的路径（s 平面） | **参数一变，极点往哪躲** |
| **(d)** | 把 (c) 的极点映射到 z 平面 | **离散化后这些点落在哪** |

四张图的关系是**一条链**：

```
物理参数 (m, c, k)  →  A  →  极点  →  (b) 时域形状
                              ↓
                          (c) s 平面走位
                              ↓  z = e^{λTs}
                          (d) z 平面落点
```

**(a) 是唯一的"时域多状态"图，另外三张都在谈极点。** 这是本日调试最该建立的直觉：**极点是你唯一需要盯的东西**——它决定了 (b)(c)(d) 三张图，而这三张图说的是同一件事的三种语言。

## 2. 逐个面板：看什么、为什么会那样

### 2.1 图 (a)：状态不是输出

设置：`m=1, k=4, c=0.8`（ωn=2、ζ=0.2），阶跃输入，`C=[1,0]`（只有位移传感器）。

**先看形状**：

- 蓝线 `x1`（位移）：缓慢爬升到 0.377，然后振荡收敛到 0.25；
- 橙线 `x2`（速度）：**一开始就冲到 0.38**，然后立刻掉头穿过零点，为负。

**关键观察 1：速度先动，位移后动。** 这是 `x2 = ẋ1` 的直接后果——位移的斜率就是速度，所以速度必须先有值，位移才动得起来。

**关键观察 2：速度过零的时刻 = 位移到峰的时刻。** 图上两条虚线标出来了：

```
位移峰值  t = 1.604 s
速度过零  t = 1.602 s
相差      2.0 ms（正好一个采样周期）
```

这 2 ms 不是误差，是**采样造成的**：代码里用"导数值由正变负"来找峰值时刻，而相邻两拍之间才会变号，所以定位精度就是一个 `Ts`。理论峰值时刻 `tp = π/(ωn√(1-ζ²)) = π/(2×0.9798) = 1.603 s`，实测 1.604，差 1 ms，在这个采样精度下完全正确。

> **调参时这就是你判断"采样够不够"的尺子**：如果你连峰值和过零点差了一拍都受不了，Ts 就得再小。

**关键观察 3（最重要）：橙线在真实系统里是拿不到的。** 你没有速度传感器，`C=[1,0]` 只给你蓝线。橙线是状态空间"算"出来的——这就是 Day 9 观测器要做的事：**用蓝线反推出橙线**。

**看这张图时的错误读法**：不要盯着"蓝线最后稳定在 0.25"就以为懂了。0.25 = 1/k = 1/4 是**直流增益**，这是传递函数的常识。(a) 的新东西是**橙线**——它告诉你系统内部有个比你测的量更"急躁"的量在动。

### 2.2 图 (b)：ζ 是"形状旋钮"

设置：`ωn = 2` 固定，`c` 取 0.8 / 2.828 / 4.0 / 8.0。

| 参数 | ζ | Q | 实测超调 |
|---|---|---|---|
| c=0.800 | 0.200 | 2.500 | **52.7 %** |
| c=2.828 | 0.707 | 0.707 | **4.3 %** |
| c=4.000 | 1.000 | 0.500 | −0.0 % |
| c=8.000 | 2.000 | 0.250 | −0.5 %（无超调，慢） |

**先说一个反直觉的**：`c = 2.828` 对应的 ζ = 0.7071，也就是 Day 4 说的**巴特沃斯**（频域最平坦、无谐振峰）。但它的阶跃响应**仍有 4.3% 超调**。

理论值 `Mp = e^{−πζ/√(1−ζ²)} = e^{−π} = 0.0432`。**Day 4 的图 (b) 里那个二阶低通 4.32% 的超调，就是这个数**——同一个系统，只是 Day 4 用 `fc、Q` 描述，今天用 `ωn、ζ` 描述。

> ⚠️ **两个"临界"不是一回事**：
> - 通带鼓包的临界：`Q > 0.707`（即 ζ < 0.707）；
> - 阶跃超调的临界：`ζ < 1`（即 Q > 0.5）。
>
> 巴特沃斯刚好卡在第一个临界上，所以频域最平，但时域还有 4.3%。

**再看振荡快慢**：四条线的"节奏"完全一样（都是 ωn = 2 rad/s，周期 ≈ 3.14 s），差别只在"消得多快"。**ωn 定节奏，ζ 定形状**——一句话记法。

**ζ 从 1 继续往上加会怎样**：红线的超调是 −0.5%，负超调的意思是**它从下方逼近 1，没有过冲，但爬得很慢**。为什么慢？看 (c)。

### 2.3 图 (c)：`c` 变化时，极点走一条圆弧

设置：`c` 从 0.02 扫到 20，`m=1, k=4`（所以 ωn = 2 恒定）。

**图上三样东西**：

1. **灰虚线圆**：半径 = ωn = 2；
2. **红/紫轨迹**：`c` 从 0.02 到 4 时，两个极点**始终在这个圆上滑动**，从 `±2j` 往左走到 `-2`；
3. **`-2` 处的 breakaway**：过了这个点（`c > 4`，即 ζ > 1），两个极点分裂到实轴上，一个奔 `-0.2`，一个奔 `-20`。

**为什么 c ≤ 4 时极点一定在半径 2 的圆上**：阻尼没到临界时，`λ = −ζωn ± jωn√(1−ζ²)`，模长 `|λ| = ωn√(ζ² + 1 − ζ²) = ωn`。**模长和 ζ 无关**——这是 (c) 全部的秘密。

代入本课默认参数（c=0.8）：`λ = −0.400 ± 1.960j`，`|λ| = √(0.16+3.84) = 2.0` ✓。

**分裂后为什么"一个越来越慢"**：`c > 4` 时有两个实根，`λ₁·λ₂ = ωn² = 4` 恒定。一个变负得多（−20），另一个就必须变负得少（−0.2）来保持乘积不变。**那个慢极点(−0.2)的时间常数是 5 秒，它决定了整条红线的爬升速度**——这就是 (b) 里 ζ=2 那条线慢的原因。

**读这张图的方法**：不要看具体的点，看**轨迹的形状**。

```
垂直往上  →  ζ 小，振荡强（c 小）
沿弧往左  →  ζ 增大，振荡减弱，衰减加快（c 增大）
分裂成两支 → ζ 过 1，变成两个"一阶"的串联（c 过大）
```

**一个工程含义**：`c` 调到刚好 4 时，(c) 上两个极点在 −2 重合——**“最快的无超调”**。再往上加 `c`，虽然依然无超调，但慢极点拖后腿，反而变慢。**最优的"快且不超调"就是临界阻尼点**，而它恰好也是极点模长和实部相等的点（−2 = −ωn）。

---

### 2.4 图 (d)：把极点卷到 z 平面

设置：`Ts = 0.1 s`，把 (c) 的整条 s 平面轨迹映射成 z 平面轨迹。

**映射规则**：

```
z = e^{λ·Ts}
```

**图上标注的那个点**：

```
λ = −0.400 + 1.960j
z = e^{(-0.4+1.96j)×0.1} = 0.942 + 0.187j
|z| = 0.9608 < 1  →  稳定
```

**这个 z 的两个分量各有一个物理含义**（这是读图 (d) 的关键）：

| | 公式 | 含义 | 本课数值 |
|---|---|---|---|
| **\|z\|** | `e^{Re(λ)·Ts}` | **每拍衰减多少** | 0.9608 → 每拍衰减 3.92 % |
| **∠z** | `Im(λ)·Ts` | **每拍转多少弧度** | 0.1961 rad ≈ 11.2° |

换算成工程语言：**每拍衰减 3.9%、每拍转 11.2°**，10 拍后只剩 67%，一圈要 32 拍。你完全可以不画图、只看 `|z|` 和 `∠z` 就在脑子里重建振荡的样子。

**整条轨迹的读法**：

- 左边（`c` 很小，极点接近 `±2j`）：z 落在**单位圆上**（`|z| = 1`），等幅振荡；
- 中间：z 往圆内收；
- 右边（`c` 很大，两个实极点）：z 变成两个**正实轴上的点**（0.98 和 0.138），一个贴近单位圆（慢），一个贴近原点（快）。

实测 z 的实部范围是 `0.1381 ~ 0.98`，**全在单位圆内**——这就是 Day 6 说的"ZOH 保稳定"的图解：`c` 扫遍全程，z 都没出圈。

> **为什么前向欧拉不保稳定**：它的映射是 `z = 1 + Ts·λ`（一条**直线**，不是圆），Ts 一大，s 左半平面的点被这条直线推到单位圆外。Day 6 的图 (b) 在画这件事，今天这张 (d) 是"正确答案长什么样"的对照。

## 3. 一个旋钮扫过去，四张图怎么联动

把 `c` 当唯一旋钮，从 0.02 扫到 20（`m=1, k=4` 固定，所以 ωn 恒为 2）：

| c | ζ | 图 (a) 见过的样子 | 图 (b) 超调 | 图 (c) 极点位置 | 图 (d) z 落点 |
|---|---|---|---|---|---|
| 0.02 | 0.005 | 几乎不衰减的振荡 | ≈100% | 贴着 `±2j` | 几乎在单位圆上 |
| 0.8 | 0.20 | 明显振荡（本课默认） | 52.7% | `−0.4 ± 1.96j` | `0.942 ± 0.187j`，\|z\|=0.961 |
| 2.828 | 0.71 | 一个鼓包 | 4.3% | `−1.414 ± 1.414j` | 往内收 |
| 4.0 | 1.00 | 无超调、最快 | 0% | `−2`（二重） | 实轴，重根 |
| 8.0 | 2.00 | 无超调、很慢 | 0% | `−0.42` 和 `−9.6` | 一个贴圆、一个靠原点 |

**这条链的意义**：你改一个物理参数 `c`（阻尼系数），它经过 `A`、经过极点、经过 `e^{λTs}`，最后体现为你在示波器上看到的一条曲线。**中间每一步都是确定的、可算的、可画的。** 这就是"用状态空间思考"和"试参数"的区别。

## 4. 其余旋钮，各改哪一张

### 4.1 `m` 和 `k`：只改 ωn（改节奏，不改形状）

```
ωn = √(k/m)
```

| 动作 | ωn | 图 (c) 的圆 | 图 (b) 的节奏 |
|---|---|---|---|
| `k` 翻倍 | ×1.414 | 半径变大 | 更快 |
| `m` 翻倍 | ×0.707 | 半径变小 | 更慢 |

**注意**：`k` 一变，直流增益 `1/k` 也变（本课 0.25 = 1/4）。所以阶跃响应的**终值**会跟着变——看图时别把"终值变了"误当成"超调变了"。想只改节奏不改终值，就得同时调整输入幅值，或者改用"归一化"的传递函数形式。

### 4.2 `Ts`：只改 (d)，不动 (a)(b)(c)

`Ts` 不影响连续域的任何东西（A、极点、超调都不变），它只影响：

1. **(d) 里 z 的落点**：`Ts` 变大 → 整个图案被"卷"得更紧（`|z|` 变小，因为 `e^{-0.4·Ts}` 更小）；
2. **(a) 的采样点密度**，以及 §2.1 里那个 ±1 拍的定位误差。

**约束**：`Ts` 至少要满足 Nyquist（`ωs > 2ωn`，本课 ωn=2 → `Ts < 1.57 s`），但真正卡你的是精度：`ωn·Ts` 要足够小，否则 (d) 里 z 的幅角一转换回连续域就失真。经验值 `ωn·Ts < 0.2`（本课 0.2 刚好卡线）。

### 4.3 `C`：只改可观性，不动 A、B

```python
C = [1, 0]   # 只测位移 → 速度要靠观测器
C = [0, 1]   # 只测速度 → 位移要靠观测器
C = [[1,0],[0,1]]  # 两个都测 → 不需要观测器
```

**A、B 一个数都没变**，因为对象的物理没变。变的只是"你能看见什么"。

这一条在 Day 9 会变成硬约束：**`is_observable()` 为 True，观测器才有解**。

### 4.4 `B`：只改可控性

```python
B = [[0], [1/m]]    # 力只推速度（本课）
B = [[1], [0]]      # 力直接推位移（物理上不成立，但数学上合法）
```

第二种在数学上完全合法，只是物理上讲不通。**数学合法 ≠ 物理可实现**，这是状态空间最容易骗人的地方——秩条件算出来可控，不代表你真能实现那个输入。

## 5. 调参公式与速查

**给定 ωn、ζ，直接算时域指标**（本课验证过前两条）：

| 指标 | 公式 | ζ=0.2 理论 | ζ=0.2 实测 |
|---|---|---|---|
| 超调 | `Mp = e^{−πζ/√(1−ζ²)}` | 52.66 % | **52.7 %** ✓ |
| 峰值时间 | `tp = π/(ωn√(1−ζ²))` | 1.603 s | **1.604 s** ✓ |
| 衰减时间常数 | `τ = 1/(ζωn)` | 2.5 s | —— |
| 调节时间(2%) | `ts ≈ 4/(ζωn)` | 10 s | —— |
| 无阻尼振荡频率 | `ωd = ωn√(1−ζ²)` | 1.96 rad/s | **1.96** ✓（极点虚部） |
| 极点模长 | `\|λ\| = ωn`（ζ≤1） | 2.0 | **2.0** ✓ |

**反向设计（从指标反推参数）**：

```
给定想要的超调 Mp  →  ζ = −ln(Mp/100) / √(π² + ln²(Mp/100))
给定想要的响应速度 →  ωn = 4 / (ζ · ts)
然后：k = m·ωn²        c = 2ζ·√(k·m) = 2ζ·m·ωn
```

**离散化指标的换算**：

```
|z| = e^{−ζωn·Ts}        （每拍衰减比）
∠z  = ωd·Ts              （每拍转过的弧度）
```

**四个面板的"健康值"检查表**：

| 看到什么 | 说明 |
|---|---|
| 图 (b) 的线与 52.7% 不符 | 检查 ωn 是不是被 `k`/`m` 悄悄改了 |
| 图 (c) 的轨迹**不在**半径 ωn 的圆上 | 说明你 `m`、`k` 也在变（ωn 不恒定） |
| 图 (d) 有点落在单位圆外 | ZOH 算出错，或者 Ts 给成了负的 |
| 图 (a) 峰值和过零点差得远大于一个 Ts | 找峰值的方法有问题（见 §2.1） |

## 6. 动手改代码做实验

改 `examples/day8_state_space.py` 顶部的参数，**每次只改一个**，跑完对着四张图问"变了哪几张"。

**实验 A：验证"ωn 定节奏"**
```python
MASS = 4.0        # 原来是 1.0，ωn 从 2 降到 1
```
预期：(b) 四条线全部拉宽一倍；(c) 圆的半径变成 1；(d) 图案整体往右移（`|z|` 变大，更接近 1）。

**实验 B：验证"临界阻尼最快"**
把 `C_SWEEP` 改成 `[2.0, 3.0, 4.0, 5.0]`，只盯 (b) 下面三条：c=4（绿）应该比 c=3 和 c=5 都快地到达终值。

**实验 C：看 Ts 怎么卷**
```python
TS = 0.5          # 从 0.1 改成 0.5
```
预期：只有 (d) 变——z 的点往原点方向收（`|z| = e^{-0.4×0.5} = 0.819`），并且**仍然全在单位圆内**（ZOH 保稳定）。

**实验 D：把可观性搞坏**
```python
C = [0, 1]        # 只测速度
```
预期：A、B 不变，(c)(d) 完全不动，只有 §7.3 打印的"可观"变 True（仍然可观）。试试改成 `C = [0, 0]`——那就什么都看不见了，可观性崩溃。

**实验 E：图 (a) 的 2 ms**
把 `TS` 改成 0.01，重跑 (a)：峰值和过零点的差应该缩小到 ~1 ms（定位精度就是一个 Ts）。

## 7. 落到硬件上

这四张图在真实项目里对应什么：

| 图 | 硬件上的对应物 | P1–P5 里的例子 |
|---|---|---|
| **(a)** | 一个有传感器、一个没有 | P1：转速有编码器，**电流没有传感器**（P3 平衡车也这样） |
| **(b)** | 你调 PID 时看到的阶跃曲线 | 每条线的 ζ 对应一个 Kp/Kd 组合 |
| **(c)** | 参数漂移后极点往哪走 | 电池电压降 → 电机参数变 → 极点移动 |
| **(d)** | 你的控制器在 MCU 里跑的那个版本 | `Ts` 就是你的定时器中断周期 |

**一个真实的例子**：P1 的直流电机，本课算出的连续极点是 `−1.6844` 和 `−0.4156`。代入 `Ts = 1 ms`：

```
|z₁| = e^{−1.6844×0.001} = 0.99832
|z₂| = e^{−0.4156×0.001} = 0.99958
```

**两个 z 都极其贴近单位圆**。这不是坏事（说明 Ts 够小、离散化失真可忽略），但它的工程含义是：**在 MCU 里，这两个状态都是"缓慢衰减"的，你的控制器要能在 1 ms 内算完，否则采样延迟会直接吃掉相位裕度**——这就是 Day 14 之后要谈的"采样延迟"问题。

**还有一个实战提醒**：`(c)` 上那个 breakaway 点（`c = 4`）在硬件上是**不可调**的——`m`、`k`、`c` 都是物理量，你改不了。**真正能调的是控制器**。所以这些图在硬件上的正确用法不是"调对象"，而是：**先量出真实对象的极点（系统辨识，Day 13），再在这个事实基础上设计控制器**。今天画的图，是让你知道"我可以往哪里设计"。

## 8. 一句话总结这四张图

> **(a) 让你看见内部，(b) 教你 ζ 的形状语言，(c) 是 s 平面的走位图，(d) 是把这张走位图卷进单位圆。**

四张图里，只有 (a) 是"时间"，另外三张都是"极点"。**Day 9 的观测器只跟 (a) 和 (c) 打交道**（内部状态能不能反推、极点往哪放），Day 15 的 LQR 只跟 (c) 打交道（把极点挪到你想要的地方）。所以把这四张图看熟，后面两周会轻很多。

## 1. 什么是 PID（先建立直觉）

PID 是三个词的缩写，它是一条「根据误差来算控制量」的规则：

| 字母 | 全称 | 中文 | 一句话作用 |
|------|------|------|-----------|
| P | Proportional | 比例 | 误差越大，反应越猛 |
| I | Integral | 积分 | 误差老消不掉，就持续加力 |
| D | Derivative | 微分 | 误差变化太快，提前踩刹车 |

**核心思想：反馈控制。**
我们先定义「误差」：

```
误差 e = 设定值 r − 实际输出 y
```

- 设定值 r（reference / setpoint）：**你想要的目标**（比如水位想要 1 米）。
- 实际输出 y（measurement）：**传感器测到的真实值**（比如现在水位只有 0.3 米）。

PID 干的事就是：盯着这个误差 e，把它算成一个「控制量 u」去驱动被控对象，
让 y 不断逼近 r。误差为 0 了，就说明 y 追上了 r。

## 2. 位置式 PID 是什么（重点）

### 2.1 连续形式的公式

PID 输出的控制量 u 由三项相加得到：

```
u(t) = Kp·e(t)  +  Ki·∫e(τ)dτ  +  Kd·de/dt
       └ 比例项     └ 积分项       └ 微分项
```

### 2.2 计算机里用离散形式（因为电脑只能一步一步算）

计算机没法算连续积分/微分，所以要离散化。设采样周期为 `dt`（控制周期），第 k 步：

```
e[k]  = r[k] − y[k]                        （当前误差）
I[k]  = I[k−1] + e[k]·dt                   （积分：把所有历史误差累加起来）
D[k]  = (e[k] − e[k−1]) / dt               （微分：误差的变化速度）
u[k]  = Kp·e[k] + Ki·I[k] + Kd·D[k]        （三项相加 → 控制量）
```

### 2.3 「位置式」到底指什么

**位置式 PID 输出的是控制量的「绝对位置/绝对值」u**，不是「变化量」。

打个比方：控制一个水阀，位置式 PID 直接告诉你「阀门应该开到 45%」这个绝对开度。

它和「**增量式 PID**」（Day 2 会学）的区别：

| | 位置式 PID | 增量式 PID |
|---|---|---|
| 输出 | 绝对控制量 u[k] | 控制量的增量 Δu = u[k] − u[k−1] |
| 积分 | 累加所有历史误差，会无限累积 | 天然避免积分累积（只存最近几步误差） |
| 适用 | 需要绝对量（阀门开度、占空比、舵机角度） | 步进电机、需要手动/自动无扰动切换 |
| 坑 | 容易「积分饱和」，要做抗饱和处理 | 相对更安全 |

**位置式最大的坑——积分饱和（integral windup）：**
因为积分项把所有历史误差一直加，如果输出 u 已经被限幅（比如阀门最多开到 100%），
而误差还是一直是正的，积分会无限往上涨，等误差反过来时，积分项会「赖着」很久不肯降，
导致超调严重甚至震荡。
仓库里的代码用「条件积分」做简化抗饱和：**只有当输出没被限幅时才真正累加积分**。

## 3. 一阶惯性环节是什么（被控对象）

### 3.1 数学模型

被控对象就是「被 PID 控制的那个东西」，这里用最简单的动态系统：

```
dx/dt = −a·x + b·u
```

- `x`：系统的状态，也就是我们关心的「实际输出 y」（比如水位）。
- `u`：PID 算出来的控制量（比如进水阀开度）。
- `dx/dt`：状态 x 的变化速度。

### 3.2 物理意义（拿水箱举例）

想象一个水箱：

- `−a·x`：**自然泄漏/流出**。水位 x 越高，漏得越快，所以是「负」的，x 越大拖后腿越大。
- `b·u`：**进水**。阀门开得越大（u 越大），进得越快。

所以这句话翻译成人话：**水位的变化速度 = 进水速度 − 漏水速度**。

### 3.3 为什么叫「惯性」环节

状态 x **不能突变**，只能以 `dx/dt` 这个速度慢慢变。你突然把阀门开到最大，
水位也是一点点涨上去，而不是瞬间到位——这就是「惯性」（有滞后、有延迟）。

### 3.4 两个参数 a、b 的含义

- `a` 越大 → 系统响应越快。定义**时间常数 τ = 1/a**，系统约 3~5 个 τ 后达到稳态的 95%~99%。
- `b` 越大 → 同样的输入 u 能产生更大的变化（输入增益）。

### 3.5 稳态值（关键结论）

当系统稳定后 `dx/dt = 0`，于是：

```
0 = −a·x + b·u  →  x稳态 = (b/a)·u
```

本例 `a=1, b=0.3`，所以 `x稳态 = 0.3·u`。
**要让 x 稳定在设定值 1，就需要 u 长期维持在 1/0.3 ≈ 3.33。**

这个结论非常重要，它是后面理解「为什么纯 P 有稳态误差」的钥匙。

### 3.6 代码里怎么离散化（前向欧拉）

```
x[k+1] = x[k] + dt·(−a·x[k] + b·u[k])
```

就是「当前状态 + 一小段时间的变化量」，一步步往前推。

## 4. 阶跃响应曲线是怎么来的

### 4.1 什么是阶跃信号

「阶跃」就是：设定值在某一刻**突然从一个值跳到另一个值**（这里从 0 突然跳到 1）。

```
r(t) = 0   (t < 0)
r(t) = 1   (t ≥ 0)
```

它用来考察系统「遇到突然的目标变化时，能不能又快又稳地跟上」。

### 4.2 仿真循环（核心逻辑）

代码里 `simulate` 函数就是不断重复下面三步，模拟真实控制过程：

```python
for k in range(n):
    y[k] = plant.x                  # ① 读当前实际输出（传感器）
    u[k] = pid.update(1, y[k])      # ② 拿设定值=1 和当前输出算控制量
    plant.step(u[k])                # ③ 把控制量喂给对象，对象状态更新一步
```

三步对应现实里的：**测量 → 决策 → 执行**，反复循环。

### 4.3 设定值 vs 实际值是怎么「比较」出来的

- 图上的**水平虚线**就是设定值 r = 1（恒定不变）。
- 图上从 0 开始往上爬、最后贴近虚线的**实线**就是实际输出 y。
- 两者在**同一时刻的纵坐标之差，就是误差 e = r − y**。

刚开始 y=0，r=1，误差最大（e=1）；随着时间推移 y 逼近 1，误差越来越小。
看曲线就是看：**y 多久追上 r、追的过程中有没有超出去（超调）、最后稳不稳。**

## 5. P / I / D 三个参数详解（调参重点）

下面每个参数都讲：**它是干嘛的、调大发生什么、调小发生什么**。

### 5.1 P（比例 Kp）—— 按当前误差立刻反应

- **作用**：误差 e 越大，输出 u 就越大（u = Kp·e），是一种「有错立刻改」的力度。
- **Kp 调大**：响应更快、上升更猛，但容易**超调、振荡**，甚至发散（系统狂抖不停）。
- **Kp 调小**：响应变慢、变「肉」，软绵绵追不上。
- **致命缺陷**：对一阶惯性环节，**纯 P 有稳态误差（静差）**，永远差一点到不了目标。

> 为什么纯 P 有静差？（以 a=1,b=0.3 为例，非常直观）
> 稳态时 `x = 0.3·u`，而纯 P 时 `u = Kp·(1−x)`。
> 联立解得 `x = 0.3·Kp / (1 + 0.3·Kp)`。
> 当 Kp=2 时，x = 0.6/1.6 = **0.375**，离目标 1 差得远！
> 因为要维持 x=1 需要 u=3.33，可一旦误差变小，u=Kp·e 也跟着变小，根本供不上——矛盾无解。
> **这正是必须引入积分项 I 的原因。**

### 5.2 I（积分 Ki）—— 消灭稳态误差

- **作用**：把「过去所有误差」累加起来。只要误差还不为零，积分就持续往上推输出，
  一直到误差彻底为 0 才停手。它是「死磕到底、不许留残差」的项。
- **Ki 调大**：消除静差**更快**，但**超调增大**、振荡加剧，还容易**积分饱和**。
- **Ki 调小**：消静差慢，尾巴拖得久。
- **结论**：P 负责「快」，I 负责「准」。P+I 组合（PI）就能让输出既快又准地到 1。

### 5.3 D（微分 Kd）—— 按误差变化趋势提前刹车

- **作用**：盯着误差的**变化速度** de/dt。误差正在快速逼近（甚至要冲过头）时，
  微分项给出「反向的刹车力」，提前抑制超调，让系统更稳。
- **Kd 调大**：阻尼增强、超调变小、更稳，但**对噪声极其敏感**（噪声变化快，会被放大成剧烈的控制量抖动）。
- **Kd 调小**：几乎不起作用。
- **注意**：对**一阶惯性环节，D 的收益很小**（因为一阶系统本身不振荡，没多少「要刹的车」）。
  D 的价值要到**二阶系统 / 带振荡的系统**上才明显（Day 3+ 会看到）。所以本例里 PID 和 PI 差别不大。

### 5.4 三参数对照表（调参速查）

| 参数 | 调大（↑） | 调小（↓） |
|------|-----------|-----------|
| **Kp** | 响应快、上升猛；但超调大、易振荡 | 响应慢、偏软 |
| **Ki** | 消静差快；但超调大、易积分饱和、振荡 | 消静差慢、留尾巴 |
| **Kd** | 更稳、超调小；但对噪声敏感 | 几乎无作用 |

**口诀**：
- **P 管快**（响应速度）
- **I 管准**（消除静差）
- **D 管稳**（抑制超调/振荡）

**整定顺序**：先只调 P 让响应快到接近目标 → 再加 I 消掉静差 → 最后视情况加一点点 D 压超调。

## 6. 代码实现（逐段解释）

下面直接对应仓库里的两个文件。

### 6.1 控制器：`src/pid/position_pid.py`

```python
class PositionPID:
    def __init__(self, kp=1.0, ki=0.0, kd=0.0, dt=0.01,
                 output_limits=(None, None)):
        self.kp = float(kp)          # 比例增益
        self.ki = float(ki)          # 积分增益
        self.kd = float(kd)          # 微分增益
        self.dt = float(dt)          # 控制周期（秒）
        self.lo, self.hi = output_limits  # 输出限幅，None=不限
        self.reset()

    def reset(self):
        self._integral = 0.0         # 积分累加值 I[k]
        self._prev_error = 0.0       # 上一次误差 e[k-1]（算微分用）
        self._last_output = 0.0      # 上一次输出（位置式其实不一定用，记录而已）
```

**update 是核心**，输入「设定值」和「测量值」，输出控制量 u：

```python
    def update(self, setpoint, measurement):
        error = setpoint - measurement          # e[k] = r - y

        # 算一个"积分候选值"：如果这步会导致输出饱和，就不真正累积（抗积分饱和）
        integral_candidate = self._integral + error * self.dt
        derivative = (error - self._prev_error) / self.dt   # 误差变化速度

        # 三项相加 → 控制量 u（这就是"位置式"的公式）
        u = (self.kp * error
             + self.ki * integral_candidate
             + self.kd * derivative)

        # 输出限幅
        if self.hi is not None and u > self.hi:
            u = self.hi          # 饱和了 → 积分不更新（防止继续累积）
        elif self.lo is not None and u < self.lo:
            u = self.lo
        else:
            self._integral = integral_candidate  # 没饱和 → 正常累积积分

        self._prev_error = error
        self._last_output = u
        return u
```

### 6.2 被控对象 + 仿真：`examples/day1_position_pid.py`

被控对象（一阶惯性环节）：

```python
class FirstOrderPlant:
    def __init__(self, a=1.0, b=0.3, dt=0.01, x0=0.0):
        self.a = a; self.b = b; self.dt = dt; self.x = x0  # x0=初始状态

    def step(self, u):
        # 前向欧拉离散：x[k+1] = x[k] + dt·(−a·x[k] + b·u[k])
        self.x += self.dt * (-self.a * self.x + self.b * u)
        return self.x
```

仿真主循环（就是第 4 节那三步）：

```python
def simulate(pid, plant, setpoint=1.0, duration=5.0):
    n = int(duration / plant.dt)
    t = np.zeros(n); y = np.zeros(n); u = np.zeros(n)
    r = np.full(n, setpoint)          # 设定值全程恒等于 1（这就是那条水平虚线）

    for k in range(n):
        t[k] = k * plant.dt
        y[k] = plant.x                # ① 读输出
        u[k] = pid.update(setpoint, y[k])   # ② 算控制量
        plant.step(u[k])              # ③ 更新对象
    return t, r, y, u
```

## 7. 今天该记住的 5 件事

1. **PID = 比例 + 积分 + 微分**，都围绕「误差 e = 设定值 − 实际输出」工作。
2. **位置式 PID 输出的是绝对控制量 u**，积分会无限累积，所以要抗积分饱和。
3. **一阶惯性环节 `dx/dt = −a·x + b·u`** 是有惯性的系统，稳态值 = `(b/a)·u`。
4. **纯 P 对一阶系统有静差**，必须靠 I 消除；D 对一阶系统作用不大。
5. **调参口诀：P 管快，I 管准，D 管稳**。顺序：先 P、再加 I、最后补 D。

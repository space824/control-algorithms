## 0. 今天的新问题：两个传感器都不靠谱，但错得不一样

前四天都在跟**一个**信号较劲：要么控它（PID），要么滤它（低通）。

今天第一次面对**两个传感器测同一个量**：

- **陀螺仪**测的是**角速度**，积分一次才得到角度。短期非常准（响应快、噪声小），但零偏偏置会一直积分下去 → **角度线性漂移**。
- **加速度计**测的是**重力在三个轴上的分量**，用 `atan2` 直接算出角度。**长期绝对准**（重力方向不会漂），但噪声大，一有振动或者加速度（比如车在加速）就完全不可信。

| | 短时间（高频） | 长时间（低频） |
|---|---|---|
| 陀螺（积分） | **准** | **漂** |
| 加速度计 | **噪声大** | **准** |

**两个传感器的缺点正好互补**——这就是"互补滤波"这个名字的来历，也是今天全部内容的出发点。

---

## 1. 互补滤波是什么：一行公式，两步操作

```
angle[k] = α·(angle[k-1] + gyro[k]·dt) + (1-α)·angle_acc[k]
```

拆成两步看，思路立刻清楚：

```
① 预测（信陀螺，短时间）：pred = angle[k-1] + gyro[k]·dt
② 修正（信加速度计，长期）：angle[k] = α·pred + (1-α)·angle_acc[k]
```

- `α` 是**陀螺（预测）的话语权**，`1-α` 是**加速度计（测量）的话语权**，两者加起来是 1。
- α 大 → 基本只用陀螺 → 平滑、但会跟着漂；α 小 → 基本只信加速度计 → 不漂、但噪声全进来了。

### 1.1 换个写法：它其实是一个"增益固定的观测器"

把上面的公式展开：

```
angle[k] = angle[k-1] + gyro[k]·dt + (1-α)·( angle_acc[k] − (angle[k-1] + gyro[k]·dt) )
                ↑ 预测值                              ↑ 测量值与预测值的差（残差）
```

也就是：

```
angle[k] = pred + K·(measurement − pred)          K = 1-α
```

**这就是一个比例观测器**：先用陀螺往前推，再用加速度计把"推歪的部分"按固定比例 K 拉回来。

> 记住这个结构，因为 **Day 9 的卡尔曼滤波完全一样**——只把固定的 `K` 换成一个随协方差自动变化的 `(1-α)ₖ`。互补滤波是 KF 的"固定增益版"，理解它，KF 就只剩下"增益怎么算"这一个新问题了。

### 1.2 为什么这个"固定增益"就够用了

因为两个传感器错在**不同的频段**：陀螺的漂移是缓慢的低频误差，加速度计的噪声是快速的高频误差。用一个截断频率把频段分开，让各自在自己擅长的频段里说话，就足够了。

## 2. α 的物理意义（与 Day 3 是同一个公式，但含义反了）

### 2.1 加速度计那一路就是个一阶低通

把互补滤波只看加速度计这一条通路：`angle` 对 `angle_acc` 的响应是

```
H_acc(z) = (1-α) / (1 − α·z⁻¹)
```

这正是 Day 3 的一阶低通，只是系数换了个名字——令 **α' = 1-α**：

```
y[k] = α'·x[k] + (1-α')·y[k-1]        ⟺        (1-α)·x[k] + α·y[k-1]
```

所以 Day 3 的全部结论可以直接搬过来：

```
τ  = dt·(1-α')/α' = dt·α/(1-α)

cos(2π·fc·dt) = (2 − 2α' − α'²) / (2(1−α'))  ,  α' = 1-α
```

本课参数：`dt = 10 ms, α = 0.98` → `α' = 0.02` → **τ = 0.490 s，fc = 0.32 Hz**。

### 2.2 ⚠️ α 的含义和 Day 3 正好相反

| | 公式 | α 是谁的权重 |
|---|---|---|
| Day 3 一阶低通 | `y = α·x + (1-α)·y_prev` | **新样本**（输入） |
| Day 5 互补滤波 | `angle = α·pred + (1-α)·accel` | **历史预测**（陀螺） |

Day 3 里 α 越大越"跟手"；Day 5 里 α 越大越"信陀螺"、越平滑但越容易漂。**抄公式时最容易被这个反转绊倒**，写代码前先想清楚"我要放大的是哪一路"。

### 2.3 α 只在给定采样率时才有意义

本课 `α=0.98` 在 100 Hz 下 τ=0.49 s。如果你把采样率提到 200 Hz 而 α 还是 0.98：

```
τ = dt·α/(1-α) = 0.005 × 49 = 0.245 s      ← 时间常数直接减半
fc 从 0.32 Hz 变成 0.65 Hz
```

**同样的 α，滤波强度差一倍。** 这就是为什么类里同时给了 `tau` 和 `cutoff_hz` 两个属性——想按"物理意义"调参，就该按 fc 调，再反推 α。

## 3. 为什么叫"互补"：低通 + 高通，加起来恒等于 1

把输出写成两路输入各自传递函数的和：

```
angle = H_lp(z)·angle_acc + H_hp(z)·angle_gyro_int
H_lp(z) = (1-α)/(1-α·z⁻¹)          （低通：让加速度计管低频）
H_hp(z) = 1 − H_lp(z) = α(1-z⁻¹)/(1-α·z⁻¹)   （高通：让陀螺管高频）
```

关键性质：

```
H_lp(z) + H_hp(z) ≡ 1        ← 对任何频率都成立
```

在 z=1（直流/极低频）：`H_lp = 1, H_hp = 0` → 完全信加速度计；
在 z=−1（奈奎斯特）：`H_lp ≈ 0, H_hp ≈ 1` → 完全信陀螺。

**两条曲线的权重加起来永远是 1，谁也不多、谁也不少**——这就是"complementary（互补）"这个词的严格含义。图 (d) 画的就是这两条曲线。

---

## 4. 与一阶低通的关系：一句话总结

| | Day 3 一阶低通 | Day 5 互补滤波 |
|---|---|---|
| 输入 | 1 路 | **2 路**（陀螺、加速度计） |
| 输出 | 平滑后的信号 | 融合后的角度 |
| 核心公式 | `y = α'x + (1-α')y` | `angle = α·pred + (1-α)·accel` |
| α 含义 | 信新样本 | **信陀螺** |
| 本质 | 低通 | **低通 + 高通 = 1** |

**互补滤波 = 把一阶低通和它的"补"（高通）并起来用**。Day 3 只学了低通的一半，今天补上另一半。

## 5. 代码实现（逐段）

### 5.1 核心类：`src/filter/complementary.py`

```python
def update(self, gyro_rate, accel_angle):
    """① 预测：用陀螺把上一拍的角度往前推一步
       ② 修正：用加速度计按 (1-alpha) 的权重拉回来"""
    pred = self._angle + (float(gyro_rate) - self.bias) * self.dt
    self._angle = self.alpha * pred + (1.0 - self.alpha) * float(accel_angle)
    return self._angle
```

两行，就是全部。**滤波器只存一个状态 `self._angle`**（和一阶低通一样省内存）。

三个细节：

1. **`bias` 减去的是零偏，不是噪声**。零偏是常值，可以标定；噪声是随机的，只能靠滤波。类里留了 `bias` 参数，但要清楚：**互补滤波不会自己估计零偏**，那是 KF 的活（Day 9–10）。不填就当 0，漂移会全部体现出来——本课就是这么做的，好让图 (a) 的漂移更明显。
2. **`dt` 必须是真实采样间隔**。它既在预测里（陀螺积分），又隐含在 α 的物理意义里，`dt` 错了等于两个地方同时错。
3. **构造时校验 α ∈ (0,1)、dt > 0**，避免 `α=1` 时除零（`tau` 属性里 `1-α` 在分母上）。

### 5.2 三个体检属性

```python
@property
def tau(self):           # τ = dt·α/(1-α)
@property
def cutoff_hz(self):     # 离散域精确 -3dB，与 Day 3 同一个式子
@property
def angle(self):         # 当前估计
```

`cutoff_hz` 直接复用了 Day 3 的精确解公式（把 `α' = 1-α` 代进去）。**这不是巧合**——加速度计那一路本来就是一阶低通，公式当然一样。

### 5.3 仿真：怎么造出"两个都不靠谱的传感器"

```python
angle_true = amp * np.sin(2π·f_tilt·t)                    # 真实角度
rate_true  = amp * 2π·f_tilt * np.cos(2π·f_tilt·t)        # 解析求导，不用差分

gyro  = rate_true + gyro_bias + gyro_noise·randn(n)       # 零偏 + 白噪声
accel = angle_true + accel_noise·randn(n)                 # 同一个角度，但噪声大得多
```

本课参数：

- 真实运动：20° 幅值、0.05 Hz（30 秒走 1.5 个周期，缓慢倾斜）
- 陀螺：零偏 **0.5 °/s**、噪声 0.1 °/s
- 加速度计：噪声 **1.5 °**（是陀螺噪声的 15 倍）

> 为什么零偏取 0.5 °/s？因为它足够小、看起来"挺准"，但 30 秒后会累积成 **15°** 的漂移——正好能让图 (a) 的红色曲线爬到 30° 以上，肉眼一眼看出问题。**这就是真实 MPU6050 的典型表现**。

### 5.4 三种估计的写法

```python
# ① 纯陀螺积分（不补偿零偏，模拟"没标定"）
angle_gyro[k] = angle_gyro[k-1] + gyro[k]*dt

# ② 纯加速度计
angle_acc[k] = accel[k]

# ③ 互补滤波
for k in range(n):
    angle_cf[k] = cf.update(gyro[k], accel[k])
```

三者都从同一个初值出发，保证对比公平。

## 6. 图的对应与解释（四张子图）

运行 `python examples/day5_complementary_filter.py` 生成 `docs/images/day5_complementary_filter.png`。

### 实测数据（本课参数）

| 估计方法 | RMSE（对真值） | 末态误差 |
|---|---|---|
| 纯陀螺积分 | **8.58°** | 14.83° |
| 纯加速度计 | 1.49° | 0.00° |
| **互补滤波（α=0.98）** | **0.32°** | 0.64° |

**融合后比单独用加速度计好 4.7 倍，比纯陀螺好 27 倍。** 这不是"稍微好一点"，是数量级上的改善。

### 图 (a)：时域——三条线各是什么病

- **灰色细线（纯加速度计）**：一直围着真值抖，但从不跑偏——噪声大、无漂移。
- **红色（纯陀螺积分）**：前几秒贴得很紧，然后一路往上飘，第 30 秒已经偏了 **14.8°**。这就是零偏积分的结果：`0.5 °/s × 30 s = 15°`。
- **蓝色（互补滤波）**：既贴着黑虚线（不漂），毛刺又几乎看不见（不抖）。**两边的病都没了。**

### 图 (b)：误差曲线——"为什么必须融合"

这张图比 (a) 更直接：

- 红线（陀螺）是**一条斜直线**：误差随时间线性增长，斜率就是零偏（0.5 °/s）。**只要时间够长，它一定会废。**
- 灰线（加速度计）在一个带子里抖，均值始终在 0 附近——**它不积累错误**。
- 蓝线（互补）贴着 0 走，幅度比灰线小一个数量级——**它把陀螺的"趋势"借来了，把加速度计的"绝对基准"借来了**。

### 图 (c)：α 扫描——这个旋钮的两头都是坑

- **α 太小**（0.903，fc=1.68 Hz）：加速度计的噪声大量涌进来，RMSE 0.35。
- **α 太大**（0.995，τ=1.99 s，fc=0.08 Hz）：滤波器太"黏"，跟不住 0.05 Hz 的运动，产生明显滞后，RMSE 飙到 **0.97**——比 α=0.9 还差得多。
- **最优点 α ≈ 0.961**，RMSE 0.27。
- **课本值 0.98 的 RMSE 是 0.30**，离最优只差 13%——说明 0.98 这个经验值确实靠谱，但它不是"最准"，是"最常用"。

> 这条曲线的形状值得记住：**左边缓慢上升、右边陡峭崩塌**。意思是「α 稍小一点问题不大，稍大一点会翻车」。工程上宁可取小一点。

### 图 (d)：为什么叫"互补"

- 蓝线：加速度计路径的权重 `|H_lp|`，低频 1、高频 0（低通）。
- 橙线：陀螺路径的权重 `|H_hp|`，低频 0、高频 1（高通）。
- 两条线在 `fc = 0.32 Hz` 附近交叉，**加起来恒等于 1**。
- 读法：`0.01 Hz` 处蓝线≈1 → 基本全信加速度计；`10 Hz` 处橙线≈1 → 基本全信陀螺。

**"互补"不是修辞，是一个恒等式。**

## 7. 今日要点

1. **两个传感器的错误在不同频段**：陀螺漂在低频、加速度计噪在高频。融合就是按频段分配信任。
2. **公式两步**：`pred = angle + gyro·dt`（预测），`angle = α·pred + (1-α)·accel`（修正）。
3. **它是个固定增益观测器**：`angle = pred + K(meas − pred)`，`K = 1-α`。**这就是 KF 的雏形。**
4. **α 的含义和 Day 3 相反**：Day 3 的 α 信新样本，Day 5 的 α 信陀螺。
5. **τ 与 fc 复用 Day 3 的公式**：`τ = dt·α/(1-α)`。本课 `α=0.98, dt=10ms → τ=0.49s, fc=0.32Hz`。
6. **α 必须和 dt 绑定**：200 Hz 下同样的 0.98，τ 只剩 0.245 s。
7. **"互补"是恒等式**：`H_lp + H_hp ≡ 1`，两路权重永远加起来是 1。
8. **实测收益**：RMSE 从 1.49°（纯加速度计）降到 0.32°（融合），比好 4.7 倍。
9. **不估计零偏**：互补滤波只能"压住"漂移，不能"消掉"它。真正在线估计零偏要等 Day 9–10 的二维 KF。

## 8. 速查表：α 该怎么取

| 场景 | α | 理由 |
|---|---|---|
| 慢速倾斜、振动小（倾角仪、云台） | 0.98 ~ 0.99 | 平滑优先，滞后能接受 |
| 快速摆动（平衡车、无人机） | 0.95 ~ 0.97 | 跟手优先，宁可噪声多一点 |
| 加速度计噪声很大（振动环境） | 更靠近 0.99 | 少信加速度计 |
| 陀螺零偏很大（廉价模块） | 更靠近 0.95 | 多信加速度计来压漂移 |
| 采样率从 100 Hz 改成 200 Hz | **重算 α** | 保持 τ 不变：`α = τ/(τ+dt)` |

## 9. 通向 Day 9：这个"固定增益"该怎么自动定

互补滤波的 `K = 1-α` 是**手调的常数**。它有三个问题：

1. 两个传感器的噪声比变了（换了模块、改了采样率），K 就该跟着变，得重新调；
2. 陀螺的零偏是**未知且缓慢变化**的，固定 K 只能压住漂移、无法估计它；
3. 没有"我对自己有多确定"的度量，出错时无法自适应。

卡尔曼滤波正是解决这三件事：**用协方差 P 表达"我有多确定"，让增益 K 自动随 P 变化，并把零偏当作状态一起估**。

```
互补：      angle = pred + K·(accel − pred)            K 固定
KF：        angle = pred + K_k·(accel − pred)          K_k = P⁻/(P⁻+R) 随协方差变
二维 KF：   状态从 [angle] 扩成 [angle, bias]，零偏自动估出来
```

**你今天写的这 10 行，就是 Day 9 那个 40 行 KF 的骨架。**

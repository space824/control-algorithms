> **范围**：位置式 PID、增量式 PID、一阶低通、二阶低通、互补滤波、离散化
> **一句话**：前五天教的是「怎么算 u 和 y」，第六天补的是「这些公式里的 dt 从哪来、该多大」。
> 本文只留结论，推导都在对应的每日文档里。

## 1. 一条主线

五套算法的代码结构其实是同一个：**两三个乘加 + 一两个状态**。

| 算法 | 唯一的状态 |
|---|---|
| 位置式 PID | 积分器 `I`（外加两个误差历史） |
| 增量式 PID | 上一次输出 `u[k−1]` |
| 一阶低通 | 上一次输出 `y[k−1]` |
| 二阶低通 | 四个：`x[k−1]、x[k−2]、y[k−1]、y[k−2]` |
| 互补滤波 | 上一次角度 `angle[k−1]` |

状态越少，越好往单片机上搬。

## 2. 六天总表

| Day | 算法 | 核心式子 | 旋钮 | 精华一句 |
|---|---|---|---|---|
| 1 | 位置式 PID | `u = Kp·e + Ki·Σe·dt + Kd·Δe/dt` | Kp / Ki / Kd | 输出绝对量；靠独立积分器，会 windup |
| 2 | 增量式 PID | `Δu = Kp·Δe + Ki·e·dt + Kd·Δ²e/dt` | Kp / Ki / Kd | 只输出增量；无积分器但有积分作用 → 天然抗饱和 |
| 3 | 一阶低通 | `y = α·x + (1−α)·y[k−1]` | α（新样本权重） | −20 dB/dec；`τ = dt(1−α)/α` |
| 4 | 二阶低通 | `y = b0x + b1x[k−1] + b2x[k−2] − a1y[k−1] − a2y[k−2]` | fc、Q（0.7071 = 巴特沃斯） | −40 dB/dec；超调 4.32% |
| 5 | 互补滤波 | `angle = α·(angle + gyro·dt) + (1−α)·accel` | α（陀螺权重，和第 3 天相反） | 低通 + 高通 = 1；固定增益观测器 |
| 6 | 离散化 | `(Ad, Bd)`：前向欧拉 / 后向欧拉 / ZOH | Ts | 前向欧拉会炸；ZOH 精确；Ts 跟闭环速度走 |

## 3. 必须记住的六个数字

| 数字 | 是什么 |
|---|---|
| **4.32%** | 巴特沃斯阶跃超调，`exp(−π)` |
| **1.5 dB** | 同 fc 下二阶对**白噪声**只比一阶强这么多（几乎打平） |
| **11.2 dB** | 120 Hz **窄带干扰**处二阶的优势（这才是它值钱的地方） |
| **0.32°** | 互补滤波 RMSE（纯加速度计 1.49°，纯陀螺 8.58°） |
| **14.83°** | 纯陀螺积分 30 s 的漂移量 = 0.5 °/s × 30 s |
| **2/a** | 前向欧拉的 Ts 上限，过了就发散 |

## 4. 六个坑

1. **增量式漏写 dt** —— 积分增益 ×100，不是 ×10（dt = 0.01）。
2. **biquad 里的 `−a1·y[k−1]`** —— 少一个负号就变成正反馈，直接发散。自检看直流增益是否为 1。
3. **`from_cutoff` 遇到 fc ≥ fs/2** —— α = 0，滤波器冻结，输出永远停在初值。
4. **「增量式没有积分器」被误记成「没有积分」** —— 它是「积分状态的载体被夹住了」，积分作用一点没少。
5. **同一个 α，采样率翻一倍** —— τ 减半、fc 翻倍，滤波强度直接变一半。
6. **前向欧拉 Ts > 2/a** —— 从「慢」直接跳过「振」到「炸」；不是变差，是发散。

---

## 5. 三句话

1. **所有算法都是「两三个乘加 + 一两个状态」的递推**，状态越少越好上板子。
2. **每个 α / dt 都必须配采样率才有意义**。同一个 0.98，100 Hz 和 200 Hz 是两个滤波器；同一个 Ki，dt 漏写就是 100 倍的错。
3. **滤波器的收益要和噪声类型对齐**。白噪声下升阶没用（1.5 dB），窄带干扰下升阶大赚（11.2 dB）——选错场景会觉得"白学了"。

2×2 四张子图，分两组：

- **(c)(d) 下半行**：一阶系统 + 输出限幅(0,1)，设定值先 3、5 秒后降到 0.5，演示**积分饱和**。
  - (c) = 输出 y，(d) = 控制量 u。

## 2. 二阶系统参数 ζ / ωn / b 变化对图的影响（全新内容）

Day 2 引入了二阶系统，它有三个参数。它们变的时候，图 (a)(b) 会怎么变：

### 2.1 ζ（阻尼比）—— 决定「振荡多剧烈」

| ζ 变化 | 图 (a) 里的表现 |
|--------|----------------|
| **↓ 减小**（更欠阻尼） | 曲线来回穿越虚线的**次数更多、衰减更慢**，像弹簧晃不停；ζ=0 时**等幅振荡**永远不停 |
| **↑ 增大** | 振荡减弱；ζ≥1 时**完全不超调**（曲线单调爬上去，不冲过头） |

**记法**：ζ 就是「减震器」的强弱。减震越差（ζ 小），越晃。

### 2.2 ωn（自然频率）—— 决定「振荡多快」

| ωn 变化 | 图 (a) 里的表现 |
|---------|----------------|
| **↑ 增大** | 振荡**更快**（波形变密、频率高），整体响应也更快 |
| **↓ 减小** | 振荡**变慢**（波形稀疏、懒洋洋） |

**记法**：ωn 就是「弹簧的硬度」。弹簧越硬，弹得越快。

### 2.3 b（输入增益）—— 决定「输入多有效」

| b 变化 | 图 (a) 里的表现 |
|--------|----------------|
| **↑ 增大** | 同样的 u，输出 y 变化更大，曲线**响应更快、爬得更高** |
| **↓ 减小** | 同样的 u 只换来很小的 y，曲线**爬不动** |

## 3. PID 参数变化对 Day 2 各图的影响（针对这四张图）

| 参数变化 | 图里的表现 |
|---------|-----------|
| **Kp ↑** | (a) 里超调更大、振荡更剧烈；(b) 里 t=0 那根**尖峰更高** |
| **Kd ↑** | (a) 里振荡被**压制**（来回幅度变小，因为 D 提供了刹车力）；但 (b) 里 u 曲线出现**抖动** |
| **Ki ↑** | (c)(d) 里积分饱和更严重——位置式**松开限幅后超调更大、振荡更久** |

**关键点**：在二阶系统上，D 的「刹车」作用终于体现出来了——把 Kd 调大，图 (a) 里
位置式那种来回晃会被明显压小。这正是 Day 1 看不到、Day 2 才看得到的效果。

---

## 4. 四张图的核心读法（一句话版）

- **(b) 里那根竖直尖峰 = 微分冲击**：设定值阶跃瞬间 `de/dt` 爆炸，u 被猛地顶一下（冲到 33）。**两种形式都有这根刺，而且一样高**——增益配平后它们是等价的。要消除它，得改用「微分先行」（让 D 作用在测量值上）。
- **(d) 里位置式表面停在 u=1，内里积分在偷偷涨**：这就是「积分饱和」的藏身之处——u 没动，但欠账在累积。
- **(c) 里 5 秒松开后位置式冲过头再回落**：就是「还欠账」的过程；增量式没有欠账，干净落回。

## 5. 调参 → 看图 速查表（两天通用）

遇到图上的问题，先看症状，再对症调参：

| 图上的症状 | 原因 | 怎么办 |
|-----------|------|--------|
| 曲线停在虚线下方，够不着 | 静差（P 不够或没 I） | **加大 Ki**（或引入 I） |
| 曲线冲过虚线太高 | 超调大 | **加大 Kd**（刹车）或 **减小 Kp** |
| 曲线来回摆不停 | 振荡 | **加大 Kd**（阻尼）或 **减小 Kp** |
| 响应太慢、爬得肉 | 力度不够 | **加大 Kp** |
| 松开限幅后冲过头 | 积分饱和 | 位置式**加抗饱和**，或改用**增量式** |
| u 曲线有毛刺/抖动 | D 对噪声敏感 | **减小 Kd**，或对微分项加滤波 |

## 6. 动手试玩：改哪个数、看什么变化（「怎么玩」）

### 6.1 该调的旋钮在哪

打开 `examples/day2_incremental_pid.py`，有两处可改：

```python
gains = dict(kp=3.0, ki=2.0, kd=0.3)   # ① 控制器增益，两组对比共用
# ② 被控对象：SecondOrderPlant 的构造参数
#    SecondOrderPlant(zeta=0.3, wn=2.0, b=4.0, dt=0.01)
```

改任意一个数字 → 保存 → 重跑 `python examples/day2_incremental_pid.py` → 看新图 `docs/images/day2_incremental_pid.png`。**一次只改一个数。**

### 6.2 各参数的作用（一句话版）

- **Kp / Ki / Kd**：同 Day 1（快 / 准 / 稳）。但今天换成了**会振荡的二阶系统**，**D 的「刹车」作用终于显形**。
- **ζ（阻尼比）**：二阶系统「减震器」强弱，决定「会不会振荡、晃多狠」。
- **ωn（自然频率）**：二阶系统「弹簧硬度」，决定「振荡多快」。
- **b（输入增益）**：同样的 u 能换来多大变化，b 越大越好推。

### 6.3 试玩清单（改 → 跑 → 看）

| 编号 | 改哪个数 | 图上会看到什么变化 |
|------|----------|-------------------|
| 1 | `SecondOrderPlant` 的 zeta `0.3` → `0.05` | 图 (a) 振荡**剧烈得多**：来回穿越虚线更多次、衰减更慢，像弹簧停不下来 |
| 2 | zeta `0.3` → `1.5` | 图 (a) **完全不超调**：曲线单调爬上去、不冲过头（过阻尼） |
| 3 | wn `2.0` → `5.0` | 图 (a) 波形**变密变快**（振荡频率高），整体更快到位 |
| 4 | b `4.0` → `1.0` | 图 (a) 同样 u，输出**爬得更慢更低** |
| 5 | `gains` 的 kp `3.0` → `6.0` | 图 (a) 超调**更大**、振荡更猛；图 (b) t=0 那根尖峰**更高** |
| 6 | `gains` 的 kd `0.3` → `1.5` | 图 (a) 振荡被**明显压小**（刹车更强）；但图 (b) u 出现**抖动/毛刺** |
| 7 | `limits` `(0,1)` → `(0,0.5)` | 图 (c)(d) 饱和**更早**，位置式松开限幅后的超调**更夸张**，增量式仍干净落回 |

> 玩 1、2 是理解「阻尼比 ζ」最快的办法：ζ 从 0.05 拧到 1.5，图就从「疯狂晃」变成「老实爬」。
> 玩 5、6 对应口诀「D 管稳」：Kd 加大，(a) 不晃了，但 (b) 的 u 开始抖——稳和毛糙是一体两面。

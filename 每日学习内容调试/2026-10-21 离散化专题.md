## 1. 三条离散路线

统一的对象（连续时间状态空间）：

```
ẋ(t) = A·x(t) + B·u(t)
```

目标：求一个递推式

```
x[k+1] = Ad·x[k] + Bd·u[k]
```

三条路线的差别，全在 `(Ad, Bd)` 怎么算出来。

### 1.1 前向欧拉（forward Euler / 显式欧拉）

用**区间左端**的斜率走一整步：

```
x[k+1] = x[k] + Ts·(A·x[k] + B·u[k])

Ad = I + Ts·A
Bd = Ts·B
```

- 最省：一次矩阵乘加，不用求逆、不用矩阵指数；
- **可能不稳定**：一阶对象 `ẋ = -a·x` 时 `Ad = 1 - a·Ts`，只要 `Ts > 2/a` 就 `|Ad| > 1`，数值直接发散；
- 精度一阶：误差 ∝ Ts。

也顺手解释了你前五天一直写的那句 `x += dt * f(x)` —— 那就是前向欧拉。

### 1.2 后向欧拉（backward Euler / 隐式欧拉）

用**区间右端**的斜率：

```
x[k+1] = x[k] + Ts·(A·x[k+1] + B·u[k])

Ad = (I - Ts·A)⁻¹
Bd = (I - Ts·A)⁻¹·Ts·B
```

- 每步要解一个线性方程组（`(I - Ts·A)⁻¹` 可以离线算好，运行时只做矩阵乘）；
- **无条件稳定**：只要连续系统稳定（A 的特征值在左半平面），离散后一定也稳定，**不管 Ts 取多大**；
- 精度同样是一阶，但误差方向和前向欧拉**相反**（见 §3）。

### 1.3 零阶保持 ZOH（Zero-Order Hold）—— 嵌入式里真正用的那个

关键假设：**u 在每个采样区间 `[kTs, (k+1)Ts)` 内保持不变**。

这个假设不是数学上的权宜之计，而是**硬件的事实**：单片机的 PWM 占空比在两次更新之间就是恒定的，DAC 输出也是阶梯状的。既然 u 真的不变，就可以把这段区间的微分方程**精确解出来**：

```
x[k+1] = e^{A·Ts}·x[k] + (∫₀^{Ts} e^{A·τ} dτ)·B·u[k]

Ad = e^{A·Ts}
Bd = ∫₀^{Ts} e^{A·τ} dτ · B
```

- 输入真的恒定时，**它是精确的**（误差 0，不是"更小"）；
- 保稳定：连续稳定 → 离散稳定；
- 代价：要算矩阵指数，但**可以离线算好、烧进固件**，运行时和欧拉一样便宜（一次矩阵乘加）。

**Bd 怎么算不用手推积分**：把 A、B 拼成增广矩阵

```
M = [ A  B ]
    [ 0  0 ]

则  e^{M·Ts} = [ Ad  Bd ]
                [ 0   I ]
```

一次矩阵指数同时拿到 Ad 和 Bd。这就是 `discretize.py` 里 `zoh()` 的做法。

## 2. 三条路线的本质区别

| | 前向欧拉 | 后向欧拉 | ZOH |
|---|---|---|---|
| 用哪端斜率 | 左端 | 右端 | 不用斜率，直接解 |
| 计算量 | 最省 | 要矩阵求逆（可离线） | 要矩阵指数（可离线） |
| 精度 | 一阶（∝Ts） | 一阶（∝Ts） | **精确** |
| 稳定性 | **Ts 有上限** | 无条件稳定 | 无条件稳定 |
| 误差方向 | 偏大 | 偏小 | 无 |
| 嵌入式里代表性 | 教学/快速原型 | 少见 | **最常用** |

一句话：**前向欧拉最省但会炸；后向欧拉稳但只是近似；ZOH 精确，而且它的假设在硬件上恰好成立。**

## 3. 实测：两个欧拉的误差符号是相反的

参数：一阶对象 `ẋ = -x + u`（时间常数 T = 1 s），单位阶跃，`Ts = 0.1 s`。

| 路线 | 最大误差（对解析解 `1-e^{-t}`） |
|---|---|
| 前向欧拉 | **+0.0192**（偏高） |
| 后向欧拉 | **−0.0177**（偏低） |
| ZOH | **7.8e-16**（机器精度，等于 0） |

**为什么一个偏高一个偏低**：对象响应是**上凸**的（斜率越来越小）。

- 前向欧拉用左端斜率走一整步 → 起点斜率大，走过头 → **偏高**；
- 后向欧拉用右端斜率 → 终点斜率小，走不够 → **偏低**。

幅度差不多（0.019 vs 0.018），符号相反。这就是图 (a) 里一条在零线上、一条在零线下的原因。

> 这个「相反」有个实用价值：两种欧拉可以互相估计误差量级。如果两者差很多（比如差 5 倍以上），说明 Ts 已经太大了，该考虑换 ZOH。

## 4. 稳定性：前向欧拉的生死线

一阶对象 `ẋ = -a·x`，前向欧拉给出 `Ad = 1 - a·Ts`。要稳定，必须

```
|1 - a·Ts| < 1   ⟺   0 < Ts < 2/a
```

本课 `a = 1`，所以界限是 **Ts < 2 s**。图 (b) 画了四个 Ts：

| Ts | Ad = 1−Ts | 行为 |
|---|---|---|
| 0.5 | +0.5 | 收敛，但一阶慢（每拍衰减一半） |
| 1.0 | 0.0 | **一拍就到终值**（deadbeat），之后再不动 |
| 1.5 | −0.5 | 收敛，但**符号交替**（一拍上、一拍下）地衰过去 |
| **2.1** | **−1.1** | **发散**，振幅每拍涨 10%，几十拍后冲到 ±40 |

这就是前向欧拉最经典的坑：**`Ts` 稍大一点点，从"慢"直接跳过"振"到"炸"**。而且 `Ts = 1.0` 那个 deadbeat 很迷惑——它看起来"最快最好"，其实是在稳定边缘上，稍微再大一点就翻脸。

**后向欧拉和 ZOH 没有这条线**：只要连续系统本身稳定，`Ts` 再大也不会发散（当然精度会变差、响应会失真）。

## 5. 采样周期怎么选

三条独立的判据，取三者中最严的那条：

### 5.1 数值稳定性（只对前向欧拉）

```
Ts < 2/|λ|max          λmax = A 里最快的那个特征值
```

本课 λ = −1 → Ts < 2 s。这条通常很宽松，**不是瓶颈**。

### 5.2 精度（对所有方法）

```
经验法则：Ts ≤ T/10 ~ T/20        T = 对象最短的时间常数
```

一阶是 1 s，取 T/10 就是 100 ms 上限；取 T/20 是 50 ms。

### 5.3 闭环性能（最严的一条）

图 (d) 是这一条的证据：二阶对象 + PI，`Kp=3, Ki=6`，让它带 **1 拍计算延迟**（真实 MCU 就是这样：这一拍采样、下一拍才输出）。

| Ts | 超调 | 峰值 | 上升时间 |
|---|---|---|---|
| 10 ms | 40.4% | 1.40 | 740 ms |
| 40 ms | 45.5% | 1.46 | 720 ms |
| 100 ms | **57.9%** | 1.58 | 700 ms |
| 200 ms | **83.9%** | 1.84 | 600 ms |

同一个控制器、同一个对象，**只把 Ts 从 10 ms 放大到 200 ms，超调就从 40% 涨到 84%**。

**原因不是"算得粗"，而是"延迟变大"**：

- 1 拍计算延迟 = 1 个 Ts 的纯延迟；
- Ts 从 10 ms 涨到 200 ms，这个纯延迟就涨了 20 倍；
- 纯延迟吃相位裕度 → 超调涨 → 再大就振荡 → 再大就发散。

这就是**采样率不能随便降**的真正原因：它不只是"精度"问题，是"稳定性"问题。

> 补充一条常被忽略的：ZOH 本身相当于额外引入约 **Ts/2** 的等效延迟（输出是阶梯，平均晚了半个周期）。所以实际的总延迟 ≈ 1.5·Ts。这也是为什么控制周期要尽量短。

## 6. 代码实现（逐段）

### 6.1 矩阵指数：不依赖 scipy 自己写

```python
def expm(A, terms=18):
    norm = np.linalg.norm(A, np.inf)
    s = 0 if norm <= 1.0 else int(np.ceil(np.log2(norm)))
    As = A / (2.0 ** s)

    E = np.eye(A.shape[0])
    term = np.eye(A.shape[0])
    for k in range(1, terms + 1):
        term = term @ As / k
        E = E + term

    for _ in range(s):
        E = E @ E
    return E
```

**为什么要"缩放-平方"**：泰勒级数 `e^A = Σ Aᵏ/k!` 只在小矩阵上收敛快。A 的范数一大，需要的项数就爆炸。所以先把 A 除以 `2^s` 让它变小，算完再平方 `s` 次还原——这是所有数值库（含 MATLAB 的 `expm`）的标准做法。

`terms=18` 对 1~6 阶矩阵足够；本课实测 ZOH 误差 7.8e-16，说明精度到机器极限。

### 6.2 ZOH：用增广矩阵一次算出 Ad 和 Bd

```python
def zoh(A, B, Ts):
    n, m = A.shape[0], B.shape[1]
    M = np.zeros((n + m, n + m))
    M[:n, :n] = A
    M[:n, n:] = B
    E = expm(M * Ts)
    return E[:n, :n], E[:n, n:]
```

不用手推 `∫e^{Aτ}dτ`：把 B 塞进右上角，矩阵指数会**自动**把积分算出来。

## 7. 图的对应与解释（四张子图）

### 图 (a)：误差曲线——两个欧拉一上一下

- 橙线（前向欧拉）在零线**上方**，峰值 +0.0192；
- 绿线（后向欧拉）在零线**下方**，谷值 −0.0177；
- 蓝线（ZOH）贴着零线，误差 1e-16（就是浮点噪声）。

**读法**：两条欧拉线的形状几乎镜像，说明它们的误差量级相同、方向相反。ZOH 不是"更好"，是"对采样点而言没有误差"。

### 图 (b)：前向欧拉的生死线

- 四条曲线对应 Ts = 0.5 / 1.0 / 1.5 / 2.1；
- Ts=1.0（橙）一拍到位后不动——deadbeat；
- Ts=1.5（绿）上下交替衰减；
- **Ts=2.1（红）每拍涨 10%，几十拍后冲到 ±40** —— 越过了 `Ts < 2/a` 这条线。

### 图 (c)：误差随 Ts 的变化（双对数）

- 两条欧拉线都是**斜率 1 的直线**：误差 ∝ Ts，这就是"一阶精度"的图形含义；
- ZOH 一直是 1e-14 量级（贴着浮点极限），**与 Ts 无关**；
- 红色竖虚线标出 `Ts = 2/a`：过了这条线，前向欧拉开始发散。

**读法**：想要精度，把 Ts 减半就能把欧拉误差减半；想彻底摆脱这个依赖，换 ZOH。

### 图 (d)：闭环——Ts 的真实代价

- 黑虚线是 Ts=2 ms 的参考响应；
- 另外四条是 10/40/100/200 ms；
- Ts 越大，**第一个峰越高**（1.40 → 1.84），后面的振荡也越大。

**读法**：对象和控制器的参数一个字没改，只是采样变慢，系统就从"有点超调"变成"明显振荡"。这就是 §5.3 说的"延迟效应"。

## 8. 今日要点

1. **三条路线只差 `(Ad, Bd)` 怎么算**：前向欧拉 `(I+TsA, TsB)`，后向欧拉 `((I-TsA)⁻¹, …)`，ZOH `(e^{ATs}, ∫e^{Aτ}dτ·B)`。
2. **前向欧拉有稳定性上限 `Ts < 2/|λ|`**，越过就发散；后向欧拉和 ZOH 无条件稳定。
3. **两个欧拉的误差方向相反**（本课 +0.0192 vs −0.0177），幅度相近；ZOH 对采样点精确（1e-16）。
4. **欧拉是一阶精度**（误差 ∝ Ts），ZOH 精确——因为它的假设（u 在一个周期内恒定）在硬件上真的成立。
5. **ZOH 用增广矩阵算**：`e^{[[A,B],[0,0]]·Ts}` 的右上块就是 Bd。
6. **采样周期由三条判据决定**：稳定性（`2/|λ|`）、精度（`T/10~T/20`）、闭环性能（最严）。实际取三者中最小的。
7. **Ts 变大不只是"算得粗"，更是"延迟变大"**：1 拍计算延迟 = 1 个 Ts，ZOH 还额外约 Ts/2。本课超调从 40% 涨到 84%。
8. **矩阵指数可以自己写**：缩放-平方 + 泰勒，20 行 numpy，不用 scipy。

## 9. 速查表：该用哪条路线

| 场景 | 用哪个 | 理由 |
|---|---|---|
| 写控制/滤波的实时循环 | **ZOH**（离线算好 Ad/Bd） | 精确、稳定、运行时和欧拉一样便宜 |
| 快速试算、教学演示 | 前向欧拉 | 一行搞定，只要 Ts 足够小 |
| 对象很"硬"、Ts 被迫放大 | 后向欧拉或 ZOH | 前向欧拉会炸 |
| 传递函数形式的滤波器 | 双线性变换（Tustin） | 保稳定，且 -3dB 点可以精确预畸变（Day 4 已经用过） |
| 只想和现成仿真对答案 | `scipy.signal.cont2discrete` | 结果和本课 `zoh()` 一致，装了 scipy 就能交叉验证 |

## 1. Day 4 图的结构（`day4_second_order_lowpass.png`）

2×2 四张子图，分两组：

- **(a)(b) 上半行**：时间域——「滤波后长什么样」「阶跃怎么响应」。
  - (a) = 同一段含噪正弦，一阶 vs 二阶（带放大窗），(b) = 阶跃响应对比。
- **(c)(d) 下半行**：频域——「截止频率在哪」「用延迟换噪声划不划算」。
  - (c) = 幅频响应，(d) = 延迟 vs 残余噪声的权衡曲线。

与 Day 3 的关键区别：Day 3 的旋钮是 **α（一个数）**；Day 4 的旋钮是 **fc 和 Q（两个数）**，所以图的行为更丰富，也更容易调错。

---

## 2. fc 变化对图的影响（最常用的旋钮）

| fc 变化 | (a) 时域 | (c) 幅频 | (d) 工作点位置 |
|---|---|---|---|
| **↑ 升高** | 曲线更贴噪声输入，毛刺多，滞后小 | −3 dB 点右移，整条曲线往右推 | 曲线上的点往**左上**（延迟小、噪声大） |
| **↓ 降低** | 更平滑，但整体右移（滞后大） | −3 dB 点左移 | 点往**右下**（延迟大、噪声小） |

**记法**：fc 是"分界线画在哪"。分界线往右画 → 放行更多高频 → 干净不了；往左画 → 干净但迟钝。这条和 Day 3 的 α 完全对应（α 大 ↔ fc 高）。

---

## 3. Q 变化对图的影响（今天新增的旋钮）

Q 只影响**拐点附近的形状**，不影响远端斜率（远端永远是 −40 dB/dec）。

| Q | (c) 幅频在 fc 附近 | (b) 阶跃响应 | 什么时候用 |
|---|---|---|---|
| **0.5**（ζ=1，临界阻尼） | 拐角很圆，无峰 | **无超调**，但更慢 | 指令不能振的场合 |
| **0.7071**（默认，巴特沃斯） | 最平坦，无峰 | 超调 **4.32%** | 默认选它 |
| **1.0** | 峰起 **+1.25 dB**（约 0.84·fc 处） | 超调 **16.3%**，明显来回振 | 想让"fc 附近"通过得更多 |

**记法**：Q 是「拐角的圆滑度」。Q 大 = 拐角"翘"起来 = 通带边缘更饱满，但阶跃会振；Q 小 = 拐角"塌"下去 = 稳但慢。

> 试玩时把 `q=0.7071` 改成 `q=1.0`，会在 (c) 里看到一个 +1.25 dB 的小包，(b) 里超调从 4.3% 涨到 16%。这两个数字都是解析算得出来的，可以对一下。

## 4. 其他参数变化对图的影响

### 4.1 信号频率 f_sig

| f_sig 变化 | (a) 里的表现 |
|---|---|
| **↑ 接近 fc** | 信号本身开始被衰减、明显滞后（一阶二阶都会） |
| **↓ 远低于 fc** | 信号几乎无损，只剩下噪声被滤 |

**关键**：滤波器分不清信号和噪声，只按频率切。**信号频率一旦逼近 fc，就会被当噪声一起削**。设计时保证 fc ≳ 3~10 × f_sig。

### 4.2 噪声类型（今天最重要的一条）

| 噪声类型 | (d) 里的表现 | 结论 |
|---|---|---|
| **白噪声**（铺满频谱） | 两条虚线**几乎重合** | 阶数换不来好处，用一阶就行 |
| **窄带干扰**（集中在某一频率） | 两条实线**拉得很开** | 二阶明显更优，离 fc 越远差距越大 |

**关键**：换成二阶之前，先问一句「我的噪声是白的还是集中的」。传感器的白噪声 → 一阶；PWM 纹波、工频、谐振 → 二阶。这一条如果搞反，会觉得"二阶白买了"。

### 4.3 干扰频率 f_int（示例里的 120 Hz）

| f_int 变化 | (c) 里的表现 | (d) 里的表现 |
|---|---|---|
| **↑ 远离 fc**（如 240 Hz） | 落在更陡的坡上 | 两条实线**拉得更开**（二阶优势更大） |
| **↓ 靠近 fc**（如 50 Hz） | 落在拐角附近 | 两条实线**靠近**（二阶优势变小） |

**关键**：二阶的优势是一个**随频率距离增长**的量。fc 的 2 / 4 / 8 倍处，一阶与二阶的衰减差大约是 **5 / 12 / 18 dB**。

### 4.4 采样周期 dt

| dt 变化 | 影响 |
|---|---|
| **dt ↑（采样慢）** | 同样的 fc，双线性变换的频率畸变更明显；奈奎斯特变低，fc 必须更小 |
| **dt ↓（采样快）** | 畸变减小，二阶与连续域的理论曲线几乎重合 |

**关键**：二阶对采样率比一阶敏感得多（双线性变换的 warping 是二阶效应）。经验法则：**fc ≤ fs/10**，即至少每个信号周期采 10 个点。

## 5. 四张图的核心读法（一句话版）

- **(a) 两条彩色线几乎重合**：同 fc、白噪声下，二阶并没有更干净——这是本课的"反直觉点"。
- **(b) 蓝线过冲一下再落回来**：4.32% 超调是巴特沃斯的固有代价，橙色一阶没有。
- **(c) 同一 -3 dB 点、两条不同坡度**：滚降斜率差一倍，这就是二阶唯一的硬优势。
- **(d) 虚线重合、实线分开**：白噪声打平、窄带干扰二阶碾压——一张图回答"到底该用几阶"。

## 6. 调参 → 看图 速查表

遇到图上的"症状"，对照着调：

| 图上的症状 | 原因 | 怎么办 |
|---|---|---|
| 滤波后还有明显毛刺 | fc 太高 | **降低 fc** |
| 波形错开/滞后太多 | fc 太低，或二阶相位滞后本来就大 | **升高 fc**；如果 fc 已经够高，考虑退回一阶 |
| 信号幅值变小、波形被削 | fc 接近甚至低于信号频率 | **升高 fc**，保证 fc ≳ 3×f_sig |
| (c) 里 fc 附近鼓了个包 | Q 太大（> 0.7071） | **把 Q 调回 0.7071** |
| (b) 阶跃超调太大、来回振 | Q 太大 | **Q 降到 0.5**（零超调）或 0.7071 |
| (c) 拐角太圆、过渡带很缓 | Q 太小 | 稍微**升高 Q**（别超过 0.7071） |
| (d) 虚线重合但实线没分开 | 干扰不集中，本质是白噪声 | **别用二阶**，一阶够用还省内存 |
| (d) 实线分得很开 | 典型窄带干扰 | **该上二阶**，划算 |
| 滤波器输出发散、越跑越大 | biquad 的 `a1` 符号抄错（少了负号） | 检查 `- a1*y[k-1]`，并用 `dc_gain ≈ 1` 自检 |
| 不知道该填多少 fc/Q | 想按 Hz 设计 | 用 `SecondOrderLowPass.from_cutoff(fc, dt)`，Q 默认 0.7071 |

## 7. 动手试玩：改哪个数、看什么变化

### 7.1 该调的旋钮在哪

打开 `examples/day4_second_order_lowpass.py`，核心可改的是 `main()` 顶部这几个数：

```python
dt = 0.001          # 采样周期 1ms
f_sig = 3.0         # 正弦信号频率 3Hz
f_int = 120.0       # 窄带干扰频率
fc = 35.7           # 截止频率（与 Day 3 的 α=0.2 对应）
noise_std = 0.4     # 白噪声标准差
```

二阶专属的 Q 在类构造里：

```python
lp2 = SecondOrderLowPass.from_cutoff(cutoff_hz=fc, dt=dt, q=0.7071)
```

改任意一个 → 保存 → 重跑 `python examples/day4_second_order_lowpass.py` → 看新图。**一次只改一个数。**

### 7.2 各参数作用（一句话版）

- **fc（截止频率）**：分界线画在哪。高 → 跟手但毛糙；低 → 干净但滞后。
- **Q（品质因数）**：拐角圆不圆。0.7071 = 最平坦（巴特沃斯，超调 4.32%）；0.5 = 零超调但更慢；1.0 = 鼓起 +1.25 dB、超调 16.3%。
- **f_sig**：信号频率。逼近 fc 就会被削。
- **f_int**：干扰频率。离 fc 越远，二阶的优势越大。
- **dt**：采样周期。二阶比一阶更挑采样率，保证 fc ≤ fs/10。
- **noise_std**：噪声强度。只影响"绝对毛刺量"，不改变上面的规律。

### 7.3 试玩清单（改 → 跑 → 看）

| 编号 | 改哪个数 | 图上会看到什么 |
|---|---|---|
| 1 | `fc` 35.7 → 10 | (c) 两条曲线一起左移；(a) 两条都更平滑但滞后明显变大 |
| 2 | `fc` 35.7 → 150 | (a) 曲线贴住噪声输入；(d) 工作点移到左上角 |
| 3 | `q=0.7071` → `0.5` | (b) 超调消失、但爬得更慢；(c) 拐角变圆 |
| 4 | `q=0.7071` → `1.0` | (b) 超调涨到约 16%，来回振；(c) fc 附近鼓出 +1.25 dB 的包 |
| 5 | `f_int` 120 → 50 | (d) 两条实线互相靠近（二阶优势变小） |
| 6 | `f_int` 120 → 240 | (d) 两条实线拉得更开（二阶优势变大） |
| 7 | `f_sig` 3 → 30 | (a) 信号本身被衰减、滞后明显——逼近 fc 了 |
| 8 | `dt` 0.001 → 0.005 | 奈奎斯特降到 100 Hz，(c) 高频段曲线与理论偏差变大 |
| 9 | 把 `noise_std` 改成 0，只留 `f_int` | (a) 只剩 120 Hz 干扰，一阶几乎滤不掉、二阶滤得很干净 —— **最能说明二阶价值的一个实验** |

> 第 9 条是这个项目里最值得做的对比实验：**把白噪声关掉，只留一个 120 Hz 正弦干扰**，你会看到一阶几乎无能为力、二阶却干净利落。这就是"窄带干扰 vs 白噪声"的差别，比任何文字都直观。

## 8. 和 Day 3 的对照

| | Day 3（一阶） | Day 4（二阶） |
|---|---|---|
| 旋钮 | α 一个 | fc + Q 两个 |
| 幅频斜率 | −20 dB/dec | −40 dB/dec |
| 阶跃超调 | 0% | 4.32%（巴特沃斯） |
| 白噪声下的性价比 | **高** | 低（打平还要付延迟） |
| 窄带干扰下的性价比 | 低 | **高** |
| 状态数（MCU 内存） | 1 | 4 |

**一句话**：一阶是"够用就好"的默认选项；二阶是"知道干扰在哪、愿意付延迟"时的精准武器。

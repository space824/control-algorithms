## 0. 今天的新问题：一个输入一个输出，藏起了什么

前七天写的所有对象，全都是同一个形状：

```python
y = alpha * x + (1 - alpha) * y        # Day 3  一阶低通
y = b0*x + b1*x1 + b2*x2 - a1*y1 - a2*y2   # Day 4  二阶低通
angle = alpha*(angle + gyro*dt) + (1-alpha)*accel_angle   # Day 5  互补滤波
```

**一个数进去，一个数出来。** 这种写法很方便，但它偷偷做了一个假设：系统内部"只有一个量在动"。

真实对象几乎都不是这样：

- 直流电机里，**电流**和**转速**同时在动，而且互相耦合（电流产生转矩，转速产生反电动势）；
- 倒立摆里，**摆角、摆角速度、小车位置、小车速度**四个量同时在动；
- 你 Day 4 写的那个 biquad，代码里只有 `y`，但它内部其实有 **4 个记忆量**（x[k-1]、x[k-2]、y[k-1]、y[k-2]）。

状态空间干的事，就是把这些"内部正在动的量"**显式地摆出来**：

```
ẋ = A·x + B·u       # 内部怎么演化
y = C·x + D·u       # 从哪一路读出去
```

就两行。代价是要处理矩阵，好处是**你终于能看见系统内部**——包括那些你没有传感器的量。

**为什么这一天必须单独占一天**：Day 9 的卡尔曼滤波要估的就是 `x`；Day 15 的 LQR 要乘的也是 `x`；Day 18 的 MPC 预测的还是 `x`。如果 `x` 是什么没弄清楚，后面三周全是背公式。

## 1. 状态是什么：三个判据

教科书会先给定义再给你例子，这里反过来——**先给判据，能过三关的就是一组状态**。

### 1.1 判据一：足够

> 知道 `x[k]`，再加上未来的输入 `u[k], u[k+1], …`，就能算出未来所有的 `y`。

换句话说：**状态是系统的全部记忆**。给了状态，历史就不重要了。

这是最本质的一条。PID 里的积分项 `integral` 就是一个状态——因为它记住了"过去所有误差的累积"；滤波器的 `y[k-1]` 也是状态——因为它记住了"上一次的输出"。

### 1.2 判据二：彼此独立

> 任意两个状态之间，不能存在代数关系。

如果 `x2 = 3·x1`，那 `x2` 就是多余的，约掉它。这条保证了"个数最少"。

### 1.3 判据三：最少 —— 个数等于分母的阶数

> 状态的最少个数 = 传递函数分母的阶数。

这条最实用，**看到分母就能立刻知道有几个状态**：

| 对象 | 传递函数 | 状态数 |
|---|---|---|
| 一阶低通（Day 3） | `1/(Ts+1)` | 1 |
| 二阶低通 biquad（Day 4） | `ωn²/(s²+ (ωn/Q)s + ωn²)` | 2 |
| 质量-弹簧-阻尼 | `1/(ms² + cs + k)` | 2 |
| 直流电机（电流+转速） | `Kt/(LJs² + (RJ+Lb)s + Rb + KeKt)` | 2 |
| 倒立摆（线性化后） | 4 阶 | 4 |

⚠️ 注意第 2 行：Day 4 的 biquad 在代码里有 4 个记忆量（x1、x2、y1、y2），但**状态是 2 个**——因为 4 个记忆量里有两个是冗余的（由另外两个决定）。这就是判据二在起作用。**"代码里存了几个变量"和"系统有几个状态"不是一回事。**

## 2. 从物理方程写 A、B、C、D（质量-弹簧-阻尼）

拿最经典的例子：一个质量块挂在弹簧上，带阻尼。

```
m·ẍ + c·ẋ + k·x = F        # 牛顿第二定律，F 是外力（我们的输入 u）
```

`m = 1 kg`、`k = 4 N/m`、`c` 是阻尼系数（后面当旋钮用）。

### 2.1 第一步：选状态

一个二阶方程 → 两个一阶方程，标准做法是**"位置和速度"**：

```
x1 = x        （位移）
x2 = ẋ        （速度）
```

这不是唯一选法（也可以选"位移和加速度"），但选物理量做状态的好处是**它们有物理含义**，后面设计观测器、LQR 时能讲得通。这是本课的第一个手艺。

### 2.2 第二步：把二阶方程拆成两个一阶

```
ẋ1 = x2                              （位移的导数就是速度）
ẋ2 = -(k/m)·x1 - (c/m)·x2 + (1/m)·F  （从原方程解出 ẍ）
```

### 2.3 第三步：抄成矩阵

```
⎡ẋ1⎤   ⎡   0       1  ⎤ ⎡x1⎤   ⎡  0  ⎤
⎢   ⎥ = ⎢              ⎥ ⎢  ⎥ + ⎢     ⎥ · F
⎣ẋ2⎦   ⎣ -k/m    -c/m ⎦ ⎣x2⎦   ⎣ 1/m ⎦
```

于是：

```python
A = [[0, 1], [-k/m, -c/m]]
B = [[0], [1/m]]
```

**A 的第一行 `[0, 1]` 就是"ẋ1 = x2"这句话**；第二行是从原方程抄下来的系数。你不需要背任何"标准型"，照着方程抄就行。

### 2.4 C 是"你有哪个传感器"

```
y = C·x
```

同样一个系统，`C` 不同就是不同的传感器配置：

| C | 输出 | 物理含义 |
|---|---|---|
| `[1, 0]` | 位移 | 你装了编码器/激光位移计 |
| `[0, 1]` | 速度 | 你装了测速发电机 |
| `[[1,0],[0,1]]` | 两个都测 | 你两个都装了（那就不需要观测器了） |

这是本课最容易被忽略的一点：**A、B 是对象的物理属性，C 是你的选择。** 同一个对象，换个传感器，C 就变了，可控性不变但可观性会变。

`D` 是"输入直接穿到输出"的那一部分。真实系统有惯性，输入不会瞬间改变输出，所以**本课所有对象 `D = 0`**。它存在只是为了数学完整（比如一个纯电阻的比例环节）。

## 3. 四个矩阵各管什么

| 矩阵 | 管什么 | 一句话 | 本课的取值 |
|---|---|---|---|
| **A** | 系统自己怎么演化 | 决定极点、稳定性、振荡频率——**最关键的一个** | 从物理方程抄 |
| **B** | 输入从哪个门进来 | "我这一脚踹在哪" | 从物理方程抄 |
| **C** | 从哪一路读出去 | 传感器配置 | 你来选 |
| **D** | 输入直接穿到输出 | 真实系统一般都 0 | 全 0 |

一句话记法：**A 是"本性"，B 是"入口"，C 是"窗口"，D 是"直连"。**

对本课的系统，`B = [0, 1/m]ᵀ` 意味着：**力只能直接推速度，推不了位移**——位移是被速度"积分"出来的。这一点在 Day 9 设计观测器时很重要。

## 4. 和传递函数是同一件事（能控标准型）

状态空间和传递函数是同一个系统的两套写法，可以互相换算：

```
G(s) = C·(sI − A)⁻¹·B + D
```

**任何一个传递函数，都能机械地转成 A、B、C、D**，方法叫"能控标准型"。给定

```
G(s) = (b1·s + b0) / (s² + a1·s + a0)
```

直接写：

```
A = [[-a1, -a0],      B = [[1],      C = [b1, b0],    D = 0
     [  1,   0]]            [0]]
```

注意 **A 的第一行就是分母的系数取负**，这是能控标准型的标志。本课代码里的 `canonical_from_transfer()` 就是把这件事自动化了，包括分子分母同阶（有直通项）的情形。

**两种写法的取舍：**

| | 传递函数 | 状态空间 |
|---|---|---|
| 多输入多输出 | 麻烦（要一个 G 矩阵，每个元素一个式子） | 天然（B、C 加维度就行） |
| 初值问题 | 不好处理（传递函数假设初值为零） | 天然（x₀ 直接给） |
| 内部状态 | **看不见** | 全都在 x 里 |
| 手算稳定性 | 求特征方程根 | 求 A 的特征值（同一件事） |
| 调得动吗 | —— | **可控性** |
| 看得见吗 | —— | **可观性** |

后两行是状态空间独有的。传递函数根本没法回答"我这个输出够不够反推全部内部状态"这种问题——而这正是 Day 9 观测器的核心。

⚠️ **能控标准型的状态没有物理含义**。它只是把"分母系数"机械地塞进矩阵，`x1`、`x2` 也不是位移和速度。所以真做工程（观测器、LQR）时，还是要像 §2 那样**按物理量选状态**。本课两种都写了一遍，就是为了让你看到：数学上等价，工程上不等价。

## 5. 矩阵能直接告诉你什么

拿到 A、B、C、D 之后，很多问题不用仿真就能回答。

### 5.1 极点 → 稳定性

**极点 = A 的特征值**（连续域）。

```python
lam = np.linalg.eigvals(A)
```

- 全部 `Re(λ) < 0` → 稳定（衰减）；
- 有 `Re(λ) > 0` → 发散；
- 有 `Re(λ) = 0` 且是单根 → 临界（等幅振荡 / 恒定值）。

本课系统 `m=1, k=4, c=0.8`，极点算出来是：

```
λ = -0.400 ± 1.960j
```

三个信息一次给你：

- 实部 `-0.4` → 衰减时间常数 `τ = 1/0.4 = 2.5 s`（振荡多久消掉）；
- 虚部 `1.96` → 振荡角频率 `ωd = 1.96 rad/s`（≈ 0.31 Hz）；
- 模长 `|λ| = √(0.4² + 1.96²) = 2.0` → **正好等于 ωn**。

最后一条不是巧合，见下面的图 (c)。

### 5.2 可控性：推得动吗

> 通过输入 `u`，能不能把状态推到任意想要的位置？

判据是秩：

```python
Ctrl = [B, A·B, A²·B, …, Aⁿ⁻¹·B]      # 形状 (n, n·m)
可控 ⟺ rank(Ctrl) == n
```

一句话理解：**B 把你推出去，A·B 是"推出去之后系统自己会带着你走的方向"，A²·B 再一步……** 如果这些方向能张满 n 维空间，那哪里都去得了。

本课的质量-弹簧-阻尼和直流电机都是可控的（实测 rana 都是 n）。

### 5.3 可观性：看得见吗

> 只看 `y`，能不能反推出全部状态？

```python
Obs = [C; C·A; C·A²; …; C·Aⁿ⁻¹]       # 形状 (n·p, n)
可观 ⟺ rank(Obs) == n
```

理解方式对称：**C 是第一次看到的，C·A 是"经过一步演化后看到的"，C·A² 再一步……**

这一条直接决定了 Day 9：**如果你只有位置传感器（C=[1,0]），速度这个状态就得靠观测器估出来**——而观测器能成立的前提，正是可观性。

本课代码里刻意造了一个反例：

```python
A = [[-1, 0], [0, -1]]      # 两个一模一样的极点
B = [[1], [0]]              # 只推得到第一个状态
C = [1, 0]                  # 只看得到第一个状态
```

结果：`可控 = False`、`可观 = False`。第二个状态既推不动也看不见，是个"孤儿"。这说明**B 和 C 的零出现在同一行/同一列上，是最危险的结构**。

现实里更常见的是"可控但不可观"：对象你推得动，但传感器读不全。这才是观测器的用武之地。

### 5.4 直流电机：一个真实的两状态对象

```python
L·di/dt = -R·i - Ke·ω + u      # 电枢回路，Ke·ω 是反电动势
J·dω/dt =  Kt·i - b·ω          # 机械方程，Kt·i 是电磁转矩
```

写成矩阵（状态 = `[i, ω]`）：

```python
A = [[-R/L, -Ke/L],
     [ Kt/J,  -b/J]]
B = [[1/L], [0]]
C = [0, 1]          # 输出转速（P1 速度环用的就是这一路）
```

代入本课参数（R=1, L=0.5, J=0.01, b=1e-3, Ke=Kt=0.05），实测极点：

```
λ = -1.6844 和 -0.4156
```

**两个极点差了 4 倍**，不是一个数量级——因为机电耦合把两个本可以差很多的根"拉"到一起了。

有意思的是把它们和"假设没有反电动势"（Ke = 0）比较：那时 `det(A) = (R/L)(b/J) = 0.2`，极点会跑到 `-2.0` 和 `-0.1` 附近。**反电动势相当于给系统加了一个"电气弹簧"**，它把电气极点和机械极点都往中间拽。

这也是为什么电机控制要分**电流环（内环，快）和速度环（外环，慢）**：电气时间常数 `L/R` 和机械时间常数 `J/b` 本来就差好几个数量级，反电动势又把它们耦合起来——分层控制就是在解这个耦合。

## 6. 离散化：接 Day 6，以及一条漂亮的恒等式

Day 6 已经把"给定 A、B，怎么算出 Ad、Bd"讲完了，这里只用结论：

```
Ad = e^{A·Ts}
Bd = (∫₀^{Ts} e^{A·τ} dτ)·B
```

**C、D 不变**（它们只是"怎么读数"，跟时间推进无关）。

今天要补的一条，是 Day 6 没讲透的：**ZOH 离散会精确保留极点**。

```
eig(Ad) = exp(eig(A)·Ts)
```

实测（`m=1, k=4, c=0.8, Ts=0.1`）：

| 连续极点 λ | `eig(Ad)` 实际算出来 | `exp(λ·Ts)` 理论值 |
|---|---|---|
| −0.400 − 1.9596j | 0.942401 − 0.187073j | 0.942401 − 0.187073j |
| −0.400 + 1.9596j | 0.942401 + 0.187073j | 0.942401 + 0.187073j |

**最大偏差 1.11e-16**，就是浮点极限，可以认为完全相等。

这条恒等式的意义远不止"数值准"：

- 它把 s 平面和 z 平面连起来了：`z = e^{s·Ts}`；
- 于是"连续稳定 ⟺ 极点都在左半平面"就自动变成"离散稳定 ⟺ 极点都在单位圆内"——**这正是 Day 6 里"ZOH 保稳定"的数学原因**；
- 顺带解释了为什么**前向欧拉不保极点**：它的映射是 `z = 1 + Ts·λ`（一条直线），而 `e^{s·Ts}` 是曲线，Ts 一大就差了十万八千里，左边半平面的点可能被映射到单位圆外（Day 6 的图 b 在画这个）。

本课算出的 `|eig(Ad)| = 0.9608 = e^{-0.4×0.1} = e^{-0.04}`，全在单位圆内，稳定。

## 7. 代码逐段

### 7.1 `StateSpace` 类：一个矩阵就是全部信息

```python
class StateSpace:
    def __init__(self, A, B, C, D=None, name=""):
        ...
```

构造函数做了**尺寸校验**（A 必须方阵、B 是 (n,m)、C 是 (p,n)、D 是 (p,m)）。这一步很值得写：状态空间最常见的错误就是维度对不上，早报错比仿真跑出一堆垃圾强。

对外提供的方法，按"分析 / 离散 / 仿真"三类分开：

| 方法 | 干什么 | 本课用它来 |
|---|---|---|
| `poles()` | 求 A 的特征值 | §5.1、图 (c) |
| `dcgain()` | 直流增益 | §8 的验证 1 |
| `freq_response(w)` | 算 G(jω) | §8 的验证 1 |
| `discretize(Ts)` | ZOH 离散 | §6、图 (d) |
| `controllability_matrix()` / `is_controllable()` | 可控性 | §5.2 |
| `observability_matrix()` / `is_observable()` | 可观性 | §5.3 |
| `step(Ts, n)` | 跑阶跃，**返回全部状态 X** | 图 (a)(b) |

最后一个注意：`step()` 返回的 `X` 形状是 `(n_steps, n)`，是**所有状态**的轨迹，不只是输出。这是状态空间相对传递函数的额外好处——图 (a) 里那条橙色的"速度"，你没有传感器，但能算出来。

### 7.2 三个建模模板

| 函数 | 对象 | 状态 | C 的含义 |
|---|---|---|---|
| `mass_spring_damper(m, c, k)` | m·ẍ + c·ẋ + k·x = F | [位移, 速度] | 默认测位移 |
| `dc_motor(R, L, J, b, Ke, Kt)` | 电机（电气+机械） | [电流, 转速] | 测转速 |
| `canonical_from_transfer(num, den)` | 任意传递函数 | 无物理含义 | —— |

前两个是"按物理量选状态"，第三个是"机械转换"。**同一个系统两种写法都能建出来**，§8 的验证 1 就是拿它们互相印证。

### 7.3 本课的三组验证

代码跑完会打印三组验证，都是"让你眼见为实"：

1. **物理建模 vs 能控标准型**：同一个 `1/(s²+0.5s+4)`，两套 A、B、C、D 算出的 `|G(jω)|` 相对差 ≤ 5.55e-17，`dcgain` 都是 `0.25 = 1/k`；
2. **ZOH 保极点**：`eig(Ad)` 和 `exp(λ·Ts)` 偏差 1.11e-16；
3. **可控/可观**：四个对象里有一个刻意造的"孤儿状态"，可控可观同时失败。

## 8. 图的对应与解释（四张子图）

### 图 (a)：一个系统，两个状态，只有一个有传感器

- 蓝色 `x1` = 位移（有传感器，`C=[1,0]`）；
- 橙色 `x2` = 速度（**没有传感器**，但状态空间把它算出来了）；
- 两条虚线几乎重合：位移峰值在 `t = 1.604 s`，速度过零点在 `t = 1.602 s`，**相差一个采样周期（2 ms）**。

**读法**：速度过零 = 位移停止上升 = 位移到达峰值。这就是 `x2 = ẋ1` 的几何含义。同时注意橙色的峰（0.38）比蓝的峰来得早——**速度总是先动，位移是跟着磨蹭的**。

这也是"状态 ≠ 输出"最直观的一课：`x2` 一直存在，只是你没有那个传感器。

### 图 (b)：同样是 ωn，只改阻尼 ζ

- 蓝 ζ=0.2：超调 **52.7%**，振荡明显；
- 橙 ζ=0.707：超调 **4.3%**，一个很小的鼓包；
- 绿 ζ=1.0：无超调，爬升最快；
- 红 ζ=2.0：无超调，最慢。

**读法**：横轴上四条曲线的"振荡快慢"完全一样（都是 ωn = 2 rad/s），差别只在"振荡消得多快"。**ωn 决定节奏，ζ 决定形状。**

### 图 (c)：极点随 c 的轨迹

- 灰虚线：半径 = ωn = 2 的圆；
- 红/紫：c 从 0.02 扫到 20 时两个极点的走向；
- 关键：**c 从 0 到 4（临界阻尼）的整个过程中，极点始终在这个圆上滑动**，只是从 `±2j` 沿圆弧往左走到 `-2`；
- 越过 `c = 4` 之后（breakaway 点 `-2`），两个极点分裂到实轴上，一个跑向 `-0.2`（越来越慢），一个跑向 `-20`（越来越快）。

**读法**：`|λ| = ωn` 这条几何事实告诉你——**调阻尼不改节奏，只改"衰减速度"和"往哪个方向躲"**。分裂后那个慢极点（→ -0.2）就是"重阻尼系统慢得像一阶"的原因。

### 图 (d)：ZOH 把极点映到 `z = e^{λ·Ts}`

- 灰虚线：单位圆（z 平面的稳定边界）；
- 彩色曲线：把 (c) 里的极点在 `Ts = 0.1 s` 下映射过来的轨迹；
- 标注：`λ = -0.400+1.960j → z = 0.942+0.187j，|z| = 0.9608 < 1`。

**读法**：整个 s 左半平面被"卷"进单位圆内。**圆的半径 `e^{Re(λ)·Ts}` 就是衰减快慢**——Re(λ) 越负、半径越小、收敛越快。这条映射是 Day 6 "ZOH 保稳定"的图解版本。

## 9. 今日要点

1. **状态就是系统的全部记忆**：知道它 + 未来的输入，就能算出未来全部输出。
2. **状态个数 = 传递函数分母的阶数**。代码里存了几个变量不算数。
3. **建模三步**：选物理量当状态 → 二阶方程拆成两个一阶 → 照着抄成矩阵。不需要背标准型。
4. **A 是本性、B 是入口、C 是窗口、D 是直连**。A、B 是对象属性，C 是你的传感器选择。
5. **极点 = eig(A)**：实部管衰减，虚部管振荡，模长 = ωn（阻尼未过临界时）。
6. **可控** = 推得动（`rank[B, AB, …] = n`）；**可观** = 看得见（`rank[C; CA; …] = n`）。Day 9 观测器的前提是可观性。
7. **能控标准型数学等价但工程不等价**：它的状态没有物理含义，真做观测器/LQR 要按物理量选状态。
8. **ZOH 精确保极点**：`eig(Ad) = exp(λ·Ts)`，实测偏差 1e-16。这就是"左半平面 → 单位圆"的代数版本。
9. **直流电机的两个极点被机电耦合拉近了**（-1.68 和 -0.42），这是"电流环要快、速度环要慢"的物理根源。

## 10. 速查表

**建模查表：**

| 拿到什么 | 怎么建 A、B、C、D |
|---|---|
| 一个 n 阶微分方程 | 选"变量 + 各阶导数"当状态，拆成 n 个一阶 |
| 一个传递函数 | 能控标准型，A 的第一行 = 分母系数取负 |
| 物理系统的能量项 | 拉格朗日/牛顿定律写出方程，再按上面拆 |
| 只有传感器图表 | C 由传感器决定；A、B 与传感器无关 |

**分析查表：**

| 想知道 | 看什么 |
|---|---|
| 稳不稳 | `eig(A)` 实部符号 |
| 振荡多快 | `eig(A)` 虚部 |
| 衰减多快 | `eig(A)` 实部（时间常数 = 1/\|Re\|） |
| 稳态到哪 | `dcgain = -C·A⁻¹·B + D` |
| 推得动吗 | `rank([B, AB, …]) == n` |
| 看得见吗 | `rank([C; CA; …]) == n` |
| 离散后稳不稳 | `eig(Ad)` 模长 < 1 |

**什么时候用哪个写法：**

| 场景 | 用哪个 |
|---|---|
| 单入单出、只关心输入输出关系 | 传递函数（省事） |
| 多入多出、要设计观测器/LQR/MPC | **状态空间**（必须） |
| 要处理初值、要仿内部量 | 状态空间 |
| 现场调 PID | 都不用，直接调（Day 1） |

**一个可以现在就验证的小事**：Day 4 的二阶低通在 Q = 0.7071（巴特沃斯）时，阶跃响应有 4.32% 超调，而第 (b) 图里 ζ = 0.7071 的那条线也正好是 4.3%。**两者是同一个系统**——Day 4 用 `fc`、`Q` 描述它，今天用 `m`、`c`、`k`（或 `ωn`、`ζ`）描述。换算公式：

```
ωn = √(k/m)          Q = 1/(2ζ)          fc = ωn/(2π)
ζ  = c/(2√(km))      ωn = 2π·fc
```

⚠️ 注意一个容易混的点：**"通带鼓包"的临界是 Q > 0.707，"阶跃超调"的临界是 ζ < 1（即 Q > 0.5）**。所以巴特沃斯（Q=0.707）虽然频域最平坦，时域仍有 4.32% 超调——它俩不是同一个"临界"。Day 4 只讲了频域那一面，今天补上时域这一面。

第一周：PID + 滤波（地基）
════════════════════════════════════

Day 1：环境搭建 + 建仓库 + 位置式 PID
安装 VS Code、Python、numpy、matplotlib
git init，写 .gitignore（忽略 __pycache__），打第一次 commit
以后每天结束前提交一次——commit 历史本身就是作品集的一部分
写一个位置式 PID 类（含积分分离、输出限幅、微分先行）
配一个一阶惯性环节作为被控对象：dx/dt = -ax + bu
画阶跃响应曲线：设定值 vs 实际值
调 P / I / D 三个参数，观察效果
【硬件】下单：编码电机 1:30、TB6612、MPU6050、8 通道逻辑分析仪，约 ¥120（清单见 控制项目实现/README.md）

Day 2：增量式 PID
写增量式 PID
对比位置式和增量式的区别（积分饱和、突变响应）
抗饱和两种写法都实现一次：积分分离 与 back-calculation，对比超调量
画对比图

Day 3：一阶低通滤波
写一阶 RC 低通滤波：y[k] = α * x[k] + (1-α) * y[k-1]
生成含噪声的正弦信号，滤波后对比
调 α 看截止频率变化

Day 4：二阶低通滤波
用 scipy.signal.butter 设计巴特沃斯，再自己写差分方程实现（先跑通，双线性变换的理论可以后补）
和一阶对比：谁的噪声抑制更好？谁的延迟更大？
补一张幅频特性图（画到 200 Hz），两个滤波器叠在一起比

Day 5：互补滤波
写互补滤波：angle = 0.98 * (angle + gyro*dt) + 0.02 * accel
注意 α 和采样率是绑定的：α = τ/(τ+dt)，200 Hz 下 0.98 只剩 0.24 s 的时间常数
模拟陀螺仪漂移 + 加速度计噪声
验证互补滤波能融合两者优点

Day 6：离散化专题（半天）+ 整理（半天）
写清楚连续模型怎么变离散：前向欧拉 / 后向欧拉 / ZOH 三条路，各自误差与适用场合
用 scipy.signal.cont2discrete 验证 ZOH
实验：同一个一阶对象，Ts 取 1 / 10 / 100 ms，看阶跃响应差多少，总结"采样时间到底怎么选"
整理前五天代码进 src/
用 Mermaid 画 PID 控制框图、滤波流程图（文本图能进 git，比 draw.io 好维护）
写 README 第一部分：PID + 滤波的原理和仿真结果

Day 7：休息 / 补进度 / 刷两道 LeetCode 保持手感
【硬件】器件到货就开工：电机开环转起来 + 编码器计数正确（P1 的 Step 0–1）

第二周：状态估计（核心硬菜）
════════════════════════════════════

Day 8：状态空间模型 + 离散化
从物理方程写出连续状态方程：质量-弹簧-阻尼 mẍ + cẋ + kx = 0 → A/B/C/D
用 numpy 实现离散递推：x[k+1] = A@x[k] + B@u[k]
用 cont2discrete 做 ZOH 离散，再和"直接把连续 A 当离散用"对比，看 Ts 大时能差多少
画自由响应曲线，并看特征值：极点位置决定快慢和振荡

Day 9：确定性观测器（上午）→ 卡尔曼滤波（下午）
先写 Luenberger 观测器：x̂[k+1] = A@x̂ + B@u + L@(y - C@x̂)
用 place_poles 配置 L，观察 L 大/小的差别：跟得快 vs 噪声放大
再写 KF 的预测 + 更新两步，记住一句话：KF 就是"增益随协方差自动调整的观测器"
对一维位置估计：测量有噪声，KF 能滤掉
画真实值、测量值、估计值的对比图

Day 10：扩展到二维 KF
位置 + 速度联合估计
调 Q 和 R 矩阵，观察收敛速度和平滑度的 trade-off
做一个 Q/R 扫描表：8 组参数 × (RMSE, 收敛时间)，选出最优那组并写清理由

Day 11：扩展卡尔曼滤波 EKF
针对非线性系统：比如 x^2 或 sin(x) 的测量
雅可比矩阵：先数值差分跑通，再换解析式，对比两者结果是否一致
对比 KF 和 EKF 在非线性系统上的表现

Day 12：EKF 应用于倒立摆
倒立摆的状态方程（非线性）——直接引用标准拉格朗日方程，别从零硬推，先把 EKF 跑通
用 EKF 估计摆角 + 角速度
画收敛过程
加一个鲁棒性验证：初值故意给错 30°，看多久收敛回来

Day 13：系统辨识（半天）+ 整理（半天）
这一天的东西，LQR 和 MPC 全都要靠它
做阶跃实验：给恒定输入，记录输出走到稳态的全过程
拟合 FOPDT：K（增益）、T（时间常数）、τ（纯滞后），用 curve_fit，记下 R²
把辨识结果直接转成状态空间——这是仿真和硬件之间唯一的那座桥
写 README 第二部分：状态估计的原理和仿真结果

Day 14：休息 / 补进度
【硬件】这周：P1 速度环闭环 + 阶跃辨识（正好复用 Day 13 的方法）；P2 姿态解算跟住 Day 9–11

第三周：最优控制（进阶）
════════════════════════════════════

Day 15：LQR 理论复习
理解代价函数：J = ∫(x^T Q x + u^T R u) dt
理解 Q 和 R 的含义：状态权重 vs 控制代价
理解黎卡提方程在做什么：把"无限长的未来代价"折成"当前的一个二次型"

Day 16：手写 LQR 求解器
先用迭代法解代数黎卡提方程（自己写，跑 100 次看收敛）
再用 scipy.linalg.solve_continuous_are 验证，两条路的结果应该一致
求离散版：solve_discrete_are + dlqr，对比连续 K 与离散 Kd 的差别

Day 17：LQR 闭环仿真
对象换成不稳定的：倒立摆线性化模型 / 双积分系统（用弹簧-阻尼这种稳定对象，看不出 LQR 镇定的价值）
画状态轨迹和控制量
调 Q/R 观察效果：更快的响应 vs 更小的控制量
鲁棒性测试：A/B 各加 ±20% 扰动，看闭环极点还稳不稳

Day 18：MPC 思想入门 + 无约束解析解
理解滚动优化 + 有限时域 + 预测矩阵：Y = F·z + Φ·ΔU
无约束时有闭式解，直接矩阵乘，别装 QP 库（QP 是留给约束的）
验收：无约束 MPC 跑稳后，等效增益应≈ LQR 的 K。对上了说明你写对了

Day 19：带约束的 MPC（这天才是 MPC 的精髓）
加约束：|u| ≤ u_max、Δu 限幅，进一步加状态约束（温度/倾角不能超）
用 osqp 或 cvxpy 解 QP
画出"约束被激活"的对比：PID 会硬顶到饱和然后超调/失控，MPC 会提前减速
这张图才是"MPC 到底强在哪"的答案

Day 20：MPC 与 LQR 的定量对比
预测时域 N 从 5 扫到 50：性能怎么变、单步计算量怎么涨
有无约束两种情况各跑一遍
写 README 第三部分：最优控制的原理和仿真结果

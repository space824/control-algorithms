## 2. 驱动选型：别用 L298N

| 模块 | 电压 | 持续电流 | 压降 | 效率 | 结论 |
|---|---|---|---|---|---|
| **TB6612FNG** | 2.5–13.5 V | 1.2 A（峰值 3.2 A） | 低 | 高 | **首选**，¥8–12 |
| DRV8833 | 2.7–10.8 V | 1.5 A | 低 | 高 | 双路一体 ¥10，但**上限 10.8 V，不适合 12 V 电池组** |
| L298N | 5–35 V | 2 A | **1.4–3 V** | **低** | 不推荐：发热大、压降大、还要 5 V 逻辑供电 |
| BTS7960 | 5.5–27 V | 43 A | 低 | 高 | 大功率车才用，¥25 |

**关键点**：L298N 每通道压降约 2 V，12 V 供电到电机只剩 10 V，发热还大。**同样的钱买 TB6612**。

功率开关（P5 加热）另有讲究：**必须用逻辑电平 MOSFET**（IRLB8721 / IRLR7843，`Vgs(th) < 2 V`）。普通的 IRF520 在 3.3 V 栅压下开不透，会停在放大区——**又烫又不通**。

## 3. 供电与共地（80% 的"玄学故障"都在这）

### 3.1 分级供电

```
电池/适配器 (12 V)
   ├─► 电机驱动 / 加热片      ← 大电流、有噪声
   └─► 降压模块 → 5 V         ← 干净电源
            ├─► MCU 5V 引脚（板载 LDO → 3.3 V）
            ├─► 编码器 VCC（3.3 V 或 5 V，看电机规格）
            └─► 传感器 VCC（3.3 V）
```

**原则：执行器和 MCU 用同一个电源，但走两条线。** 电机启动瞬间可达 3 A，这股电流不能流经 MCU 那一根细线。

### 3.2 共地（星形接地）

```
        ┌──── 电池负极（唯一的地参考点）
        │
   驱动 GND ──── MCU GND ──── 编码器 GND ──── 传感器 GND
```

- **必须全部连通**，否则信号没有共同参考 → 编码器读数随机跳、ADC 乱跳。
- **但不要串成一根线**（菊花链），大电流会让每段产生压降。
- 从电源负极用接线端子分多根线出去。

### 3.3 去耦电容（不能省）

在每个电机驱动模块的 **VM 与 GND 之间**就近并：

- 100 µF / 25 V 电解（储能，吸收启动冲击）
- 0.1 µF 瓷片（高频噪声）

**症状对照**：不加电容时，电机一加速 MCU 就复位 / 串口乱码 / ADC 跳变。加了就好——这不是玄学，是电源完整性问题。

### 3.4 电池

- 3S 18650（12.6 V 满电）**必须配保护板**（过充/过放/过流）。
- 满电 12.6 V → 快没电 9.5 V，**同样 PWM 扭矩差 30%**，增益会随电量漂移，测试尽量满电。
- 不要用杂牌，不要短路，不要刺穿。充电时人不要离开。

## 4. 编码器接线（P1 / P3 / P4 共用）

### 4.1 六线编码器电机的线序（JGB37-520 常见）

| 线色 | 功能 | 接法 |
|---|---|---|
| 红 | 电机 + | 驱动输出 |
| 黑（粗） | 电机 − | 驱动输出 |
| 蓝 | 编码器 VCC | **3.3 V**（部分电机要 5 V，看规格） |
| 黑（细） | 编码器 GND | GND |
| 绿 | A 相 | TIMx_CH1 |
| 白 | B 相 | TIMx_CH2 |

> **线序一定要自己实测**：万用表通断档找电机线（电阻几欧），剩下的用「两两之间有微弱电压变化」找编码器 A/B。**不要凭颜色硬接**——不同批次颜色定义会变。

### 4.2 STM32 编码器模式配置

| 项目 | 设置 |
|---|---|
| 模式 | `TIM_ENCODERMODE_TI12`（A/B 双通道，四倍频） |
| 输入滤波 | `ICFilter = 6`（抑制电机噪声引起的假计数） |
| 上拉 | 编码器多为开集输出，**开 MCU 内部上拉** `GPIO_PULLUP` |
| 计数范围 | 16 位（0–65535），读后清零 |

**经验**：`ICFilter` 太小在换向时丢/多数，太大（如 15）在高速时丢脉冲，**6–8 是常用值**。

## 5. IMU 安装（P2 / P3 / P4 共用）

| 要求 | 说明 |
|---|---|
| **刚性固定** | 螺丝或硬胶（环氧/厚涂热熔胶）。**禁止面包板插着、禁止软泡棉**——那会把振动变成噪声送进控制环 |
| **位置** | 尽量靠近车体几何中心、**远离电机和电池大电流走线**（磁场干扰） |
| **方向标注** | 车体和 IMU 模块上各画一个箭头，统一"前"方向，代码注释里写死符号表 |
| **减震（仅大车）** | 底盘有明显高频振动导致角度抖动时，可加薄硅胶垫；**只在确实有振动时加**，否则引入低频晃动 |
| **校准** | 每次上电静止 3–5 s 标定陀螺零偏 |

## 6. 布线习惯

1. **颜色约定**：红 = 电源正，黑 = GND，黄/绿 = 信号，蓝 = 编码器 A，白 = 编码器 B。全线统一。
2. **电机线双绞**，远离信号线；必要时加磁环。
3. **杜邦线只用于调试**。长期运行的线（PWM、电源）改成焊接 + 端子 + 热缩管。
4. **留检修余量**：每个模块的线留 3–5 cm 松弛，扎带固定，避免拉扯焊盘。
5. **标签**：超过 4 根线就贴标签。一周后你会感谢自己。

## 7. 保护设计（新手最容易忽略）

| 保护 | 做法 | 防什么 |
|---|---|---|
| **反接保护** | 电源输入串肖特基二极管（SS34）或 P-MOS 理想二极管 | 电池接反烧全板（最常见事故） |
| **过流** | 主回路串 2–5 A 自恢复保险丝（PPTC） | 电机堵转、短路 |
| **过压尖峰** | 电机端子并 TVS（SMBJ15A）+ 0.1 µF | 断电瞬间反电动势打穿驱动 |
| **过温** | 加热回路串 KSD 温控开关（常闭） | MCU 死机持续加热 |
| **软件急停** | 驱动 STBY 接 GPIO，按键拉低 | 失控时手动断输出 |
| **机械限位** | 转动部件加挡块 | 电机转到 360° 绞断线 |

## 9. 安全红线（上电前逐条过）

### 9.1 通用

- [ ] **先断电接线，接完用万用表测一遍有没有短路**，再上电
- [ ] 电源第一次上电，**串一个 1 A 保险丝**试（防接反烧板）
- [ ] 转动部件加护罩，附近**不要放手**
- [ ] 手边有**机械断电开关**（不是软件命令）
- [ ] 不在桌边测试（会掉），不在有液体的桌面测试

### 9.2 电机类（P1 / P3 / P4）

- [ ] 电机用夹具固定，**不要手持测试**（启动扭矩会甩飞）
- [ ] **第一次闭环前先验证符号**：正 PWM → 转速为正；前倾 → 控制器输出应让轮子往前追
- [ ] 第一次上电**架空空转**，第二次**扶墙**，第三次才放手
- [ ] 每次改增益都回到"架空"确认方向
- [ ] 场地 ≥ 2×2 m，铺防滑垫
- [ ] 倒立摆的摆杆平面内不要站人，戴护目镜

### 9.3 加热类（P5）

- [ ] **独立于 MCU 的过温保护**（KSD 常闭开关串在加热回路）
- [ ] 加热片贴金属散热块，不悬空、不贴塑料
- [ ] 箱体用亚克力/金属，**绝不用纸盒泡沫**
- [ ] 软件限温 60°C，写死在代码里
- [ ] 双路测温交叉校验（NTC + DS18B20），差 > 5°C 立即切断
- [ ] 人离开房间必须断电

## 10. 「玄学故障」速查

| 症状 | 90% 的原因 |
|---|---|
| 电机一加速 MCU 复位 | 电源被拉垮 → 加电容、分开供电 |
| 编码器读数随机跳 | 没共地 / 没有上拉 / 没开输入滤波 |
| I2C 读不到 | SDA/SCL 接反、没上拉、地址错 |
| 串口乱码 | 波特率不匹配 / 时钟配置错（HSE 没起振） |
| PWM 有了但电机不转 | STBY 没拉高 / 占空比低于死区 |
| ADC 读数跳变 | 参考电压不稳 / 没加滤波 / 走线太长 |
| 闭环一上就飞 | **反馈符号错了** |
| 时而正常时而失控 | 接触不良（杜邦线/面包板）→ 改焊接 |
| MOSFET 很烫但不加热 | 用了非逻辑电平管子，没开透 |

**故障时的顺序永远是**：电源 → 时钟 → 通信 → 信号 → 控制。先用万用表测电压、逻辑分析仪看波形，不要靠"再烧一次试试"。

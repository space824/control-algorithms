## 1. 项目目标（满足即可收工）

1. 给定速度指令（如 300 RPM），**100 ms 内**爬上目标，稳态误差 **< 2%**，超调 **< 10%**。
2. 手捏住输出轴施加扰动 0.2 s 后松手，**0.3 s 内**回到设定值——这是「积分项真的在工作」的直接证据。
3. 上位机录一段阶跃数据导出 CSV，做出**「仿真 vs 实测」对比图**。

做完这三条，你就从「会写 PID 类」跨到了「能让电机听话」。移动机器人、云台、机械臂、无人机的底层，全是这一套。

---

## 2. 为什么第一个项目选它

- 传感器和执行器都是**数字量**（编码器计数、PWM 占空比）：没有噪声标定、没有姿态坐标系，变量最少。
- 出错时**现象明确**：不转 → 查接线；反向 → 换相；抖动 → 查周期或滤波；超调 → 查参数。最适合练调试手感。
- 代码骨架（`motor.c` / `encoder.c` / `pid.c` / 10 ms 定时器 / 串口上报）在 P3 里**原样复用**，是资产不是练习。

## 4. 接线

### 4.1 引脚分配（F103C8T6）

| 信号 | 引脚 | 外设 | 说明 |
|---|---|---|---|
| PWMA | PA8 | TIM1_CH1 | 20 kHz PWM |
| AIN1 / AIN2 | PB0 / PB1 | GPIO 推挽 | 方向控制 |
| STBY | 3.3 V | — | 拉高使能 |
| 编码器 A | PA0 | TIM2_CH1 | 编码器模式 |
| 编码器 B | PA1 | TIM2_CH2 | 编码器模式 |
| 串口 TX / RX | PA9 / PA10 | USART1 | 115200 |
| 调试 LED | PC13 | GPIO | 心跳 / 故障指示 |

> 编码器用 **TIM2 编码器模式**（`TIM_EncoderMode_TI12`），硬件自动四倍频计数，不用写中断。每周期读后清零，读到的就是「本周期脉冲数」。

### 4.2 供电

```
12V 适配器 ─┬─► TB6612 VM
            └─► MP1584 ──5V──► F103 的 5V 引脚（板载 LDO 再转 3.3V）

共地（必须全部连通）：
  适配器负极 ─ TB6612 GND ─ F103 GND ─ 编码器 GND
```

**共地不要串一根细杜邦线**。用星形接地：从电源端子单独拉线到驱动和 MCU，避免电机电流在信号地上产生压降。

## 5. 控制结构

```
        ┌──────────── TIM3 更新中断（10 ms，固定周期）────────────┐
        │                                                       │
rpm_ref ─►[-]─► 位置式 PID ─► 限幅 ±10000 ─► PWM ─► TB6612 ─► 电机 ─► 编码器 ─┐
           ▲       （或增量式）                                            │    │
           │                                                                │    │
           └──────── 一阶低通 ◄──────── 测速 Δn/(Δt·1320) ◄────────────────┘    │
                                                                                │
  主循环（非阻塞）: 每 100 ms 发一行  t, rpm_ref, rpm_meas, pwm, kp, ki, kd  ◄───┘
```

**任务划分**（决定项目成败的地方）：

| 频率 | 做什么 | 在哪 |
|---|---|---|
| 20 kHz | PWM 载波 | 硬件 TIM1 |
| **100 Hz** | **测速 + PID + 更新占空比** | **TIM3 更新中断，优先级最高** |
| 10 Hz | 串口上报一行 | 主循环，非阻塞 |
| 1 Hz | LED 心跳 | 主循环 |

> 控制周期必须**严格等间隔**。用 `HAL_Delay(10)` 的话周期会随串口发送漂移，积分项 `Ki·Σe` 直接算错——这是新手最典型的翻车点。

## 6. 三个必须先想清楚的问题

### 6.1 测速的量化误差有多大

每 10 ms 读一次计数器差值 `Δn`：

```
rpm = Δn / (1320) / 0.01 × 60 = Δn × 4.545
```

即 **1 个计数 = 4.5 RPM**。300 RPM 时相对误差约 1.5%（可接受）；降到 30 RPM 只有 6.6 个计数，误差 15%，曲线会有明显锯齿——**低转速必须靠低通或加长窗口**。

| 方法 | 原理 | 低速 | 高速 | 结论 |
|---|---|---|---|---|
| **M 法**（定周期数脉冲） | 10 ms 内数脉冲 | 差（量化大） | 好 | **本方案默认** |
| T 法（定脉冲测时间） | 数 N 个脉冲测耗时 | 好 | 差 | 低速场合再换 |
| M/T 法 | 两者结合 | 好 | 好 | 进阶，本阶段不必 |

### 6.2 位置式还是增量式

| | 位置式 | 增量式 |
|---|---|---|
| 输出 | `u = Kp·e + Ki·Σe + Kd·Δe` | `Δu = Kp(e_k−e_{k−1}) + Ki·e_k + Kd(e_k−2e_{k−1}+e_{k−2})` |
| 积分饱和 | 必须手写抗饱和 | **天然不存在**（只输出增量） |
| 模式切换 | 手/自动切换会跳变 | 无冲击 |
| 适合 | 需要绝对输出 | **PWM 这类「累加型」执行器** |

**建议**：速度环先用位置式（好理解、能直观看到积分作用），跑通后改增量式对比一次。这正好是 Day 2 的对比实验，**在硬件上做一遍比在 matplotlib 上有说服力得多**。

### 6.3 PWM 频率与死区

- F103 72 MHz，TIM1 **边沿对齐** PSC=0、ARR=3599 → **20 kHz**（中心对齐则是 10 kHz，电机略有啸叫）。
- TB6612 有死区与驱动压降，**占空比 < 5% 时电机可能不转**。做输出限幅时把这个死区算进去：限 ±95%，且 5% 以下直接输出 0，避免「嗡嗡响但不转」。

## 7. 分阶段实现

| Step | 做什么 | 验收标准 |
|---|---|---|
| **0** | 开环 PWM：固定 30% 占空比，电机转起来 | 能正反转；占空比越大转越快 |
| **1** | 编码器：手转输出轴一圈，计数应为 **±1320** | 正转增大、反转减小，数值稳定 |
| **2** | 开环测速：占空比 20/40/60/80/100% 各测 3 s 平均转速 | 得到「占空比 → 转速」曲线，看出死区 |
| **3** | 速度环 P：`Kp` 从 0 慢加 | 能跟设定值，但一定有稳态误差（证明 P 不够） |
| **4** | 加 I：`Ki` 由小到大 | 稳态误差归零；Ki 过大出现 1–2 Hz 低频振荡 → 退回去 |
| **5** | 加低通：`α = 0.3` 起 | 毛刺消失，同时观察相位滞后变大 |
| **6** | 阶跃测试 + 辨识：录 200 点，拟合 `K/(Ts+1)` | 拟合 R² > 0.95；用辨识的 T 反算 PI，实测验证 |

**Step 2 的表格一定要填**，它是后面所有调参的物理直觉来源：知道 100% 占空比对应多少 RPM，你才知道 `Kp` 从哪个量级开始试。

### 8.2 10 ms 控制中断（最核心的 20 行）

```c
/* 换算常数: 60 / (PPR * 4 * GEAR * DT) = 60 / (11*4*30*0.01) = 4.545 */
#define CNT2RPM  4.5454f

void TIM3_IRQHandler(void)
{
    if (__HAL_TIM_GET_FLAG(&htim3, TIM_FLAG_UPDATE) == RESET) return;
    __HAL_TIM_CLEAR_FLAG(&htim3, TIM_FLAG_UPDATE);

    /* 1. 读编码器（读后立即清零，保证一个周期不漏） */
    int16_t dn = (int16_t)__HAL_TIM_GET_COUNTER(&htim2);
    __HAL_TIM_SET_COUNTER(&htim2, 0);

    /* 2. 转速换算 + 一阶低通 */
    float rpm_raw = (float)dn * CNT2RPM;
    rpm_meas = lpf_update(&lpf_rpm, rpm_raw);      /* alpha = 0.3 */

    /* 3. PID */
    float u = pid_calc(&pid_speed, rpm_ref, rpm_meas);

    /* 4. 输出 */
    motor_set(u);                                   /* 内部限幅 ±10000 */
}
```

> `int16_t` 强转很关键：反转时 TIM2 计数会从 0 往下走变成 65535，强转成有符号数才是 `-1`。**每周期清零**最省事（代价是不能用硬件累加位置，做位置环要另算）。

### 8.3 位置式 PID（抗饱和 + 微分先行）

```c
typedef struct {
    float kp, ki, kd;
    float integral;
    float prev_meas;
    float out_max;      /* 10000 */
    float int_max;      /* 建议 0.8 * out_max */
} pid_t;

float pid_calc(pid_t *p, float ref, float meas)
{
    float err = ref - meas;

    /* 积分分离: 误差很大时不积分, 避免起步猛冲与饱和 */
    if (fabsf(ref) > 1e-3f && fabsf(err) < 0.5f * fabsf(ref)) {
        p->integral += p->ki * err;
        if (p->integral >  p->int_max) p->integral =  p->int_max;
        if (p->integral < -p->int_max) p->integral = -p->int_max;
    }

    /* 微分先行: 对测量值求导, 设定值突变时不产生微分冲击 */
    float d = -p->kd * (meas - p->prev_meas);
    p->prev_meas = meas;

    float u = p->kp * err + p->integral + d;
    if (u >  p->out_max) u =  p->out_max;
    if (u < -p->out_max) u = -p->out_max;
    return u;
}
```

**抗饱和的精髓不是限幅，而是「饱和时停止积分」**。上位用了「积分分离 + 限幅」双保险；进一步可写 back-calculation（`integral -= kb·(u - u_sat)`）。

**增量式版本**（Step 4 之后对比用）：

```c
float pid_calc_inc(pid_t *p, float ref, float meas)
{
    float e0 = ref - meas;
    float du = p->kp * (e0 - p->e1) + p->ki * e0 + p->kd * (e0 - 2*p->e1 + p->e2);
    p->e2 = p->e1; p->e1 = e0;
    /* 输出是增量, 由调用者累加到全局 u 上, 天然不需要抗饱和 */
    return du;
}
```

### 8.4 串口上报（不许阻塞控制环）

```c
/* 主循环里每 100 ms 一次 */
printf("%lu,%.1f,%.1f,%.0f\r\n", HAL_GetTick(), rpm_ref, rpm_meas, u);
```

- 波特率先用 115200（一行 ~30 字节，10 Hz 完全够）。
- **绝对不要在 10 ms 中断里 `printf`**：HAL 的阻塞发送会把周期抖到 12–15 ms，积分和微分全部失真。
- 想上 200 Hz 采样就换 921600 + 二进制帧 + CRC（见 [上位机与工具链.md](../公共资料/上位机与工具链.md)），或用 DMA 发送 + 环形缓冲。

## 9. 参数整定

先算**理论起点**，别盲试。由 Step 6 的辨识结果 `G(s) = K/(Ts+1)`（K: RPM per 输出量，T: s）：

```
取闭环时间常数 Tc = 0.3 T
    Kp = T / (K · Tc)
    Ki = Kp / T          （积分时间 Ti = T）
```

再**实测微调**：

| 现象 | 原因 | 动作 |
|---|---|---|
| 响应慢、跟不上 | Kp 偏小 | Kp × 1.3 |
| 起振、等幅振荡 | Kp 过大 / Kd 不足 | Kp × 0.7 |
| 有稳态误差 | Ki 不足 | Ki × 1.5 |
| 1–2 Hz 低频来回摆 | Ki 过大 | Ki × 0.5 |
| 突变设定值猛冲 | 无抗饱和 | 加积分分离 + 输出限幅 |
| 曲线全是毛刺 | 测速量化 | 减小 α 或加长测速窗口 |

**起始参数**（1:30 电机、300 RPM 量级、输出 ±10000）：`Kp = 30, Ki = 15, Kd = 0`。速度环一般不需要 D，真要加从 2 起。**这些只是量级参考，一切以 Step 2 实测为准。**

## 11. 常见坑

1. **编码器不计数**：没调用 `HAL_TIM_Encoder_Start(&htim2, TIM_CHANNEL_ALL)`；或 AB 相接反导致计数反向。
2. **转速符号错 → 闭环正反馈飞车**。Step 1 必须单独验证：给正占空比，RPM 必须为正。**这条不验证，第一次闭环就可能烧驱动。**
3. **电机一加速 MCU 就复位**：电源被拉垮。在 TB6612 的 VM/GND 就近并 100 µF 电解 + 0.1 µF 瓷片；电机线与信号线分开走线。
4. **积分饱和造成「起转延迟」**：0 → 300 RPM 时 PWM 早已打满还在积分，反转前要先「卸积分」。用积分分离。
5. **`printf` 阻塞控制环**：见 §8.4。
6. **速度环带宽设太高**：机械时间常数 T 若为 80 ms，却想要 10 ms 上升时间，必然振。控制带宽不超过对象带宽的 1/3。
7. **死区导致低速爬行**：3% 占空比电机不转，积分一路累加，突然转起来猛跳。低速段把输出限制在「刚好过死区」的最小值。
8. **只看平均数不看曲线**：平均值漂亮但曲线在抖，等于没做。
9. **忘了共地**：编码器与 MCU 不共地，计数值随机跳。
10. **换电机不重新整定**：每个电机的 K、T 都不同，参数要重来——正好再走一遍辨识流程。

## 12. 软件侧：阶跃分析与模型辨识

```python
# python/step_analysis.py —— 读 CSV，算指标，拟合一阶模型
import numpy as np, pandas as pd
from scipy.optimize import curve_fit

df = pd.read_csv("step_300rpm.csv")            # 列: t_ms, ref, rpm, pwm
t  = df.t_ms.values / 1000.0
y  = df.rpm.values

def first_order(t, K, T, t0):
    return np.where(t < t0, 0.0, K * (1 - np.exp(-(t - t0) / T)))

popt, _ = curve_fit(first_order, t, y, p0=[300, 0.08, t.min()], maxfev=20000)
K, T, t0 = popt
print(f"K = {K:.1f} RPM/unit, T = {T*1000:.1f} ms")

yf     = y[-100:].mean()
overshoot = (y.max() - yf) / yf * 100
t90    = t[np.argmax(y > 0.9 * yf)]
print(f"超调 {overshoot:.1f}%, t90 {t90*1000:.0f} ms, 稳态误差 {(yf-ref[-1])/ref[-1]*100:.2f}%")
```

这一步和你 `../../examples/day1_position_pid.py` 里的仿真指标是**同一套定义**——把实测曲线和仿真曲线画在同一张图上，就是报告里最有说服力的一张图。

## 1. 项目目标

1. **静止**时角度抖动标准差 **< 0.5°**（手放在桌上不动，读 1000 点算 std）。
2. **动态**摆动时与参考角度误差 **< 2°**，且不随陀螺漂移跑偏。
3. 产出一张**四条曲线对比图**：加速度计直算角 / 陀螺积分 / 互补滤波 / 二维 KF。

---

## 2. 为什么单独做它

- **零风险、零机械**：没有电机、没有会飞的东西，纯感知，插上就能调。
- 姿态角是所有平衡类项目（P3 平衡车、P4 倒立摆、四旋翼、云台）的**第一块拼图**，代码在 P3 里直接复用。
- 它是你计划里「Day 5 互补滤波」和「Day 9–13 状态估计」之间的**天然桥梁**：同一个物理量，用四种方法估计，误差一张图比出来——这正是面试官最爱问的那种对比。

**核心矛盾**（先把这句话记住，后面所有方法都是它的变体）：

| 传感器 | 优点 | 缺点 |
|---|---|---|
| 加速度计 | 长期不漂移（重力是绝对的） | 动态噪声大，振动/加减速下完全不可信 |
| 陀螺仪 | 短时间很准、响应快 | 积分会漂移（零偏累积） |

**低频可信加速度计 + 高频可信陀螺仪 = 融合滤波**。互补滤波、卡尔曼、Mahony、Madgwick 全是这个思路的不同数学表达。

## 5. 数据链

```
MPU6050 (200 Hz 硬件采样)
   │  I2C 突发读 14 字节 (0x3B 起)
   ▼
TIM 定时 200 Hz 中断 ──► 原始值 → 单位换算 → 零偏扣除
   │                          │
   │                          ├─► 加速度计角:  atan2(ay, az)
   │                          └─► 陀螺角速度: gx - bias
   ▼
算法（互补 / KF / EKF）──► 角度
   │
   ├─► 串口上报 (100 Hz)  ──► 上位机实时曲线
   └─► OLED 显示
```

**关键点：用定时器中断触发采样，不要用 `while(1)` 轮询**。卡尔曼的 `dt` 必须是真实间隔，轮询会让 `dt` 抖动 ±2 ms，`Q` 矩阵的假设全部失效。

## 6. 阶段 A：把数据读通

### 6.1 初始化序列（照抄即可）

| 寄存器 | 地址 | 值 | 含义 |
|---|---|---|---|
| PWR_MGMT_1 | 0x6B | `0x01` | 退出睡眠，时钟选陀螺 X 轴 PLL（比内部 RC 稳） |
| SMPLRT_DIV | 0x19 | `0x04` | 采样率 = 1 kHz / (1+4) = **200 Hz** |
| CONFIG | 0x1A | `0x03` | DLPF：加速度 44 Hz、陀螺 42 Hz（想更平滑用 `0x04`=21 Hz） |
| GYRO_CONFIG | 0x1B | `0x08` | 量程 ±500 °/s，灵敏度 **65.5 LSB/(°/s)** |
| ACCEL_CONFIG | 0x1C | `0x00` | 量程 ±2 g，灵敏度 **16384 LSB/g** |
| INT_ENABLE | 0x38 | `0x01` | 数据就绪中断（用 INT 引脚时需要） |

### 6.2 换算

```c
float ax = raw_ax / 16384.0f;          /* 单位 g */
float gyro_x = raw_gx / 65.5f;         /* 单位 °/s */
/* 加速度计直算倾角（绕 X 轴） */
float ang_acc = atan2f(ay, az) * 57.29578f;
```

> 量程选择有取舍：±500 °/s 够平衡车用（快速倒地时角速度可达 300 °/s）；想留余量用 ±1000（32.8 LSB/(°/s)），代价是分辨率变差。

## 7. 阶段 B：零偏标定（必须有）

上电后**静止 3–5 秒**，采样 500 点求均值，作为陀螺零偏：

```c
gyro_bias_x = mean(gx_samples);        /* 单位 °/s, 通常 0.1~2 °/s */
```

- 零偏**随温度漂移**，所以每次上电都要标，且在「工作温度」下标。
- 顺带算加速度计静止均值和标准差：均值用来校正安装倾角（模块贴歪几度），标准差用来定 KF 的 `R`（见 §11）。

## 8. 阶段 C：互补滤波

```
angle[k] = α · (angle[k-1] + gyro·dt) + (1-α) · angle_acc[k]
```

**α 的物理意义**：等价于一个时间常数为 τ 的一阶低通，用来「信任陀螺的时长」。

```
τ = α·dt / (1-α)      ⟺      α = τ / (τ + dt)
```

| dt | 想要 τ | α |
|---|---|---|
| 10 ms（100 Hz） | 0.5 s | **0.980** ← 课本常见值来自这里 |
| 5 ms（200 Hz） | 0.5 s | **0.990** |
| 5 ms（200 Hz） | 1.0 s | 0.995 |

> **很多人直接抄 `0.98` 却采样率是 200 Hz，结果 τ 只有 0.24 s，滤波效果偏弱。改采样率必须重算 α。**

调参方向：α 越大 → 越信陀螺 → 平滑、但长期会漂；α 越小 → 越信加速度计 → 跟得快、但抖动大。**0.98~0.99 之间找平衡**。

```c
float complementary_update(float gyro, float acc_ang, float dt, float alpha)
{
    static float angle = 0.0f;
    angle = alpha * (angle + gyro * dt) + (1.0f - alpha) * acc_ang;
    return angle;
}
```

**这一步就能用了**。互补滤波计算量极小（两次乘加），在 F103 上跑 200 Hz 毫无压力，很多量产产品就用它。先用它跑出动图，再去啃卡尔曼。

## 9. 阶段 D：一维卡尔曼（只估角度）

状态一个变量 `x = [angle]`。预测用陀螺，观测用加速度计。

```
预测:  x⁻ = x + (gyro - bias)·dt        P⁻ = P + Q·dt
更新:  K  = P⁻ / (P⁻ + R)
       x  = x⁻ + K·(z_acc - x⁻)
       P  = (1 - K)·P⁻
```

- `Q`：过程噪声，代表「模型有多不信任」。陀螺噪声大就调大。
- `R`：观测噪声，**用实测的加速度计角方差**（§7 里算的 std²）。
- `K` 自动在 0~1 间滑动：初始 `P` 大 → `K→1`（听加速度计的）；跑久了 `P` 降下来 → `K→0`（听陀螺的）。

**这一步会遇到的问题**：陀螺零偏是未知的常值，一维 KF 会把零偏「当成噪声」处理，角度仍会缓慢漂移。这就是要升二维的原因。

---

## 10. 阶段 E：二维卡尔曼（角度 + 陀螺零偏）—— 本项目的核心

状态 `x = [angle, bias]`，这才是工程上真正好用的版本：

```
预测:
    angle += dt * (gyro - bias)
    P00 += dt*(dt*P11 - P01 - P10 + Q_angle)
    P01 -= dt * P11
    P10 -= dt * P11
    P11 += Q_bias * dt

更新 (z = 加速度计角):
    y  = z - angle
    S  = P00 + R_measure
    K0 = P00 / S ;  K1 = P10 / S
    angle += K0 * y
    bias  += K1 * y
    P00 -= K0*P00 ;  P01 -= K0*P01
    P10 -= K1*P00 ;  P11 -= K1*P01
```

```c
typedef struct { float P[2][2]; float angle, bias;
                 float Q_angle, Q_bias, R_measure; } kf2_t;

float kf2_update(kf2_t *k, float gyro, float z_acc, float dt)
{
    /* --- 预测 --- */
    k->angle += dt * (gyro - k->bias);
    k->P[0][0] += dt * (dt*k->P[1][1] - k->P[0][1] - k->P[1][0] + k->Q_angle);
    k->P[0][1] -= dt * k->P[1][1];
    k->P[1][0] -= dt * k->P[1][1];
    k->P[1][1] += k->Q_bias * dt;

    /* --- 更新 --- */
    float y = z_acc - k->angle;
    float S = k->P[0][0] + k->R_measure;
    float K0 = k->P[0][0] / S, K1 = k->P[1][0] / S;
    k->angle += K0 * y;
    k->bias  += K1 * y;
    float P00 = k->P[0][0], P01 = k->P[0][1];
    k->P[0][0] -= K0 * P00;  k->P[0][1] -= K0 * P01;
    k->P[1][0] -= K1 * P00;  k->P[1][1] -= K1 * P01;
    return k->angle;
}
```

**为什么这一版好**：`bias` 被显式地估出来了。你可以在串口里把 `bias` 打出来——静止时它应该稳定在一个小常值附近（比如 0.6 °/s），**这就是滤波器在自动标定零偏**，是很漂亮的一个可视化结果。

**起始参数**（200 Hz、±500 °/s 量程）：

| 参数 | 起始值 | 调法 |
|---|---|---|
| `Q_angle` | `0.001` | 变大 → 更信加速度计 → 跟得快、抖 |
| `Q_bias` | `0.003` | 变大 → 零偏收敛快，但角度会跟着抖 |
| `R_measure` | `0.03` | **用实测加速度计角方差填**，别猜 |

`R_measure` 的正确做法：静置 1000 点，`R = var(angle_acc)`。若算出 0.5，就用 0.5。

## 11. 阶段 F：EKF（四元数，可选进阶）

一维/二维 KF 只估一个轴，且假设小角度。真要三维姿态（翻滚/俯仰/偏航），用四元数 EKF：

```
状态: q = [q0, q1, q2, q3]
预测: q̇ = 0.5 · q ⊗ [0, ωx, ωy, ωz]    （离散化后由陀螺积分）
      F = ∂f/∂q （4×4，含 ω 与 dt）
观测: 把 q 转成重力方向 ĝ = R(q)·[0,0,1]，与归一化加速度计 a/|a| 比较
      残差 r = a/|a| - ĝ
      H = ∂ĝ/∂q （3×4，解析式或数值差分）
更新: 标准 EKF 公式，最后归一化 q
```

三个务实建议：

1. **雅可比用数值差分先跑通**（`H[:,i] = (g(q+εe_i) - g(q-εe_i))/(2ε)`，ε=1e-6），跑通再换解析式。数值差分在 F103 上也就 8 次函数调用，200 Hz 完全够。
2. **先写仿真**：在 Python 里用陀螺真值 + 加噪加速度计跑 EKF，验证收敛再上板子。这就是 Day 11 的任务。
3. **别自己造轮子太久**：Madgwick / Mahony 滤波器（互补滤波的非线性版本，带陀螺零偏在线估计）实现只有几十行，效果接近 EKF 且计算量小得多。**先用 Mahony 跑出三维姿态，再拿自己的 EKF 对比**，这个对比本身就是报告的一节。

## 12. 精度怎么评估（别自欺欺人）

| 指标 | 方法 | 目标 |
|---|---|---|
| 静态噪声 | 静止 1000 点，算 std | < 0.5° |
| 静态漂移 | 静止 5 分钟，看首尾差 | < 1°（KF 应优于互补滤波） |
| 动态精度 | 装在小舵机/慢速转台上按 0.5 Hz 摆动，用手机倾角 App 或量角器夹具做参考 | 误差 < 2° |
| 相位滞后 | 正弦摆动时比较输入与估计的过零点时间差 | < 30 ms |
| 零偏估计 | 串口打印 `bias`，静止时应稳定不漂 | 波动 < 0.2 °/s |

**"没有参考标准的角度测量等于没测"**。最省事的参考：手机装个水准仪/倾角 App，跟模块一起贴在同一个平面上。

## 13. 常见坑

1. **`WHO_AM_I` 读不到**：多半是 SDA/SCL 接反或没接上拉。用逻辑分析仪看一眼波形最快。
2. **读出来的数全是 0 或 0xFFFF**：没有先写 `PWR_MGMT_1=0x00/0x01` 退出睡眠。
3. **不加零偏标定**：角度 10 秒漂 5°，你会误以为是滤波器写错了。
4. **`dt` 用固定值而实际采样有抖动**：200 Hz 的定时器中断优先级被串口打断 → dt 实测 5 ms 波动到 7 ms → 滤波振荡。**把 IMU 采样中断设为最高优先级。**
5. **忘记量程换算**：把 `65.5 LSB/(°/s)` 当成 `131`（那是 ±250 量程），角度会差一倍。
6. **符号搞错**：三轴方向必须实测确认（绕某轴转，看哪个数变化、是正是负）。写张符号表贴在代码注释里。
7. **模块没固定死**：用面包板插着调，一动就抖 → 你调的是「面包板振动」不是算法。**热熔胶或螺丝固定死**。
8. **DLPF 开太大**（21 Hz）+ 快速摆动：相位滞后明显，平衡车会抖。平衡类项目用 44 Hz 以上。
9. **在中断里做 `atan2` 和浮点除**：F103 无 FPU，`atan2f` 约 20 µs。200 Hz 时占比很小可接受，但别放 1 kHz 环里。
10. **忘了先仿真**：直接上板子调 Q/R 会陷入「改一个数、烧一次固件、看一眼」的低效循环。

## 14. 软件侧

- **上位机**：一条串口发 `t, ang_acc, ang_gyro, ang_cf, ang_kf, bias` 六列，Python 画 4 条曲线叠加。参考 [上位机与工具链.md](../公共资料/上位机与工具链.md)。
- **先离线仿真**（推荐在 `../../examples/` 里加一个 `day5_complementary.py`）：

```python
import numpy as np
dt, N = 0.005, 2000                      # 200 Hz, 10 s
t = np.arange(N) * dt

true_ang = 0.3 * np.sin(2*np.pi*0.5*t)   # 真实姿态: 0.5 Hz 摆动, 单位 rad
gyro = np.gradient(true_ang, dt) + 0.02 + 0.01*np.random.randn(N)   # 零偏 + 噪声
acc  = true_ang + 0.05*np.random.randn(N)                          # 噪声更大的观测量

# 互补滤波
alpha, ang_cf = 0.99, 0.0
out_cf = []
for k in range(N):
    ang_cf = alpha*(ang_cf + gyro[k]*dt) + (1-alpha)*acc[k]
    out_cf.append(ang_cf)

print("acc  RMSE:", np.sqrt(np.mean((acc-true_ang)**2)))
print("gyro RMSE:", np.sqrt(np.mean((np.cumsum(gyro*dt)-true_ang)**2)))
print("cf   RMSE:", np.sqrt(np.mean((np.array(out_cf)-true_ang)**2)))
```

把 `alpha` 换成 0.9 / 0.99 / 0.999 各跑一遍，你就**在电脑上先看到了 α 的效果**——到货后只需移植，不用摸索。
